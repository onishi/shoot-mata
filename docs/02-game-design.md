# 02 ゲームデザイン

## プレイの流れ
タイトル → 操作説明を見て開始 → ステージを右へ進み敵と戦う → ボス撃破でクリア、残機を失うとゲームオーバー → 結果画面 → 再挑戦またはタイトル。

初期目標は1ステージ約3分。プロトタイプでは約60秒の縮約版を作る。画面は自機を左側に置き、敵が右から入る。背景だけがスクロールする演出でもよい。

## コアループ
1. 移動して敵弾を避け、敵の形と配置を見る。
2. 雑魚の群れにはワイド、耐久敵にはフォーカスを選んで撃つ。
3. 敵を倒し、破壊音・光・スコアで結果を知る。
4. 落ちたエネルギーを回収するか、安全を優先するか決める。
5. ゲージが満タンならバーストの使い時を選ぶ。次の敵配置へ進む。

## 初期ルール
- 移動：矢印キー／WASD。射撃：Space を押している間。武器切替：Shift または X。バースト：Z。ゲーム中の P または Escape でポーズ。
- 自機の移動範囲は画面内。フォーカス中は速度を下げ、精密に狙えるようにする。
- ワイドは3方向、フォーカスは正面の高火力弾。切替は即時で、現在のモードを色とHUD文字で示す。
- 敵は軽量機、耐久機、ボス。軽量機はワイドが当てやすく、耐久機はフォーカスが速く倒せる耐久値にする。
- 敵弾・敵本体に触れると被弾。短い無敵時間を設け、被弾のたびに残機を1減らす。残機が0になると終了。
- 敵を倒すとスコアとエネルギーが出る。エネルギーは一定時間で消える。ゲージが満タンなら Z で短時間の高火力バーストを発動し、ゲージを空にする。
- ボス撃破でクリア。ボスが出る前に残機が尽きればゲームオーバー。
- 結果画面にスコア、撃破数、被弾数を示す。再挑戦で全状態を初期化する。

## スコアと難度
- 軽量機100点、耐久機300点、ボス2000点。回収1個50点。クリア残機は1機につき500点。
- コンボやオンラインランキングはMVP外。最初はリトライ時の自己スコア比較のみを目指す。
- 難度は固定。序盤で移動と切替、中盤で回収とバースト、終盤でボスを確認できるように敵配置を作る。敵弾速度・密度・体力は実プレイ後に調整する。

## 画面と情報
| 画面 | 主な情報・操作 |
| --- | --- |
| タイトル | ゲーム名、開始、操作説明、音のON/OFF |
| プレイ | 残機、スコア、武器モード、バーストゲージ、ポーズ操作 |
| ポーズ | 再開、リトライ、タイトル、音のON/OFF |
| 結果 | クリア／ゲームオーバー、スコア、撃破数、被弾数、再挑戦、タイトル |

初回はタイトル画面で操作を表示し、プレイ中は切替直後に武器名を短く表示する。背景と敵弾、自弾は色・形・明度で見分けられるようにする。スマートフォンでは画面内の移動パッド、射撃、切替、バースト、ポーズを用意する。タッチUIの具体的な配置はフェーズ03で決める。

## 未確定でプレイ後に調整する数値
自機速度、発射間隔、敵体力、敵弾速度、エネルギー消滅時間、ゲージ必要量、バースト持続時間、ボス出現時刻。これらは仮値として実装し、レビューに実測と変更理由を残す。
