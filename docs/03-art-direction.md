# 03 アート方針

視覚的な基準は [アートボード](../phase03/artboard.svg) にまとめた。外部作品の画像は使用していない。

## ムード
暗い宇宙港と電子回路を思わせる、黒に近い紺の背景。90年代アーケード風の明快なシルエットと発光を使いながら、情報を優先して余白を残す。画面全体を光らせず、危険物・回収物・操作結果に光を集中させる。

## 色と役割
| 役割 | 色 | 用途 |
| --- | --- | --- |
| 背景 | `#090e20`、`#172344` | 空と遠景。低コントラスト |
| 自機／ワイド | `#55e2ef` | 自機、広角弾 |
| フォーカス | `#ffe084` | 集中弾とモード表示 |
| 敵／危険 | `#ff627e` | 敵、敵弾、被弾警告 |
| エネルギー | `#7ef2aa` | 回収物とゲージ |
| 文字 | `#f4f7ff` | 主表示。補助文字は `#a7b5d5` |

敵弾は暖色の円、自弾は寒色または黄色の線、自機は三角の前向きシルエット、回収物はひし形にし、色だけに依存しない。

## 線、質感、動き
- 基準解像度は 960×540、16:9。内部描画を拡大し、整数倍に限定せず画面に収める。
- 2〜3px相当の硬い輪郭、少数の幾何形状、控えめな残光。背景は低速の多層スクロール。
- 撃破は0.2秒程度の閃光と破片、回収は短い吸い込み線、被弾は自機の点滅で示す。
- 光や揺れで敵弾が隠れる場合は演出を弱める。激しい画面揺れは使わない。

## アセット制作規則
- 後続で画像を作る場合、原寸 960×540 を基準に 2倍解像度で制作し、PNGの透過背景を使う。背景画像のみ不透明でよい。
- `player_*`、`enemy_*`、`bullet_*`、`fx_*`、`bg_*` の接頭辞と小文字スネークケースで命名する。
- 同じ役割は上記の色相に合わせ、敵弾の輪郭は背景のどこでも読めるようにする。
- 外部素材を導入する場合は出典・ライセンス・改変条件を記録する。現在のアートボードは自作のSVG図形のみ。
