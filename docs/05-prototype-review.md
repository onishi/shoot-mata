## 確認したこと
- Chrome のローカル開発サーバーでタイトルから開始。Spaceで射撃し、初回の敵を倒してスコア100と緑のエネルギーが出ることを画面で確認。
- Xでワイドからフォーカスへ即時切替。自機とHUDの色が水色から黄色へ変わることを画面で確認。
- Pでポーズし、再開、被弾によるゲームオーバー、RETRYで残機・スコア・モード・時間が初期化されることを画面で確認。
- 起動直後の敵が自機の高さから外れ、最初の射撃が当てにくかった。初回の敵を中央レーンへ変更し、再確認した。
- `npm run build` 成功。ブラウザのコンソールエラーは確認した範囲で0件。
- 状態更新を使う自動操作では、被弾を無効化せず、切替7回・回収28回・バースト6回・被弾1回を経て約45秒でボス撃破に到達。回収とバーストを含む一周がルール上成立することを確認した。これは人がクリアできる証拠ではない。

## プレイから得た感触
- 切替で色と射撃の幅がすぐ変わるため、操作結果は分かる。
- 初期配置の修正後、最初の撃破は数秒で成立し、スコアと回収物が次の行動を示す。
- 無操作では約8秒でゲームオーバーになった。初見の難度として適切かは、継続操作でのプレイから判断する必要がある。
- 回収のために前へ出る操作と、バースト発動をブラウザ上で連続して試せていない。面白さの中心に関する判断は保留。

## 判定と次の作業
