# 08 アルファ・ベータテスト計画と実施記録

## 対象と判定
対象は `phase-08-01/` から始まる独立したMVP版。αでは主要フローと状態の整合、βでは操作性・視認性・負荷・端末差を調べる。合格は「実施した試験で主要フローが成立し、重大な既知不具合が残らない」。試験できない条件は合格扱いにしない。

## αテスト項目
| 項目 | 手段 | 期待結果 | 状態 |
| --- | --- | --- | --- |
| 開始・移動・射撃・切替・回収・バースト | 自動テスト、ブラウザ操作 | 基本ルールが成立 | 自動テスト合格。Chromeで開始と縦画面の切替を操作。射撃・回収・バーストの手動通し操作は未実施 |
| ポーズ・再開・タブ離脱 | 自動テスト、ブラウザ操作 | 中断中に進まず、入力が残らない | 自動テストとChromeのポーズ・再開は合格。真のタブ離脱は未実施 |
| ゲームオーバー・クリア・結果確定 | 自動テスト、ブラウザ操作 | 結果とスコアが確定 | 合格。最後の残機と同時回収を回帰テストで確認。無操作の敗北、8倍速自動プレイのクリアをChromeで確認 |
| 再挑戦・タイトル復帰・繰り返し | 自動テスト、ブラウザ操作 | 状態と操作が初期化される | 自動テストとChromeの再挑戦・タイトル復帰は合格。長時間の繰り返しは未実施 |
| PCと小画面表示 | Chrome画面確認 | ボタンと情報が見切れない | ChromeのPC、390×844、320×568、844×390で目視合格 |

## 不具合管理
`docs/08-bugs.md` に再現手順、期待動作、実際の動作、重大度、修正と再確認結果を残す。重大度は高（主要フローを妨げる）、中（結果や操作に影響）、低（限定条件の表示・演出）とする。

## 2026-10-10 αテスト実施記録
- 対象：`phase-08-01/`、Node.js 24、Chromeのローカル開発サーバー。`npm run typecheck`、17件の`npm test`、`npm run build`が成功した。GitHub Actionsのrun `38058622281` は全ジョブ成功。
- 回帰：QA-001のテストは修正前にスコア250となり失敗、修正後にスコア200・エネルギー0で合格。QA-002のタイトルと見出しはChromeで「STAGE 01」と再確認した。
- Chrome操作：START→ポーズ→再開、ポーズ→再挑戦とタイトル、ゲームオーバー→再挑戦、8倍速自動プレイの166秒クリア→タイトルを確認。縦画面ではSWITCHでFOCUSへ変わり、ポーズ画面のボタンが見切れないことを確認。開発コンソールのエラーは0件。
- 未実施：タブを本当に非表示にする操作は今回のブラウザ環境で再現できなかった。別タブを作っても元ページの `document.hidden` はfalseのままだったため、タブ離脱の合格とは扱わない。実機マルチタッチ、ブラウザ差、高DPI、測定を伴う性能、聴感、有人の約3分プレイも未実施。
- 判定：確認した主要フローに破綻はなく、既知の高重大度不具合は0件。`phase-08-01` のタブ離脱条件は未達であり、フェーズ08は継続する。
