# 09 AIプレイテスト計画

## 目的
約3分のステージをAIが異なる操作方針で繰り返し遊び、進行の詰まり、被弾、回収、武器切替、バーストの使い方を比較して改善する。

## 受け入れ条件
- 少なくとも「生存優先」「撃破優先」「回収優先」の3方針で同じステージを複数回実行し、クリア率、被弾、撃破、回収、バースト回数、所要時間を記録する。
- ブラウザのPC・縦長・横長画面で開始、操作、結果、再挑戦をAIが確認する。
- 差が出た場面を時間と画面状態で特定し、改善を入れた場合は同じ条件で再確認する。
- 自動操縦の成績を人の難度や楽しさの代わりにしない。判定できない主観的な点は報告書に制約として残す。

## 進め方
1. ゲーム状態と操作を分離した既存の自動操縦を使い、方針ごとの入力だけを変える。
2. 同じ時間刻みと乱数条件で複数回走らせ、結果と途中経過を保存する。
3. 被弾や停滞が集中する場面をブラウザで見て、敵配置・UI・操作応答のどれが原因かを調べる。
4. 変更の前後を同じ条件で比較し、`docs/09-playtest-report.md` に根拠と限界を記録する。

物理端末と友人・外部プレイヤーによるチェックは、この計画の必須条件に含めない。
