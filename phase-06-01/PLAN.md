# フェーズ06-01 計画

## 目的
約60秒版の代表的な戦闘を、視覚・音・HUDの品質目標が分かる形にする。

## 受け入れ条件
- フェーズ05の起動→戦闘→結果→再挑戦が維持される。
- 撃破、回収、被弾、バーストの反応を色だけに頼らず区別できる。
- 音はユーザー操作後にのみ鳴り、OFFでも遊びの情報が残る。
- 自動再生と手動操作をブラウザで確認し、負荷・視認性・制作上の課題を記録する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。Chromeのスクリーンショットと、通常・自動再生の結果を確認する。
