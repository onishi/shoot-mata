# フェーズ08-02 βテスト計画

## 目的
高DPI・画面サイズ変更時の視認性と描画品質を改善し、操作・負荷・端末差の実測結果を残す。

## 受け入れ条件
- `phase-08-01/` と独立して起動・ビルドできる。
- 内部座標960×540を維持したまま、Canvasの実ピクセル数が表示寸法とDPRに追従する。
- PC、縦横の小画面でUIとゲーム画面が見切れず、主要操作が使える。
- 型チェック、テスト、ビルド、ブラウザ確認を行い、測定・未実施項目を分けて記録する。

`npm run typecheck`、`npm test`、`npm run build`。ChromeのPC・縦横小画面でCanvasの実ピクセル数を読み、操作・見切れ・コンソールエラーを確認する。

進行中。高DPIと画面変更後のCanvas解像度を修正し、ChromeのDPR 1・2、PC・縦横小画面、2回のクリアで確認した。JavaScript処理時間を測定したが、実機、別ブラウザ、入力遅延、聴感は未実施。
