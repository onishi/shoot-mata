# フェーズ08-04 ページ離脱時の入力・進行テスト計画

## 目的
ページ離脱後にゲームが進まず、復帰時に押下入力が残らない状態を確保する。

## 受け入れ条件
- `phase-08-03/` と独立して起動・ビルドできる。
- `blur`、`visibilitychange`、`pagehide` による中断を同じ手順で扱い、プレイ中なら自動ポーズする。
- 中断時にキーボードとタッチ入力を解除し、復帰は明示的な操作を要する。
- ローカルの型チェック・テスト・ビルド、ブラウザ操作、CI結果を記録する。

## タスク
1. [x] 08-03から独立した成果物を作り、受け入れ条件を記録する。
2. [x] ページ離脱経路を統合し、押下状態を安全に解除する。
3. [x] ブラウザで離脱・復帰を操作確認する。
4. [ ] 型チェック・テスト・ビルド・CIとQA記録を更新する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。Chromeで開始、ページ離脱、復帰後のポーズと再開を確認する。

## 判定
進行中。Chromeで開始→別ページへ移動→戻るとPAUSEDと復帰案内が表示され、RESUME後に時間進行を確認。タッチの保持ポインター解除と入力初期化は回帰テストで確認。実際にキーや画面を押し続けたままのページ離脱、物理端末での挙動は未確認。
