# フェーズ08-08 繰り返しプレイの安定性テスト計画

## 目的
結果からの再挑戦やタイトル復帰を繰り返しても、前のプレイ状態を持ち越さず約3分のステージを完走できることを確認する。

## 受け入れ条件
- `phase-08-07/` と独立して起動・ビルドできる。
- 開発用自動操縦で10回以上連続してクリアし、各回の時刻・スコア・撃破数・被弾数が一致する。
- 結果→再挑戦、結果→タイトル→開始、途中ポーズ→再開を含め、次のプレイで前回の状態が残らない。
- Chromeの画面操作、ローカルの型チェック・テスト・ビルド、CI結果と未確認事項を記録する。

1. [x] 08-07から独立した成果物を作り、受け入れ条件を記録する。
2. [x] 複数回の完走と状態初期化を回帰テストへ追加する。
3. [x] Chromeで結果からの再挑戦とタイトル復帰を確認する。
4. [ ] 型チェック・テスト・ビルド・CIとQA記録を更新する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。Nodeのテストで開発用操縦の全フレームを進める。Chromeでは開発用 `?autoplay=1&speed=8` を使って画面遷移を操作する。

## 判定
進行中。自動操縦10回は約166.08秒・スコア23400・撃破125・被弾0で一致した。Chromeの8倍速自動プレイで初回、RETRY後、TITLE→START後の3回とも同じ結果表示を確認し、コンソールエラーは0件。ローカルの型チェック・23件のテスト・ビルドは成功。自動操縦は人の操作感・難度・長時間の画面表示性能を評価しない。
