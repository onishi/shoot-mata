# フェーズ08-09 ボタンのキーボード操作テスト計画

## 目的
キーボードでフォーカスしたボタンをSpaceで操作できるようにし、ゲームの射撃入力と衝突しないことを確認する。

## 受け入れ条件
- `phase-08-08/` と独立して起動・ビルドできる。
- START、PAUSEDの操作、結果画面の操作、SOUNDをキーボードから実行できる。
- ボタンにフォーカスがあるSpace入力は射撃として扱わず、通常のプレイ中のSpace射撃は維持する。
- ローカルの型チェック・テスト・ビルド、ブラウザ操作、CI結果を記録する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。ChromeでSTARTにフォーカスしてSpaceを押す。ポーズ・結果・SOUNDボタンでもSpace/Enterを確認し、プレイ中の射撃を確認する。
