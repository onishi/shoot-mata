# フェーズ08-13 切替直後のモード表示テスト計画

## 目的
武器切替の直後に現在モードを自機付近へ短く表示し、操作結果を分かりやすくする。

## 受け入れ条件
- `phase-08-12/` と独立して起動・ビルドできる。
- 切替イベントに新しいモードが含まれ、WIDE／FOCUSに応じたラベルが表示される。
- 連続切替で古いラベルが残らず、一定時間で消える。
- 型チェック・テスト・ビルド、ブラウザ表示、CIと未確認条件を記録する。

## タスク
1. [x] 08-12から独立した成果物を作り、受け入れ条件を記録する。
2. [x] 切替イベントと短いラベル演出を実装・検証する。
3. [x] ブラウザで切替前後の画面を確認する。
4. [ ] 型チェック・テスト・ビルド・CIとQA記録を更新する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。SafariでXを押し、FOCUS／WIDEの表示をスクリーンショットで確認する。連続切替と時間経過による消滅は回帰テストで確認する。
