# フェーズ11-01 公開準備計画

## 目的
`phase-10-02/` を独立した公開版として保存し、GitHub Pagesへ安全に配信できる成果物と自動デプロイ手順を用意する。

## 受け入れ条件
- ゲーム進行と操作を変えず、公開版の説明・版表記・共有導線を追加する。
- OGP画像、favicon、description、canonical URL、第三者通知が本番ビルドに含まれる。
- `/shoot-mata/` のサブパスでHTML、CSS、JavaScript、画像、iconを参照できる。
- Node.js 24で型チェック・テスト・方針比較・本番ビルドが成功する。
- GitHub Pagesのデプロイ、ロールバック、キャッシュ更新、データ取扱いを文書化する。

## タスク
1. [x] 10-02から公開版を独立させ、公開用メタデータとアセットを追加する。
2. [x] Web Share APIとクリップボード代替を使う共有導線と回帰テストを追加する。
3. [x] 相対ベースパスとGitHub Pagesデプロイワークフローを実装する。
4. [x] ローカル確認と文書更新を行う。

## 確認方法
`npm ci`、`npm run typecheck`、`npm test`、`npm run playtest`、`npm run build` を実行する。`dist/` 内の参照が相対パスであること、OGP画像が1200×630であること、第三者通知を含むことを確認する。ローカルの本番プレビューでタイトル、共有、開始、結果、再挑戦を操作する。

## 判定
公開準備の受け入れ条件を満たした。ローカルの本番ビルドとPC・縦長ブラウザ確認は合格。フェーズ11はGitHub Pagesの有効化、デプロイ、本番URL確認へ進む。
