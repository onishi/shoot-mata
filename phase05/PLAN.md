# フェーズ05 計画

## 目的
仮図形で約60秒のコアループを作り、実プレイで面白さを評価する。

## 受け入れ条件
- タイトル→プレイ→クリア／ゲームオーバー→リトライを繰り返せる。
- 移動、射撃、ワイド／フォーカス切替、敵、被弾、回収、バーストが動く。
- 実プレイで良い瞬間と分かりにくい瞬間を記録し、継続／仕様変更等を判定する。

## タスク
1. [x] Vite・TypeScript基盤と空のゲーム画面を作る。
2. [x] 移動、射撃、敵、衝突、結果・リトライを作る。
3. [x] 切替、回収、バーストを作る。
4. [x] ビルド・テスト・ブラウザ操作で確認し、レビューを書く。
5. [x] 回収・バースト・ボスまで自動操作で連続プレイし、ブラウザ描画を確認する。人の連続プレイは後続の検証項目に残す。

## 確認方法
`npm run build`、`npm run typecheck`、`npm test`。ブラウザで一周を遊び、リトライする。

## 結果
受け入れ条件を満たした。ブラウザで基本フローを操作し、自動操作で切替・回収・バースト・ボス撃破を含む一周とクリア画面を確認した。判定は「継続」。人の連続プレイ評価は後続の検証項目に残す。
