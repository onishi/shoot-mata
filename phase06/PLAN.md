# フェーズ06 計画

## 目的
代表的な戦闘区間を完成品質に近づけ、残りの制作手順とコストを確かめる。フェーズ05の仮素材版は保存する。

## 完了条件
- 本番を想定した視覚・音・UIの方向性が短いプレイで確認できる。
- PCとスマートフォンで操作でき、入力遅延、テンポ、視認性、負荷の課題を記録する。
- 再利用できる制作手順と残りの作業見積もりを `docs/06-vertical-slice-review.md` に残す。

## スライス
1. [ ] `phase-06-01`：デスクトップの代表区間。撃破・回収・バーストの演出、短い音、HUDを整える。
2. [ ] `phase-06-02`：タッチ操作と縦持ち／横持ちの画面調整。前の成果物を残して別ディレクトリにする。
3. [ ] 両スライスのブラウザ確認と受け入れ判定。

## 確認方法
各スライスで `npm run typecheck`、`npm test`、`npm run build`。Chromeで通常操作と開発用自動再生を確認し、見た目はスクリーンショットで評価する。
