# フェーズ07 本開発計画

## 目的
バーティカルスライスを基に、約3分の1ステージをタイトルから結果・再挑戦まで遊べるMVPへ育てる。

## 完了条件
- `docs/02-mvp.md` の必須機能が1ステージでつながり、PCとタッチで操作できる。
- 各スライスを独立したディレクトリに残し、型チェック・テスト・ビルド・ブラウザで確認する。
- 本番想定の絵、音、UI、難度を見直し、残る検証課題を `docs/07-implementation-status.md` に記録する。

## スライス
1. [x] `phase-07-01`：既存の1分版を約3分の1ステージへ拡張し、敵配置とボスまでを通して遊べるようにする。
2. [ ] `phase-07-02`：結果・ポーズ・設定の導線と画面演出をMVP仕様に合わせて整える。
3. [ ] 両スライスの受け入れ判定と、次のQAへ渡す課題の整理。

## 確認方法
各スライスで型チェック、テスト、ビルドを実行する。開発用自動プレイでクリアを確認し、ブラウザで通常操作・結果・再挑戦、PCと小画面の表示を確認する。
