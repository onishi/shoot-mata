# 02 MVP 範囲と受け入れ条件

## MVP
1ステージ、約3分のプレイ。タイトルから結果・再挑戦まで、キーボードとタッチで遊べる。軽量機、耐久機、ボスを含む。ワイド／フォーカス切替、エネルギー回収、バースト、スコア、残機、ポーズ、音のON/OFFがある。仮素材で成立を確認してから本番の見た目と音を整える。

## プレイヤー視点の受け入れ条件

| 機能 | 条件 |
| --- | --- |
| 開始と操作説明 | 初見でタイトルから開始でき、移動・射撃・切替・バーストを画面内で確認できる |
| 移動と射撃 | 押した方向へ動き、画面外に出ず、射撃中も移動できる |
| 武器切替 | 入力後すぐ弾の形と移動速度が変わり、現在モードが読める |
| 戦闘 | 敵を倒せる。敵弾・接触で被弾し、短時間の無敵状態が見て分かる |
| 回収とバースト | 倒した敵のエネルギーを拾うとゲージが増え、満タン時に任意で発動できる |
| 進行と終了 | 敵配置の変化を経てボスが現れ、撃破でクリア、残機0でゲームオーバーになる |
| 結果とリトライ | 結果にスコア等が出て、再挑戦すると最初から正常に遊べる |
| ポーズと音 | ポーズ中はゲームが進まず、音を切れる。タブを離れても安全に止まる |
| 画面サイズ | PCと縦持ちスマートフォンで主要UIが見切れず、操作できる |

## 後回し
- 追加ステージ、ルート分岐、複数のボス。
- 武器追加、複雑な強化、ストーリー、ランキング、クラウド保存。
- アクセス解析とアカウント機能。

## プロトタイプの縮小範囲
フェーズ05はキーボードで約60秒の一周をまず成立させる。図形描画、軽量機・耐久機、単純な終盤の大型敵、切替、回収、バースト、結果・リトライまでを対象にする。タッチ、音、設定、完成アートは後続フェーズ。ここでの検収は面白さの観察であり、MVP機能完了ではない。
