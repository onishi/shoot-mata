## 07-02 MVP画面フロー（2026-10-10）

### 実装と確認
`phase-07-01/` を残して `phase-07-02/` を独立させた。タイトル→開始→プレイ→ポーズ→再開・再挑戦・タイトル、およびクリア／ゲームオーバー→再挑戦・タイトルの操作を揃えた。ポーズ中は進行を止め、再開では時間とスコアを保持する。再挑戦とタイトル復帰ではゲーム状態、演出、押下中の入力を初期化する。スマートフォンではタイトル・結果で不要なポーズボタンを隠す。音のON/OFFは全画面で使えるヘッダーに残した。

Node 24で型チェック、16件のテスト、ビルドが成功。画面遷移の許可範囲、ポーズ中の停止、再開時の保持、結果・再挑戦時の初期化をテストした。ChromeでPC幅、320×568・390×844の縦持ち、844×390の横持ちをスクリーンショット確認。ポーズから再挑戦・タイトル、ゲームオーバーからタイトル、クリアからタイトルを操作した。開発用8倍速自動プレイは166秒・スコア23400・撃破125・被弾0でクリア。ポーズ中とタイトルで音のON/OFFが切り替わり、ブラウザのコンソールエラーは0件だった。CIに07-02を追加した。

### MVPとフェーズ07の判定
**フェーズ07完了。** 約3分の1ステージ、軽量機・耐久機・ボス、2種類の射撃、回収とバースト、残機・スコア、キーボード・タッチ、ポーズ、音のON/OFF、結果・再挑戦・タイトル復帰がつながった。MVPに必要な設定は音のON/OFFだけなので、独立した設定画面は設けず、常に押せるヘッダーボタンを設定操作とした。アートと音は自作のCanvas図形とWeb Audio合成音を使う。
