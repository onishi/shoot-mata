# フェーズ08-05 入力応答計測計画

## 目的
キーボードとタッチの入力イベントから次のCanvas描画処理までの時間を開発環境で計測する。

## 受け入れ条件
- `phase-08-04/` と独立して起動・ビルドできる。
- 開発用 `?profile=1` だけでキーボードとタッチの入力応答を記録し、Canvasから集計値を読める。
- 計測対象と上限を明記し、描画表示や物理端末の遅延と混同しない。
- ローカルの型チェック・テスト・ビルド、ブラウザ操作、CI結果を記録する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。Chromeで `?profile=1` の入力を操作し、Canvasの `data-input-frame-profile` を読む。

## 判定
完了。Chromeの `?profile=1` でキーボードのX入力後は2イベントの平均4.75ms、95パーセンタイル5.4ms。縦画面でSWITCHとFIREを加えた5イベントでは平均5.52ms、95パーセンタイル6.8ms。ローカルとGitHub Actions run `38188121806` で型チェック・20件のテスト・ビルドに合格。これらは入力イベントから次のCanvas描画処理までの当該環境の少数サンプルであり、画面表示や物理端末の入力遅延を示さない。
