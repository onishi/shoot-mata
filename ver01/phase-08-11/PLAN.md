# フェーズ08-11 ポインターキャプチャ喪失テスト計画

## 目的
タッチ操作中にポインターキャプチャが予期せず失われても、移動と射撃の押下状態を残さない。

## 受け入れ条件
- `phase-08-10/` と独立して起動・ビルドできる。
- スティックとFIREのキャプチャ喪失時に各入力が解除される。
- キーボードとポインターの同時FIREでは、ポインター側だけを解除する。
- 型チェック、テスト、ビルドとブラウザの主要フローを確認し、未実施条件を記録する。

## 確認方法
`npm run typecheck`、`npm test`、`npm run build`。模擬 `lostpointercapture` イベントで入力と押下表示を確認し、ブラウザで開始からゲームオーバー・再挑戦を操作する。

08-11の受け入れ条件を満たして完了。`lostpointercapture` を模擬した回帰テストは修正前に失敗、修正後に成功。該当ポインターの移動・射撃だけを解除し、同時に押しているキーボードFIREは維持する。ローカルとGitHub Actions run `38349710079` で型チェック・26件のテスト・ビルドが成功。Safariで開始・無操作の敗北・再挑戦を確認。実ブラウザでのキャプチャ喪失、押下中のタブ離脱、物理端末は未確認。
