# フェーズ10-01 リリース候補監査計画

## 目的
`phase-09-02/` を独立したリリース候補として保存し、MVPへの対応、成果物の構成、権利、データ取扱い、依存関係を監査する。

## 受け入れ条件
- `phase-09-02/` と独立して起動・テスト・ビルドできる。
- `docs/02-mvp.md` の各条件に、実装または既存の確認記録を対応付ける。
- 素材・フォント・音、外部通信・保存・個人データ、依存ライセンスと脆弱性を確認する。
- 確認済みの事実、未実施項目、次の最終ブラウザ確認を `docs/10-acceptance.md` に分けて残す。

## タスク
1. [x] 09-02から独立したリリース候補を作る。
2. [x] MVP条件と既存のQA・プレイテスト証拠を対応付ける。
3. [x] ソース、ビルド成果物、ロックファイルから権利・通信・保存・依存関係を監査する。
4. [x] 型チェック・テスト・方針比較・ビルドを実行し、検収記録の初稿を作る。

## 確認方法
Node.js 24で `npm ci`、`npm run typecheck`、`npm test`、`npm run playtest`、`npm run build`、`npm audit` を実行する。ソースと `dist/` から外部URL、通信・保存API、外部アセット参照を検索し、`package-lock.json` のライセンス表記を確認する。

## 判定
10-01の監査条件を満たした。ゲームのルールと通常操作は09-02から変更していない。フェーズ10全体の公開可否は、10-02の最終ブラウザ確認後に判定する。
