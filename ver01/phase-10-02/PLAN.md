# フェーズ10-02 最終ブラウザ確認計画

## 目的
`phase-10-01/` を変更しない独立したリリース候補として、主要フロー、画面変更、中断、音声操作、繰り返し再挑戦を最終確認する。

## 受け入れ条件
- PC、縦長、横長の各画面で開始、武器切替、バースト、ポーズ・再開、結果、再挑戦が成立する。
- リサイズ後もレイアウト・Canvas解像度・操作状態に致命的な問題がない。
- 音声ON/OFF、フォーカス喪失からの自動ポーズと明示再開が成立する。
- 連続プレイと状態初期化で多重進行や既知の高・中重大度不具合が見つからない。
- 型チェック・テスト・方針比較・本番ビルドが成功し、結果と制約を検収記録へ残す。

## 確認方法
Node.js 24で `npm ci`、`npm run typecheck`、`npm test`、`npm run playtest`、`npm run build` を実行する。ブラウザでは `?qa=burst-ready&safearea=1` と通常の開始状態を使い、PC・縦長・横長で状態遷移、横スクロール、コンソールエラーを確認する。

## 判定
ローカルの受け入れ条件を満たした。PC・縦長・横長の主要フロー、リサイズ、音声、状態初期化を確認し、コンソール警告・エラーは0件だった。CIの成功確認後にフェーズ10全体を判定する。
