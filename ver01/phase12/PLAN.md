# フェーズ12 運用・アップデート計画

## 目的
公開版の可用性、配信内容、依存関係、改善候補を、個人データを追加収集せずに継続管理する。

## 完了条件
- 公開URLと必須アセットを再現可能な方法で定期確認できる。
- パフォーマンスと配信容量の基準値、依存関係、権利条件の確認日を記録できる。
- 不具合、保守、改善、新機能を分け、次の作業候補に優先順位と根拠がある。
- 更新時に既存のテスト、ビルド、公開確認、ロールバック手順を維持する。

## スライス
1. [x] `12-01`：本番スモークチェック、公開後の基準値、定期実行、運用記録を追加する。
2. [x] `12-02`：依存更新候補を互換性と影響範囲で分類し、Vite 7.3.7へのパッチ更新を独立して検証する。
3. [x] `12-03`：本番チェックとバックログの初回見直しを行い、再現可能な不具合と根拠のある改善を優先する運用を確定する。

## 収集方針
ゲーム内解析、Cookie、識別子、プレイ履歴は追加しない。GitHub Actionsから公開ファイルを取得し、HTTP状態、同一オリジン、内容、容量、応答時間だけを確認する。応答時間は共有基盤とネットワークで変動するため記録値とし、固定の失敗条件にはしない。

## 判定
完了。公開監視、初回の運用レビュー、依存監査、権利通知、バックログ分類、Viteパッチ更新を確認した。重大な既知不具合は0件。Vite 8・TypeScript 7は必要性と互換性を確認するまで適用しない。全開発フェーズは完了し、以後は定期点検と根拠のある改善を継続運用として扱う。
