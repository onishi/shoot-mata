# 04 アセット制作パイプライン

状態: Phase 04完了時ベースライン（2026-10-21）

## 目的と台帳単位

`phases/phase-04/asset-production-plan.json`を、Phase 06・07で必須素材を不足なく制作するための機械可読な下限表とする。1制作単位は、個別に状態と証拠を追えるビジュアル、アニメーション集合、UI画面、音イベントまたは音楽レイヤーであり、PNG枚数やアニメーションのフレーム数とは一致しない。

現時点の下限は125制作単位である。内訳はステージ固有56、3武器×3段階の弾・命中18、共通ビジュアル37、共通音イベント14。アニメーションフレーム、レスポンシブ書出し、圧縮配信形式、ローカライズ差分は含まない。Phase 06で第1面を完成した後に実測工数とファイル数で再見積りし、必須範囲を減らさずPhase 07計画へ反映する。

## 命名と配置

- 小文字英数字とハイフンだけを使い、末尾を`-v{整数}.{拡張子}`にする。
- ステージ固有物は`stage-0N-{舞台}-{役割}-vN`、武器は`weapon-{系統}-{段階またはイベント}-vN`、共通物は`player-`、`core-`、`ui-`、`vfx-`から始める。
- 編集元、生成プロンプト、生成コード、書出し物を混同せず、ゲーム投入物だけを`assets/game/`または`assets/audio/`へ置く。
- 同じ論理素材の置換は版番号を上げる。ファイルを上書きした場合もSHA-256と編集履歴を更新する。

## 制作から検証まで

1. `asset-production-plan.json`の制作単位を台帳へ`planned`で追加し、要件ID、用途、担当フェーズを結ぶ。
2. 構想画像・試作音を`draft`として作り、完全なプロンプトまたは生成コード、外部素材の出典と許諾を保存する。
3. 画像を背景・主体・状態へ分離し、必要な透過、余白、基準座標で書き出す。音は48kHz mono PCM16 WAVを検査用マスターにする。
4. PNGヘッダー、寸法、alpha、SHA-256、色非依存差、背景輪郭密度を検査する。音は形式、ピーク、クリップ、無音余白、ループ端、SHA-256を検査する。
5. PC、320px縦長、390px縦長、844×390横長でゲーム座標へ合成し、欠落、横溢れ、HUD遮蔽、44px操作、consoleを確認する。ここまででゲーム投入可能なら`final`にする。
6. ゲーム本体で状態遷移、入力、音量・ミュート、複数同時表示、性能、権利を確認した素材だけを`verified`にする。分離素材や参照ページだけでは`verified`にしない。

## ステージ別の下限

各ステージは遠景・中景・前景、通常敵3種以上、固有仕掛け、ボス、リズム・旋律・危機の音楽3層、導入・クリア演出を持つ。第4面ボスは3形態を個別状態として追う。武器はランス、スプレッド、シーカーそれぞれLv1〜3について弾と命中表現を別制作単位にする。

UIはタイトル、導入、チュートリアル、設定、ステージ選択、HUD、ポーズ、結果、コンティニュー、エンディング、クレジットの11画面を下限とする。VFXは攻撃、命中、被弾、撃破、回収、武器成長、警告、ボス登場、クリアを下限とする。

## Phase 06実績による再見積り

第1面の製品経路までで46/125制作単位相当を接続し、最低79単位が残る。内訳は第2面15、第3面13、第4面15、第1面残4、武器別命中9、共通ビジュアル15、共通音8である。旧集計の123/77は第2面のboss 3形態を1形態として数えた誤りで、2026-10-22に制作範囲を減らさず訂正した。

第1面固有assetは10,174,611 bytes、共有assetは5,775,992 bytesとなり、現build 16,086,103 bytesのままでは残り3面を追加できない。Phase 07の制作前に配信形式と寸法を再設計し、各面2.25 MiB以下、共有asset・コード等7 MiB以下を一次予算とする。16 MiBの製品上限、完成アート、背景3層、敵3種、ボス、音を削減対象にはしない。

Phase 07では制作原本PNGを保持し、背景を1280×720のlossy WebP、自機・敵・boss・コアを表示上限より大きい縮小lossless WebPとして配信する工程を採用した。`npm run assets:optimize` は同じ設定で11画像を生成し、復号後のRGB PSNRとalpha差、byte数、SHA-256を `assets/delivery/asset-optimization-audit.json` へ記録する。背景はPSNR 33.373 dB以上、alpha最大差0、actorとコアはRGB・alphaとも復号画素差0。第1面配信assetは音込み1,577,842 bytes、共有assetは音込み392,888 bytes、静的build全体は2,106,350 bytesとなり、面別2.25 MiB、共有7 MiB、全体16 MiBの自動上限に合格した。
