# プレイヤーガイド

状態: v2.0.0（build ID `phase10-rc1-20261024`）時点の内容（2026-10-26）

## はじめに

敵から奪った3色のリアクターコアを取得順に装填し、武器を組み替えながら4つのステージを突破する横スクロールシューティング。

- プレイURL: https://onishi.github.io/shoot-mata/game/public/
- ルートの `https://onishi.github.io/shoot-mata/` は旧版ver01の展示であり、v02ではない。

## 操作

| 動作 | キーボード | タッチ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | MOVEパッドを指でなぞる |
| 射撃 | Z / Space（押しっぱなし） | FIREボタン |
| 決定 | Enter | 画面のボタン |
| 戻る | Esc | 画面のボタン |
| ポーズ | P | PAUSEボタン |

フルスクリーンは画面上部のボタンから任意で開始できる。使わなくても全機能で遊べる。

## 三連装リアクター

- コアは赤・青・黄の3色。色に加えて形と記号でも見分けられる。
- 取得したコアは3つの枠へ古い順に並ぶ。4個目を取ると最も古い1個が押し出される。
- 先頭のコアの色が主武器を決める。
- 先頭と同じ色の数（1〜3個）が武器レベル（Lv1〜3）を決める。

### 主武器

| 色 | 武器 | 得意なこと | レベルが上がると |
| --- | --- | --- | --- |
| 赤 | LANCE | 正面への直射。硬い敵やボスを素早く倒す | 威力が上がり、貫通する数が増える |
| 青 | SPREAD | 広がる射線。敵の群れを制圧する | 弾数が増える（3→5→7発） |
| 黄 | SEEKER | 追尾弾。照準を捨てて回避に集中できる | 追尾弾の数が増える（1→2→3発） |

### 補助効果

先頭と異なる色のコアは補助効果を与える。

| 混ざっている色 | 効果 |
| --- | --- |
| 赤 | 弾の貫通+1 |
| 青 | 被弾後の無敵時間が延びる |
| 黄 | コアを拾える範囲が広がる |

単色Lv3の火力を保つか、混色にして補助効果を得るかが本作の中心となる判断になる。欲しいコアを取りに行くことは、危険な位置へ寄ることでもある。HUDには3つの枠、主武器とレベル、次に押し出されるコアが表示される。

## 被弾と残機

- 被弾すると先頭のコアを1つ失う。その被弾ではミスにならない。
- コアが1つもない状態で被弾すると、残機が1つ減る。
- 開始時は残機3、コアは赤1個。
- ゲームオーバー時はすぐに同じステージへ再挑戦できる。キャンペーンではコンティニューも選べる。

## ステージ

| # | 舞台 | 特徴 | ボス |
| --- | --- | --- | --- |
| 1 | 軌道残骸帯 | 狭い残骸回廊と開けた迎撃域が交互に来る | 残骸を盾に向きを変える解体艦 |
| 2 | 雲海精製塔 | 上下の気流、開閉する遮蔽、帯電域 | 塔を登降する精製守護機 |
| 3 | 生体方舟 | 攻撃で開閉する組織、増殖源、収縮する通路 | 部位で弱点が変わる中枢体 |
| 4 | 恒星炉心 | 周期的な熱波、退避域、破壊で変わる安全圏 | 3形態を持つ炉心制御機 |

キャンペーンでは4ステージを通してエンディングとクレジットまで進む。クリアしたステージはステージ選択から単独で遊べるようになる。

## スコア

| 項目 | 得点 |
| --- | --- |
| 敵の撃破 | 敵ごとの得点 |
| コアの取得 | 1個につき75 |
| 連続撃破 | 3体目以降、撃破ごとに連続数×25 |
| 無被弾クリア | ステージを被弾0でクリアすると1000 |

結果画面で内訳を確認できる。ベストスコアとクリア状態はステージ別・難易度別にブラウザへ保存される。

## 設定

### 難易度

| 項目 | 標準 | アシスト |
| --- | --- | --- |
| 残機 | 3 | 4 |
| 開始コア | 赤1個（Lv1） | 赤2個（Lv2） |
| 敵弾の速さ | 100% | 75% |
| 無敵時間 | 1倍 | 1.5倍 |
| コアを拾える範囲 | 1倍 | 1.25倍 |

### 表示と音

- 表示: 動き軽減、明滅軽減、高コントラスト
- 音: BGMと効果音の音量とミュート。音はSTART操作の後に鳴り始め、無音でも最後まで遊べる。

## 攻略のヒント

- 序盤は赤を3個そろえ、正面の敵を素早く倒す感覚に慣れる。
- 敵が群れで来る区間では、先頭を青へ入れ替えると楽になる。
- 被弾するとコアが減るため、青を混ぜて無敵時間を延ばすのは保険として有効。
- 4個目を取る前に、どのコアが押し出されるかをHUDで確認する。
