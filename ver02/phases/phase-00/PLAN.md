# Phase 00 plan — 旧版の反省と再調査

状態: 完了（2026-10-19）

## 目的

ver01を改修案としてではなく失敗事例として監査し、v02が同じ完成誤判定を起こさないための判断基準を作る。横スクロールシューティングの魅力と、ブラウザで完成品を作る際の制約を一次情報で再調査する。

## 対象

- ver01の企画、MVP、レビュー、検収、バックログ、作業ログ
- 横スクロールシューティングの代表的な武器成長、攻防転換、ステージ分岐
- 音声、描画ループ、タッチ、保存、フルスクリーン、アクセシビリティのブラウザ制約
- Phase 01で比較する独自性の仮説

## 対象外

- ver01のコード、素材、設定のコピーまたは改修
- コンセプトの最終決定
- 技術スタックの決定、ゲームコード、完成アートの制作
- 製品要件の確定

## 完了条件

- [x] 失敗原因が成果物の記録を根拠に説明されている
- [x] 各原因に再発防止策と、後続フェーズで確認できるゲートがある
- [x] 参考作品から学ぶ構造と、複製しない表層が分けられている
- [x] ブラウザ制約が設計への影響とともに整理されている
- [x] Phase 01で比較する3つ以上の仮説と評価軸がある
- [x] 必須文書の置き場所と状態が作られている

## 確認方法

1. `ver01/docs/` の主張を引用箇所まで追跡する。
2. 外部調査は公式サイト、プラットフォーム提供者、MDN、W3Cを優先する。
3. `00-lessons.md` の各対策をREADMEのフェーズまたは必須ゲートへ対応付ける。
4. `git diff --check` と文書リンクの機械検査を行う。
