# Phase 01 plan — コンセプト

状態: 完了（2026-10-19）

## 目的

Phase 00で作った3つの仮説を同じ基準で比較し、完成製品の設計を拘束できる一文コンセプトを1案だけ選ぶ。対象プレイヤー、感情的ゴール、プレイヤーの判断、習熟、反復理由を説明可能にする。

## 対象

- 三連装リアクター、位相航路、漂流兵装群の具体化と比較
- 90年代アーケードシューティングらしさと本作固有の新しさの分離
- 4ステージ、3武器系統×3段階、キーボード・タッチへの展開可能性
- Phase 02の製品要件とPhase 03の試作へ渡す仮説・反証条件

## 対象外

- 操作可能な試作と面白さの実証（Phase 03）
- 製品要件、画面一覧、ステージ詳細の確定（Phase 02）
- 技術スタック、完成アート、音の決定
- 候補案の要素を無検証で採用案へ混合すること

## 完了条件

- [x] 3案が対象プレイヤー、判断、習熟、反復性、4ステージ展開、入力負荷、独自性、制作リスクで比較されている
- [x] 採用案と不採用理由が記録されている
- [x] 対象プレイヤー、感情的ゴール、90年代らしさ、本作固有の新しさが定義されている
- [x] プレイヤーが何を判断し、何に熟達し、なぜ繰り返すかを説明できる
- [x] 一文コンセプトと、後続フェーズで棄却できる反証条件がある

## 確認方法

1. READMEの4ステージ、3武器系統×3段階、完成品質、入力要件を比較表へ対応させる。
2. 各候補を同じ8評価軸・5段階で採点し、点数だけでなく根拠と致命的リスクを記録する。
3. 採用案について、10秒、1分、1プレイ、複数プレイの時間幅で判断と習熟を説明する。
4. `git diff --check` とMarkdownリンク検査を行う。
