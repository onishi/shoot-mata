# Phase 02 plan — 製品要件と受け入れ条件

状態: 完了（2026-10-19）

## 目的

READMEの必須要件を縮小せず、選定した「三連装リアクター」を4ステージ以上の完成製品として定義する。全必須項目に実装フェーズ、検証方法、必要な証拠を割り当て、MVPを製品完成と誤認できない構造にする。

## 対象

- プレイヤー体験、ゲームループ、パワーアップ、4ステージ、進行、画面、操作、音、保存、アクセシビリティ
- 完成アート、性能、ブラウザ対応、権利、データ取扱い、公開・復旧
- 内部MVPの範囲と、MVPに含まれない必須製品要件
- READMEの最終完成チェックと製品要件の受け入れマトリクス
- Phase 02で判断するとしたバックログ3件

## 対象外

- 武器数値、敵配置、ステージ秒数の最終調整
- 技術スタックと実装方式の決定
- 操作可能な試作、完成アート、ゲームコード
- 主観的な面白さや操作感の合格判定

## 完了条件

- [x] READMEの全必須要件が製品要件に保たれている
- [x] 4ステージが背景、仕掛け、敵編成、ボス、コア判断の差を持つ
- [x] 3武器系統×3段階と、取得順による選択・トレードオフが定義されている
- [x] タイトルからエンディング・再挑戦までの画面と状態遷移が定義されている
- [x] キーボード、タッチ、PC、縦長・横長スマートフォンの条件がある
- [x] 全必須要件に実装フェーズ、検証方法、証拠が割り当てられている
- [x] 内部MVPと製品完成が明確に分離されている

## 確認方法

1. READMEの製品目標、検証最低条件、最終完成チェックを受け入れマトリクスへ逆引きする。
2. 製品要件IDが受け入れマトリクスに欠落・重複していないことを機械的に確認する。
3. 各行に実装フェーズ、検証種別、必要証拠、現在状態があることを確認する。
4. `git diff --check` とMarkdownリンク検査を行う。
