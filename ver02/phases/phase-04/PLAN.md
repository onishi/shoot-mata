# Phase 04 plan — アート・音・UX設計

状態: 進行中（2026-10-21）

## 目的

Phase 03で確定したFIFO三連装を、4ステージへ一貫して展開できる造形、色、質感、動き、VFX、UI、音の制作規則へ変換する。代表シーンと分離アセットを実際のゲーム表示条件へ置き、後続制作が同じ客観基準で合否判定できる状態にする。

人間による主観評価はユーザー指示により進行ゲートへ使わない。美しさ、懐かしさ、迫力、聴感は未評価とし、仕様照合、画像寸法、コントラスト、色非依存識別、遮蔽率、アセット欠落、音量ピークなど再現可能な検査で進める。

## 対象

- 自機、3コア、代表敵、軌道残骸帯背景、HUD、攻撃・被弾・回収VFXの代表素材
- 4ステージへ展開可能な色、形、材質、レイヤー、アニメーション規則
- BGM・効果音の役割、ループ、音量、権利、書出し規則
- PC、320〜390px縦長、スマートフォン横長の代表ゲーム画面
- 作成者、方法、プロンプト、権利、ハッシュ、状態を持つアセット台帳

## 対象外

- 全4ステージ分の完成素材量産
- ゲーム本体の描画・音声基盤
- 人間の好み、楽しさ、操作感、聴感による合否
- 生成された一枚絵をそのままゲーム背景や製品アセットへ転用すること

- [x] 最終品質の方向を示す16:9代表ビジュアルがあり、生成方法、プロンプト、寸法、ハッシュ、権利状態を追跡できる
- [x] 自機、代表敵、背景レイヤー、コア、HUD、VFXをゲーム用に分離した素材またはコード表現がある
- [x] 代表シーンをゲーム座標で合成し、基本図形だけの仮表示がない
- [x] 3コア、敵弾、敵、背景、味方弾を色以外の形・明度・輪郭でも機械判別できる
- [x] PC、320〜390px縦長、スマートフォン横長でHUD遮蔽率、文字寸法、44px操作対象、横溢れを検査する
- [x] 動き軽減と高コントラスト設定で重要情報が欠落しない
- [ ] 音の代表セットについてピーク、無音余白、ループ継ぎ目、用途、権利を検査する
- [ ] 残りの必須素材を同じ工程で作れる命名、書出し、検査手順と見積りがある

## 客観確認

1. ラスター画像はPNGヘッダー、寸法、アルファ、SHA-256を記録する。
2. 代表画面を1440×900、390×844、844×390で描画し、横溢れ0、重要HUD欠落0、44px未満の操作対象0を検査する。
3. コアと戦闘要素はグレースケール化・色覚シミュレーション後も輪郭または記号が一意であることを画像差分と仕様表で確認する。
4. HUD占有率、対象と背景の輝度コントラスト、明滅頻度、画面揺れ量に数値上限を設ける。
5. 音は波形検査でクリップ0、用途別ピーク範囲、ループ端差分を記録する。聴感の良否は判定しない。
6. 生成画像は構想・基準用とし、ゲーム投入前に分離、編集、ライセンス、表示検証を完了する。
