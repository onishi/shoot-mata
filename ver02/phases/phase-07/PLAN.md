# Phase 07 plan — 全コンテンツ制作

状態: 進行中（2026-10-22）

## 目的

Phase 06で確立した制作・実装・検証経路を使い、第2〜4面、残る武器・機体・コア状態、UI、VFX、音を揃え、タイトルからエンディングまで仮素材なしで通す。

## 対象

- 16 MiBの製品buildへ4面を収める配信asset工程と面別容量予算
- 第2面・雲海精製塔、第3面・生体方舟、第4面・恒星炉心
- 各面の背景3層、通常敵3種以上、固有仕掛け、ボス、音楽3層、導入・クリア
- 第1面に残る音層・演出、3武器の命中差、共有の機体・コア状態、主要画面・VFX・音
- 4面進行、ステージ選択、エンディング、クレジット、保存復元

## 対象外

- 最終難易度・長時間性能・全ブラウザ調整（Phase 09）
- 製品要件の最終検収と公開（Phase 10〜11）
- 未測定の主観品質を合格とすること

## 実装順

1. [完了] 第1面assetを基準にPNG・WebP等の寸法、alpha、容量、Canvas表示を比較し、面別2.25 MiB以下・共有等7 MiB以下の予算を自動検査する
2. 第2面をデータ、完成asset、固有仕掛け、敵、ボス、音、開始→結果の順で完成させる
3. 同じゲートで第3面、第4面を個別に完成させる
4. 第1面の残単位と共有武器・機体・コア・UI・VFX・音を完成させる
5. 4面進行、保存、エンディング、クレジットを接続し、キーボードとタッチの決定的通しを追加する
6. 全asset台帳、権利、build、容量、通信、console、3画面条件を再検証する

## 完了条件

- [ ] 4面をそれぞれ開始→固有仕掛け→ボス→結果→再挑戦まで通せる
- [ ] 各面に固有の完成背景、敵3種以上、仕掛け、ボス、音がある
- [ ] 3武器×3段階、混色補助、必要な機体・コア状態が全区間で判別できる
- [ ] タイトル、ステージ進行、エンディング、クレジットが保存を含めてつながる
- [ ] 必須経路にplaceholder、planned、draftの素材が残らない
- [ ] 16 MiB以下の静的buildと全4面の決定的・ブラウザ通しに合格する

## 最初の作業単位

第2面・雲海精製塔の最小完成スライスを、stage schema、固有仕掛け、敵3種、bossの決定的simulationから実装する。完成assetと音を接続する前にも、第1面の分岐を増やさずデータ差替えで開始→仕掛け→boss→結果を通せることを先に固定する。
