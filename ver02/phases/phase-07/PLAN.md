# Phase 07 plan — 全コンテンツ制作

状態: 進行中（2026-10-22）

## 目的

Phase 06で確立した制作・実装・検証経路を使い、第2〜4面、残る武器・機体・コア状態、UI、VFX、音を揃え、タイトルからエンディングまで仮素材なしで通す。

## 対象

- 16 MiBの製品buildへ4面を収める配信asset工程と面別容量予算
- 第2面・雲海精製塔、第3面・生体方舟、第4面・恒星炉心
- 各面の背景3層、通常敵3種以上、固有仕掛け、ボス、音楽3層、導入・クリア
- 第1面に残る音層・演出、3武器の命中差、共有の機体・コア状態、主要画面・VFX・音
- 4面進行、ステージ選択、エンディング、クレジット、保存復元

## 対象外

- 最終難易度・長時間性能・全ブラウザ調整（Phase 09）
- 製品要件の最終検収と公開（Phase 10〜11）
- 未測定の主観品質を合格とすること

## 実装順

1. [完了] 第1面assetを基準にPNG・WebP等の寸法、alpha、容量、Canvas表示を比較し、面別2.25 MiB以下・共有等7 MiB以下の予算を自動検査する
2. 第2面をデータ、完成asset、固有仕掛け、敵、ボス、音、開始→結果の順で完成させる
3. 同じゲートで第3面、第4面を個別に完成させる
4. 第1面の残単位と共有武器・機体・コア・UI・VFX・音を完成させる
5. 4面進行、保存、エンディング、クレジットを接続し、キーボードとタッチの決定的通しを追加する
6. 全asset台帳、権利、build、容量、通信、console、3画面条件を再検証する

## 完了条件

- [ ] 4面をそれぞれ開始→固有仕掛け→ボス→結果→再挑戦まで通せる
- [ ] 各面に固有の完成背景、敵3種以上、仕掛け、ボス、音がある
- [ ] 3武器×3段階、混色補助、必要な機体・コア状態が全区間で判別できる
- [ ] タイトル、ステージ進行、エンディング、クレジットが保存を含めてつながる
- [ ] 必須経路にplaceholder、planned、draftの素材が残らない
- [ ] 16 MiB以下の静的buildと全4面の決定的・ブラウザ通しに合格する

## 最初の作業単位

[完了] 第2面・雲海精製塔のstage data、固有敵3種、上下気流・開閉遮蔽・帯電域、3段階bossを決定的simulationへ実装した。seed `20261022`で24機、7回の気流反転、boss 3段階を経てtick 2947・score 9525で結果へ到達し、同seedの全状態が一致する。

## 次の作業単位

[完了] 第2面の背景3層を原本PNGと1280×720配信WebPで制作し、asset manifestと容量検査へ接続した。配信3点は合計587,018 bytes、alpha最大差0、PSNR 33.574dB以上で面別2.25 MiB予算内。

[完了] 第2面の敵3種とbossを透明背景の完成assetとして制作し、敵384×256・boss 512×427のlossless WebP、asset manifest、表示snapshotへ接続した。4点の復号画素差はRGB・alphaとも0、背景込み996,632 bytesで面別予算内。

[完了] 第2面のリズム・旋律・危機/Boss音層と導入・クリア通知を決定的な自作合成で制作した。通常2層からboss 3層への同期切替、導入・クリアevent、音声manifest、波形・合成ピーク・容量検査へ接続し、画像込み2,283,252 bytesで面別予算内。

[完了] 製品入口へ解放済みステージ選択を接続し、通常入口から第2面を選択・出撃できることをChromeで確認した。`?qa=stage02`は通常戦、帯電遮蔽、boss 3段階、結果、同seed再挑戦を2回通り、score 9525・最終snapshot一致。320×844、390×844、844×390で横溢れ0、横長は縦溢れ0。

[完了] 第3面・生体方舟のstage data、再生群体・寄生砲台・捕食体、射撃で開く組織、増殖源、収縮通路、成長3段階の方舟中枢bossを決定的simulationへ実装した。seed `20261023`で30機、増殖6回、収縮6回、boss部位放出3回を経てtick 3577・score 11950で結果へ到達し、同seedの全状態が一致する。

[完了] 第3面の背景3層を原本PNGと1280×720配信WebPで制作し、asset manifestへ接続した。中景・前景のalpha最大差0、PSNR 34.360dB以上、3点合計697,514 bytesで面別2.25 MiB予算内。

[完了] 第3面の再生群体、寄生砲台、捕食体、方舟中枢bossを透明背景の完成assetとして制作し、敵384×256・boss 512×427のlossless WebP、asset manifest、表示snapshotへ接続した。4点の復号画素差はRGB・alphaとも0、背景込み1,211,744 bytesで面別予算内。

[完了] 第3面のリズム・旋律・危機/Boss音層と導入・クリア通知を決定的な自作合成で制作した。通常2層からboss 3層への同期切替、音声manifest、loader、波形・合成ピーク・容量検査へ接続し、画像込み2,311,164 bytesで面別予算内。
