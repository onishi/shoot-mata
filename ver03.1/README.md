# shoot-mata v3.1

完成済みのv3を保持したまま、プレイフィードバックを反映した改良版です。

## v3.1の変更

- 通常敵の耐久を約半分にし、ボスとの耐久差を明確化
- 各ステージの編隊を6〜8編隊から10〜12編隊へ増加
- 各ステージに2種、全体で12種の挙動バリエーションを追加
- 天井・床・ゲート・動的地形に合わせた敵編隊と、区間切り替え演出を追加
- 自機の横移動範囲を画面右端まで拡張
- ステージクリア時にリアクターコアと追加パワーアップを維持
- OPTION、BARRIER、RAPIDの3種類のパワーアップを追加
- 第2ボタン（X / Shift）でOPTIONをTRACE / WIDE / FOCUSの3陣形に切り替えるゲーム性を追加

## 起動と検証

```sh
cd ver03.1/game
npm ci
npm run verify
```

公開物はv3.1をトップと`/v3.1/`へ、保持したv3を`/v3/`へまとめて生成します。
