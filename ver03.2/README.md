# shoot-mata v3.2

完成済みのv3とv3.1を保持した、ステージ構成・物語・地形・OPTIONを作り直す改良版です。

## v3.2の変更

- TRACEが自機の14 / 28 / 42 / 56フレーム前の実航跡を追うように変更
- OPTION上限を2機から4機へ拡張
- 全面を約22%短縮し、5秒周期の増援と4秒の空白上限で道中を高密度化
- 各面に「接近 → 侵入／転換 → 突破 → ボス」の物語と任務目的を追加
- 6面それぞれに破断装甲、配管、生体膜、炉格子、結晶、位相回路の固有地形描画を追加
- 敵撃破・隔壁破壊の粒子、ヒット反応、追加補給を実装
- v3.1の武器、パワーアップ維持、右端移動、3陣形は継承

## 起動と検証

```sh
cd ver03.2/game
npm ci
npm run verify
```

公開物はv3.2をトップと`/v3.2/`へ、保持したv3.1を`/v3.1/`、v3を`/v3/`へまとめて生成します。
