# shoot-mata v3.3

完成済みのv3〜v3.2を保持し、短く密度の高い作戦、プレイ中の物語、多角形地形へ再構成した改良版です。

## v3.3の変更

- v3.2から全6面をさらに約20%短縮
- 各面に通信・目的変更・専用編隊・大型ランドマークが連動する5件の物語イベント
- 各面2種類、合計12種類の新規敵行動を追加し、通常敵を各面8種類以上へ拡張
- 全地形を多角形化し、描画と自機・弾の当たり判定で同じ輪郭を共有
- 艦体、圧力塔、器官、炉設備、結晶群、回路核の固有ランドマーク
- 時間制CHAIN表示、作戦イベント数と結末を示すステージ結果
- v3.2の4 OPTION、実航跡TRACE、面間強化維持、右端移動を継承

## 起動と検証

```sh
cd ver03.3/game
npm ci
npm run verify
```

公開物はv3.3をトップと`/v3.3/`へ、保持したv3.2、v3.1、v3を各バージョンのURLへまとめて生成します。
