# shoot-mata v3.3 改修方針

## 目的

v3.2で追加した任務表示とステージ固有表現を土台にしつつ、「表示上は物語があるが、プレイ中の出来事として感じにくい」「地形の外形と当たり判定が矩形のまま」「道中が長く、同じ戦いが続く」という課題を解消する。完成済みの`ver03/`、`ver03.1/`、`ver03.2/`は変更せず、`ver03.3/`を新設する。

## 設計原則

### 1. 短いステージに事件を連続させる

- v3.2から道中をさらに約20%短縮し、通常ステージのボス到達を約2分〜2分30秒、全6面を約15〜18分に収める。
- 各面に導入、異変、反撃、突破、決戦の5つ以上の物語イベントを置く。
- イベントは文章表示だけで終わらせず、専用編隊、地形変化、目標更新、ランドマークのうち2つ以上を同時に発生させる。
- 幕間表示は操作を止めず、通信者、短い台詞、次の目的をHUDと短時間バナーへ表示する。

### 2. 全6面を固有の作戦として再構成する

| Stage | 作戦 | プレイ中に起きる事件 | 決着 |
| --- | --- | --- | --- |
| 1 軌道残骸 | 亡霊艦隊の旗艦を拿捕 | 偽装残骸の起動 → 格納庫急襲 → 艦内隔壁の封鎖 → 炉心航路の開通 | Wreck Wardenの指揮核を破壊 |
| 2 雲海精製塔 | 反乱作業機を援護し圧力塔を停止 | 雷雲突入 → 作業機救出 → 圧力逆流 → 塔の緊急閉鎖 | Guardianを止め雲海を解放 |
| 3 生体方舟 | 捕食された避難船を方舟から切り離す | 外皮切開 → 消化液の増水 → 生存信号発見 → 再生器官の暴走 | 心臓核を止め避難区画を分離 |
| 4 恒星炉心 | 暴走炉から冷却制御鍵を奪還 | コロナ降下 → 冷却列車との並走 → 遮熱板喪失 → 手動冷却路の開放 | 炉制御体を破壊し連鎖爆発を阻止 |
| 5 氷晶演算海 | 偽の航路を生成する予言機を追跡 | 偽目標出現 → 反射礁の誘導戦 → 信号分岐 → 本体座標の確定 | 真のOracleだけを露出・破壊 |
| 6 零点中継核 | 過去5作戦を学習した主権AIを切断 | 記録再演 → 重力反転 → 偽の撤退命令 → 味方ビーコン再接続 | 学習核を分離してSovereignを撃破 |

### 3. 敵の種類を「見た目」ではなく行動で増やす

- 各面に最低2種類、合計12種類以上の新規敵行動を追加し、各面8種類以上の通常敵を保証する。
- 新規行動には、残骸からの変形、味方対象の護衛妨害、分裂、地形沿い突進、射線予告、編隊合体などを含める。
- 同じ増援を繰り返さず、物語イベントごとに敵プール、進入方向、隊形を切り替える。
- 敵の耐久力で時間を延ばさず、短い撃破時間と役割の組み合わせで難度を作る。

### 4. 矩形ではない地形を実装する

- 地形の外形を多角形プロファイルとしてデータ化し、描画のクリップ、輪郭線、弾・自機との当たり判定で同じ形状を共有する。
- 床と天井は斜面、欠損、突起、洞、結晶峰などの凹凸を持ち、長方形の輪郭線を表示しない。
- Stage 1は破断船殻、2は曲管と塔脚、3は波打つ器官と牙、4は傾斜炉壁と排熱口、5は非対称結晶峰、6は分岐する位相回路を基本形にする。
- 各面に画面幅級の物語ランドマークを3つ以上置き、接近・通過・破壊で構成が変わるようにする。

### 5. プレイ中に物語の結果を見せる

- 現在の作戦目的に加えて、通信者名と短い状況文を表示する。
- イベント完了数と重要目標の破壊数を記録し、ステージ結果で作戦経過を要約する。
- ボス登場は道中の最後の事件から因果的につなぎ、突然出現させない。

### 6. 自主改善

- 敵撃破の連続性を示す短時間のCHAIN表示と得点倍率を追加し、高密度区間を攻める動機を作る。
- ランドマーク通過時は画面揺れ、警告色、粒子を節度ある範囲で連動させる。
- 敵・敵弾・地形の危険色を整理し、複雑化しても進路を読めるコントラストを維持する。
- v3.2の4 OPTION、実航跡TRACE、3陣形、面間強化維持、右端移動、アクセシビリティを維持する。
