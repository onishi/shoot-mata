# shoot-mata v3.4

完成済みのv3〜v3.3を保持し、背景と一体化した地形、遊びとして起きる物語、役割が異なる敵と弱点攻略型ボスへ再構成した改良版です。

## v3.4の変更

- 背景画像の質感を地形内へ使い、錆・配管・肉膜・煤・結晶・位相ノイズと連続曲線の輪郭で舞台へ馴染ませた
- 各面5件の物語イベントを、格納庫、作業艇、避難嚢、冷却列車、偽像、味方ビーコンという実体のあるセットピースへ変更
- 各面2種類、合計12種類の敵を小型／大型、寸法、移動、攻撃、役割まで分けて再設計
- 消化液上昇や護衛対象など、6面それぞれの環境ルールを追加
- 全6ボスを、装甲剥離、圧力弁、器官順序、冷却、実像判別、中継ノードという別々の弱点攻略型へ変更
- v3.3の短い構成、4 OPTION、実航跡TRACE、CHAIN、面間強化維持、右端移動を継承

## 起動と検証

```sh
cd ver03.4/game
npm ci
npm run verify
```

公開物はv3.4をトップと`/v3.4/`へ、保持したv3.3、v3.2、v3.1、v3を各バージョンのURLへまとめて生成します。
