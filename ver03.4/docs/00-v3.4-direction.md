# shoot-mata v3.4 改修方針

## 目的

v3.3の「ステージは短くなったが、地形とランドマークが幾何学記号に見える」「物語が通信文の説明に留まる」「敵とボスのサイズ・移動・攻撃・攻略が似る」という課題を解消する。背景、地形、敵、攻撃、ボス攻略を一体として設計し、文章を読まなくても各作戦の出来事と違いが伝わる版にする。完成済みの`ver03/`から`ver03.3/`は変更しない。

## 設計原則

### 1. 地形を背景世界の一部として描く

- 単色グラデーション、均一な発光輪郭、反復する幾何学模様を主表現にしない。
- 各ステージの背景レイヤーを地形内部の質感として再利用し、同じ光源・色・粒度を持たせる。
- 輪郭は当たり判定を読める最小限のリムライトに留め、錆、煤、配管、肉膜、溶融岩、氷晶、位相ノイズを不規則に重ねる。
- 地形シルエットは破断、侵食、垂れ下がり、隆起、洞、堆積を使い、規則的な山形や星形を廃止する。
- 物語ランドマークの名称ラベルを常設せず、背景に馴染む大型構造物として見せる。

### 2. 文章ではなくプレイ中の現象で物語を伝える

- 大型通信バナーを廃止し、目的表示はHUDの短文だけにする。
- 各面に5つの「実体のあるセットピース」を置く。セットピースは敵の出現元、護衛対象、破壊対象、環境変化、安全地帯のいずれかとしてゲームに作用する。
- Stage 1は残骸が変形して格納庫が開く、Stage 2は作業艇と並走する、Stage 3は避難嚢を守りながら器官を切る、Stage 4は冷却列車を追う、Stage 5は偽像が分岐する、Stage 6は味方ビーコンを再接続する流れを画面内で表現する。
- ボスは最後のセットピースから出現・起動し、道中とボス戦の因果を切らない。

### 3. 敵を役割・寸法・運動・攻撃で分ける

- 小型機は高速・低耐久、中型機は編隊制御、大型機は地形やセットピースに固定する。
- 各面の新規2種はサイズ比を最低1.8倍以上離し、移動モデルと攻撃モデルも重複させない。
- 12種を以下の役割へ分ける。

| Stage | 小型／機動役 | 大型／制圧役 |
| --- | --- | --- |
| 1 | Boarding Cutter: 上下から交差突進 | Mimetic Wreck: 残骸から変形し機雷を放出 |
| 2 | Pressure Thief: 作業艇へ吸着 | Strike Arrester: 停止して縦雷撃を予告 |
| 3 | Maw Larva: 撃破時に小型へ分裂 | Nerve Knot: 器官に固定され再生支援 |
| 4 | Corona Lance: 直線加速と残留熱 | Coolant Raider: 列車を追う大型砲艇 |
| 5 | Decoy Shard: 短距離転移する群れ | Logic Binder: 反射射線を固定する大型機 |
| 6 | Archive Ghost: 過去面の攻撃を順番に再演 | Command Leech: ビーコンへ吸着し重力を乱す |

### 4. ステージごとの遊びを根本から変える

- Stage 1: 開閉する艦殻と、残骸から至近距離で始まる待ち伏せ。
- Stage 2: 味方作業艇の護衛。Pressure Thiefを優先して剥がす判断。
- Stage 3: 上昇する消化液と、分裂敵・再生器官の処理順。
- Stage 4: 冷却列車との追走。遮熱域を渡りながら砲艇を倒す。
- Stage 5: 反射地形を利用し、偽像ではなく実体へ攻撃を通す。
- Stage 6: 重力反転と過去5面の攻撃再演。味方ビーコン周辺を確保する。

### 5. ボスを「固い敵」ではなく攻略対象にする

| Boss | 移動・攻撃 | 弱点解除と攻略 |
| --- | --- | --- |
| Wreck Warden | 艦殻へ接岸し、牽引機雷と横薙ぎ砲 | 左右装甲を各1枚破壊すると背面炉が露出 |
| Refinery Guardian | 縦レール移動、圧力噴流で進路を分断 | 上下の圧力弁を撃って同時に開き、中央核へ攻撃 |
| Ark Core | 画面を脈動させ胞子を分裂 | 上器官→下器官→心臓の順に焼くと再生停止 |
| Furnace Controller | プレイヤーと横方向に並走、熱波を放つ | 冷却ポッドを撃ち込み温度を下げた間だけ炉心が開く |
| Prism Oracle | 3体が別軌道を飛び、偽像は弾を反射 | 背景の反射光と攻撃軌道から本体を見抜いて攻撃 |
| Relay Sovereign | 位相跳躍し、過去5ボスの攻撃を再演 | 3中継ノードを任意順で破壊し、学習核を短時間露出 |

- ボスの通常HPを増やして難度を作らない。正しい弱点への攻撃は大きなダメージ倍率を持つ。
- 各ボスに固有の攻略名、弱点状態、攻略進行をHUDへ表示する。
- 自動テストで6体の攻略名が重複せず、弱点未解除時の本体ダメージが遮断され、解除後に短時間で撃破できることを確認する。

### 6. 視認性と手触り

- 敵弾は攻撃種別ごとに形、軌跡、予告を変える。危険な直線攻撃は発射前に射線を示す。
- 敵の当たり判定は表示サイズと一致させ、大型敵は小型敵より明確に大きくする。
- 撃破時の破片も機械、液体、結晶、位相粒子で分ける。
- v3.3の短い総プレイ時間、4 OPTION、実航跡TRACE、CHAIN、面間強化維持、右端移動は維持する。
