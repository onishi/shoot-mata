# 01 ゲームデザイン

状態: M0完了（2026-10-26）

## 1. ゲームの核

仮題は **SHOOT MATA: RELAY BREAKER**。崩壊した星間航路を支配する自律防衛網を、自機「MATA-03」で外縁から中枢まで突破する、PCブラウザ向け1人用横スクロールシューティングとする。

プレイヤーが繰り返す判断は次の3つに絞る。

1. 地形と弾幕の間で安全な航路を読む。
2. 常に撃てる基本ショットで立て直しつつ、3色のコアをどの順に取るか選ぶ。
3. 正面火力、広域制圧、追尾による回避専念を、次の区間に合わせて組み替える。

1周は6ステージ、標準難易度で約29分を目標とする。各面は「導入 → 展開 → 山場 → ボス」の順で新要素を単独提示してから組み合わせる。敵を全滅させないと進めない停止部屋は作らず、装備を失っても基本ショットだけで必ず進行できる。

## 2. 操作とゲーム進行

### 操作

| 動作 | キー | 備考 |
| --- | --- | --- |
| 移動 | 矢印 / WASD | 8方向。プレイフィールド内に収める |
| 射撃 | Z / Space | 押し続けて連射。基本ショットは常に出る |
| 決定 | Enter | メニューと結果画面 |
| 戻る | Escape | メニュー階層を戻る |
| ポーズ | P | プレイ中だけ受理する |

対象はデスクトップChromeとキーボード。ゲーム規則には抽象化した入力を渡し、将来のゲームパッド対応を妨げないが、M4の完成条件には含めない。

### 画面遷移

`TITLE → HOW TO PLAY（初回のみ）→ START / SETTINGS → STAGE INTRO → PLAYING ↔ PAUSE → STAGE RESULT → 次面` を基本経路とする。残機が0なら `CONTINUE → 同じ面の先頭` または `TITLE`、第6面クリア後は `ENDING → CREDITS → TITLE` へ進む。

- キャンペーン開始時は3機、コンティニューは無制限。ただしコンティニュー時はスコアを0にし、面の先頭から再開する。
- クリア済みの面はステージ選択で単独練習できる。最終面は第5面クリア後に解放する。
- PAUSE、SETTINGS、RESULTはシミュレーションを完全に止める。
- 初回説明では移動、射撃、地形接触がミスになること、3枠のコアだけを1画面で示す。

## 3. 自機、ミス、スコア

### 当たり判定とミス

- 自機の見た目はおよそ64×36論理px、被弾判定は中心の直径10pxとし、中心を常時発光させて見えるようにする。
- 敵弾または敵本体への接触時、コアがあれば先頭のコアを1個失い、90tick（1.5秒）無敵になる。コアがなければ1ミスとなる。
- **地形への接触、画面に押しつぶされること、ボス本体への接触は、コアの有無にかかわらず1ミス**とする。地形接触が単なる装備損失にならないようにする。
- ミス時はコアをすべて失い、残機を1減らし、最後に通過した安全チェックポイントから2秒後に復帰する。復帰後120tickは無敵。
- 復帰位置の前後2秒には閉じる地形や即時突進を置かない。残機が残っている限り、地形内や敵本体上へ復帰させない。

### スコア

敵撃破点、コア取得75点、3体目以降の連続撃破ボーナス（連続数×25）、面クリア2000点、ノーミス2000点を加算する。敵を逃しても進行不能にはしない。結果画面には撃破、取得、連続、クリア、ノーミスの内訳を出す。

## 4. 武器とパワーアップ

v02のFIFO三連装リアクターを、**基本ショットを失わない補助兵装方式**に改めて採用する。取得順を読む独自の判断と既存の自機・3色コア素材を維持しつつ、空の状態でも戦えるようにする。

### 常設武器: PULSE

- コア数に関係なく、射撃中は正面へ毎秒8発の小型パルスを撃つ。
- 威力は小型通常敵を約1秒で倒せる値を基準とする。
- コア兵装の発射中も同時に残り、ミス後、コア0、コア兵装の追尾対象なしのいずれでも攻撃不能にならない。
- PULSEだけで全ボスを時間制限なしに撃破できる。コア兵装は攻略速度と安全性を上げるが必須鍵にはしない。

### 三連装リアクター

- 赤・青・黄のコアを取得順に最大3個保持する。4個目で最古のコアを押し出す。
- 先頭色が主武器を決め、先頭と同色の個数がLv1〜3を決める。
- 先頭と異なる色は補助効果を与える。HUDは3枠、先頭、次に押し出される枠、武器名、Lvを常時表示する。
- コアは危険側と安全側の分岐、または編成の合間に配置し、欲しい色を選んで取れる場面を各区間に最低1回作る。

| 色 / 主武器 | Lv1 | Lv2 | Lv3 | 得意な状況 |
| --- | --- | --- | --- | --- |
| 赤 LANCE | 太い直射、威力2、貫通1 | 威力3、貫通2 | 威力5、貫通4 | 装甲、直線通路、ボス |
| 青 SPREAD | 3方向、各威力1 | 5方向、各威力1 | 7方向、各威力1.2 | 群れ、上下の設置敵 |
| 黄 SEEKER | 追尾弾1、威力1.5 | 追尾弾2 | 追尾弾3、旋回強化 | 狭路、背後、回避優先 |

数値は相対値で、M2以降の自動プレイ時間から調整する。見た目は色だけに頼らず、LANCEは菱形、SPREADは山形、SEEKERは環形で区別する。

| 混色コア | 1個 | 2個 | 狙い |
| --- | --- | --- | --- |
| 赤 | コア兵装の貫通+1 | 貫通+2 | 群れの奥や遮蔽物越し |
| 青 | 被弾後無敵+0.25秒 | +0.5秒 | 防御と危険地帯の横断 |
| 黄 | 回収半径+32px | +64px | 危険位置のコア回収 |

単色Lv3は最大火力、混色は対応力になる。ミス後に基本ショットのみへ戻るため、Lv1コアは各チェックポイント後10秒以内に必ず1個供給する。

## 7. ボス設計

全ボスはPULSEだけで撃破可能にし、弱点が閉じたままになる乱数分岐を持たせない。各形態は30〜45秒を上限に循環し、攻撃前に形と音で予告する。

| ボス | 形態と攻略 |
| --- | --- |
| Wreck Warden | 残骸盾を上下へ回転 → 露出した背面を攻撃。盾の隙間は自機2.5機分以上 |
| Refinery Guardian | 上下レール移動 → シャッター射撃 → 中央露出。閉鎖位置を2秒前に表示 |
| Ark Core | 左右の器官を順に破壊 → 中枢露出。再生部位はスコア源だが必須ではない |
| Furnace Controller | 遮熱・集光・暴走の3形態。遮蔽板を残すか火力を優先するか選ぶ |
| Prism Oracle | 鏡像2体と実体1体 → 結晶迷路 → 全反射。実体は影と被弾反応で判別できる |
| Relay Sovereign | 過去ボスの攻撃を1つずつ再演 → 中継柱3本 → 主脳露出。撃破後に脱出演出とエンディング |

## 8. 画面レイアウトとUI

デスクトップの基準論理解像度は **1280×800**。上部720pxを16:9のプレイフィールド、下部80pxを常時HUD専用帯にする。Canvasを1枚使う場合も、座標系とクリップ領域を明確に分け、敵・弾・地形は`y < 720`、HUDは`y >= 720`にしか描かない。

```text
┌──────────────────────── 1280 ────────────────────────┐
│                                                      │
│             PLAY FIELD 1280 × 720                   │
│       背景 / 地形 / 自機 / 敵 / 弾 / 短い演出       │
│                                                      │
├──────────────────────────────────────────────────────┤
│ SCORE      LIVES      [R][B][Y] LANCE Lv1   BOSS     │ 80
└──────────────────────────────────────────────────────┘
```

- 左: SCOREとハイスコア、中央左: 残機、中央: 3コア枠・主武器・Lv、右: ボス戦だけボス名と体力。
- プレイフィールド内の文字は面開始、WARNING、STAGE CLEARに限定し、各1.5秒以内で消す。ポーズは戦闘を止めた別画面扱いとする。
- HUDの文字は16px以上、重要値は色だけでなくラベル・形・数値で示す。
- Canvasはアスペクト比を保ってviewport内にcontainする。小さなviewportでは全体を縮小するが、完成判定はPC Chromeの1280×800以上で行う。
- デバッグ時だけ地形ポリゴン、被弾判定、チェックポイントを重ねる。通常起動ではクエリ指定があっても開発build以外で有効にしない。

## 9. アート方針と素材

### 再利用

- v02の自機、3色コア、Stage 1〜4の通常敵12種、ボス4種、背景3層×4面を制作原本として再利用する。
- v02の配信用WebPは、v03の表示寸法と輪郭を確認して再生成してよい。v02のゲームコードはコピーしない。
- v02背景内に描かれた梁や配管は遠景としてのみ扱い、当たり判定を付けない。接触可能な地形は輪郭の異なる新規素材を前面に描く。

### 新規制作

- Stage 1〜4の追加敵各1種、Stage 5〜6の敵8種、ボス2種、各面の地形タイル、Stage 5〜6の背景3層、自機の被弾中心表示を新規制作する。
- 90年代アーケードの密度、暗い宇宙背景、鮮明な機体輪郭、限定した発光を共通言語にする。既存作品固有の機体、名称、ロゴ、画面構成は参照・複製しない。
- 自機は白＋シアン、敵弾は橙〜赤、取得物は彩度の高い赤・青・黄、危険地形は明るい縁取りを基本にし、背景との輝度差を確保する。

### 背景の継ぎ目対策

遠景は左右端が連続する専用ループ素材にする。中景・前景は1枚をそのまま並べず、次のいずれかを素材ごとに採用する。

1. 左右端を重ねてクロスフェードできる余白を持つ。
2. 2〜3枚の異なるタイルを不規則な順で接続し、接合部を独立した前景オブジェクトで隠す。
3. ループさせず、面の全長に対応するデータ配置オブジェクトとして描く。

各背景は接合点の前後を含む自動スクロールのスクリーンショットで確認する。単純な同一画像の横並びは採用しない。

## 10. 音

- 各面に通常、山場、ボスの3状態を持つBGMを用意し、急な曲切替ではなく小節境界でレイヤーを加減する。
- SFXはPULSE、3主武器、敵弾、命中、破壊、被弾、ミス、コア取得、地形予告、UI操作を持つ。
- BGMとSFXは別gain、設定値0〜100（初期値BGM 65、SFX 45）。同じSFXは同時4音、爆発は同時6音を上限とし、古い音から停止する。
- WARNINGとミスではBGMを最大3dB、500msだけダッキングする。それ以外の通常射撃ではダッキングしない。
- M2で素材ごとのRMSとピークを測り、基準BGMに対して常時射撃の合成SFXが平均+3dBを超えないよう調整する。クリッピング（0dBFS以上）を許可しない。
- v02のStage 1〜4音源と合成コードは再利用候補とするが、上記基準で再測定する。Stage 5〜6は新規制作する。

## 11. 難易度と自動検証のための規則

標準を完成判定の対象とする。アシストは残機4、敵弾速度75%、コア回収半径1.25倍、復帰無敵1.5倍とし、地形接触がミスになる規則は変えない。

- 敵、地形、ドロップ、ボス形態はtick基準のデータとして定義する。
- 乱数はseed付きとし、装飾、候補レーン、ドロップ選択だけに使う。必須の安全路を乱数に依存させない。
- 各面に安全チェックポイントを導入終了、展開終了、ボス直前の3か所以上置く。
- 自動操縦は地形回避を最優先し、次に敵弾回避、射撃維持、コア選択を行う。PULSEのみの固定入力列でも各ボスが倒せるテストを持つ。
- 地形の描画形状と衝突形状は同じデータから生成し、デバッグ画像で差分がないことを確認する。
- 面ごとの目標時間に対し±20%を許容範囲とし、通常プレイと自動操縦の双方が範囲外なら編成密度またはスクロール長を調整する。
