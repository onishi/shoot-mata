## 2026-10-26 — M2 Hull Crawler・敵弾・壊せる残骸壁

- やったこと: Stage 1の4種目として、天井梁のワールド座標に沿って移動し近接起爆機雷を落とすHull Crawler / Mine Layerを実装し、専用の透過WebP素材を追加した。Salvage Collectorの照準弾、敵弾によるコア損失・ミス、敵弾を避ける自動操縦を加えた。
- 地形: 中央航路を塞ぐ残骸壁を地形データ上の耐久値48の破壊可能地形にした。自機弾との衝突、破壊後の描画・自機衝突・自動操縦からの除外は同じ地形IDを参照する。
- 検証: `npm run verify` でビルド、Node単体テスト8件、PC版Google Chromeの自動通しに合格した。14,103 tickでボスを撃破し、PULSE 1,761発、地形接触0、残骸壁破壊、敵弾発射、WebP 9点の読込失敗0、ブラウザ例外0を確認した。
- 画面確認: 戦闘スクリーンショットでクローラーが天井下面に接続され、橙の機雷、自機弾、地形、自機を識別できること、通常画面にデバッグ表示がなくHUDがプレイ領域外にあることを確認した。背景と地形本体は引き続き仮描画。
- 次: Wreck Wardenに回転盾、背面弱点、予告付き攻撃を実装する。その後、Stage 1の背景3層と地形を完成素材へ置き換え、音と音量測定へ進む。
