# v4.2-04 Short Boss Pacing

## Change

- BLANK BAILIFF / CROSSWIND COMPILER / APOCRYPHA TWINSへ形態別の成功上限を追加した。HP総量は増やさず、専用攻略の超過成功を形態境界まで保留する。
- 各形態を最低8秒、TWINSは最低10秒維持し、戦闘全体を30秒未満で終了させない。
- 成功上限中は同じ攻撃の反復を抑え、形態移行時に残存弾を消去して短い学習窓を作った。TWINS phase 3は最初の両機同期崩しまで、最大25秒だけ被弾を保留する。
- 追加時間はStage 2末尾の反復36秒とStage 5末尾の反復30秒を削って相殺した。Stage 1の180秒とFIRST WAKEは維持した。
