# PALIMPSEST WAKE v4.0

`ver04/`は、過去版のコード・素材・世界観・ゲームシステムを流用せずに作る完全新作の開発領域である。

プレイヤーは移動で光の航跡を描き、航跡を閉じて危険を反撃へ変える。横スクロールシューティングの「避ける」を、どこを通り、いつ輪を閉じるかという空間設計へ変える。

## 現在地

- 現在のマイルストーン: M2 垂直スライス
- M0 新作設計: 完了
- M1 コア試作: 完了
- 次の作業: `docs/status.md`の「次の最優先作業」を参照
- 公開状態: 未公開。v3.4が引き続き公開版

設計が競合する場合は、ルート`README.md`、`docs/status.md`、番号付き設計文書の順に優先する。実装によって設計の仮説が否定された場合は、必須要件を縮小せず、判断と測定結果を`docs/log.md`へ残して設計を更新する。
