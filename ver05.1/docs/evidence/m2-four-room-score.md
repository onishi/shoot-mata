# M2 4部屋組曲 検証証拠

検証日: 2026-11-03

## 実装対象

- 起動盤へ先着し、滞在して遅い扉役を通す第3ルームLONG TONE
- 始点、6拍経路、8拍経路を最終拍に揃える第4ルームFINAL CADENCE
- FIRST CHORDから全4部屋完了までの連続進行

## 固定解法

- LONG TONE: `←←↑・・・・・`、`↑↑・・・↑↑・`、`→→→・・・・・`。起動役は3拍目から左盤を保ち、扉役が6拍目に通過して7拍目に成立する。
- FINAL CADENCE: `・・・・・・・・`、`←←←↑↑↑・・`、`↑↑↑↑→→→↓`。始点役と左役が待ち、右役が上側ポケットへ入る8拍目に成立する。

## 自動検証

`ver05/game`で`npm run verify`を実行し、Vitest 13/13、TypeScript型検査、Vite production buildが合格した。

新規テストでは、起動役が盤を離れた場合にLONG TONEの扉が閉じること、盤上に留まれば遅い扉役が通れること、FINAL CADENCEの右盤へ下側から直進できず上側の8拍経路で到達できること、両室の固定解法が指定拍で成立することを確認した。
