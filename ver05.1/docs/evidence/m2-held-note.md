# M2 HELD NOTE 検証証拠

検証日: 2026-11-03

## 実装対象

- 全奏者を毎拍同時解決する規則モデル
- 別奏者の起動盤着地と同拍だけ開く拍扉
- 第2ルームHELD NOTE
- FIRST CHORDからHELD NOTEを経て全2部屋完了へ至る画面遷移

## 自動検証

`ver05/game`で`npm run verify`を実行し、Vitest 8/8、TypeScript型検査、Vite production buildが合格した。

拍扉について次をテストで固定した。

- 奏者が単独で上へ入力し続けても閉扉の手前に留まる
- 起動役が4拍目まで未到達なら扉役は通過しない
- 起動役が5拍目に盤へ着地すると、扉役は同じ5拍目に通過する
- 3本の固定フレーズで扉の先を含む3音盤へ到達し勝利する

## Chrome実プレイ

Vite開発サーバーをChromeで開き、キーボード実入力で次を通した。

1. FIRST CHORDを既知の3フレーズでクリア
2. 勝利画面のEnterからHELD NOTEへ遷移
3. 起動役`←←←↑↑・・・`を録音
4. 扉役で上入力を4拍行い、閉じた橙色の扉の手前に留まることを目視
5. 5拍目の上入力で、起動役が左盤へ着地し、扉が金色に開いて扉役が中央へ進むことを目視
6. 扉役を上側音盤へ、3人目を右音盤へ進め、7拍目にSCORE COMPLETEへ到達

1280×720論理解像度のCanvasがブラウザ表示領域へ収まり、部屋名、目的、盤面、拍、録音譜面、操作、導線、閉開状態、勝利文言に欠けや意図しない重なりは見られなかった。
