# M3 REST MARK 静寂帯の検証

実施日: 2026-11-03

## 実装

- `Room.silenceFloors`へ静寂帯をデータ化した。
- 過去奏者が帯へ入った次の入力だけを`wait`へ置換し、直後に解除する奏者別状態を`ensemblePositions`へ追加した。
- 第7室REST MARK、固定3フレーズ解法、3段階ヒント、波紋による専用描画を追加した。

## 自動検証

- `npm run verify`: 合格
- 単体: 28/28。録音中の文字どおりの移動、帯へ入った次の一拍の消音、その後の離脱、4拍目の三和音を確認した。
- 型検査とproduction build: 合格
- Google Chrome E2E: 2/2。7室連続クリア、console/page error 0件、完了保存、第7室先頭への安全な再読込を確認した。

## 画面確認

- `m3-rest-mark-replay.png`: 第1奏者の再演3拍目。静寂帯で一拍欠けたため、録音時より一マス手前にいること、波紋床、軌跡、現在奏者の区別を確認した。
- `m3-e2e-rest-mark-complete.png`: 第7室を4拍目にクリアしたSCORE COMPLETE。overlay、背面HUD、盤面が欠けず、重なりによる誤読がないことを確認した。

## 結論

静寂帯は録音を変えず、再演だけから一拍を引く規則として決定的に動作する。第7室は反転床と異なる「時間を消す」判断を追加しており、次の反転・静寂複合へ進める。
