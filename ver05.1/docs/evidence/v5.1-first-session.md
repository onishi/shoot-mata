# v5.1 初回理解・失敗復帰監査

実施日: 2026-11-03

## 発見

v5.0をChromeでタイトルから開始し、第1フレーズを8拍録音した。確定直後の一時メッセージは「フレーズを記憶しました」だけで、次の入力と過去の声が同時に動く因果は、その後に現れる弱いガイダンスか実際の入力まで確定しなかった。また、Rは現在フレーズだけを消すため、確定済みVOICEをすぐ組み直す操作がなかった。タイトルの完了部屋も視覚上は未完了と同じ表記だった。

## 改善と証拠

- 録音確定後に「VOICE 1が次の入力と同時再演します」と4.2秒表示し、live regionにも同じ文を通知した。`v5.1-replay-onboarding.png`を目視し、盤面・VOICE・操作欄と重ならず読めることを確認した。
- Shift+Rで録音声、現在拍、フレーズ番号、ヒント段階を部屋先頭へ戻した。進行保存と設定は保持する。
- 完了済みの選択部屋へチェックを表示した。`v5.1-completed-room-marker.png`を目視し、部屋番号・名前・左右矢印と衝突しないことを確認した。
- 操作欄の初回実装でBackspace記号がフォント依存で崩れたため、`BKSP / R / SHIFT+R`へ修正し再撮影した。
