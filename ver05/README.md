## 起動

```sh
cd ver05/game
npm install
npm run dev
```

キーボードで操作する。矢印またはWASDで移動、Spaceで1拍待機、Backspaceで現在フレーズを1手戻す、Rで現在フレーズを録り直す、Escapeでポーズする。

検証は `npm run verify` でまとめて実行する。現在は単体13/13、型検査、production build、Chromeでの4部屋連続実プレイに合格した。
