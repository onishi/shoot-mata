## 起動

```sh
cd ver05/game
npm install
npm run dev
```

キーボードで操作する。矢印またはWASDで移動、Spaceで1拍待機、Backspaceで現在フレーズを1手戻す、Rで現在フレーズを録り直す、Hで段階式ヒント、Escapeでポーズする。

タイトルでは左右で解除済み部屋を選択でき、`S`で音量と動きの軽減を設定できる。設定と到達部屋は自動保存され、途中の譜面は保存せず部屋の先頭から安全に再開する。

検証は `npm run verify` でまとめて実行する。現在は単体40/40、型検査、production build、Google Chrome E2E 2/2に合格し、11部屋連続クリア、6拍・10拍HUD、拍扉、保存・再読み込み、設定、ヒント、ポーズ、1280×720と640×800を自動監査する。
