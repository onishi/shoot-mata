# CHORUS SHIFT v5.0

過去の自分が奏でる8手のフレーズと同時に動き、3人の奏者を同じ拍へ揃えるターン制の時間合奏パズル。

## 現在地

- M0 企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了
- 現在の対象: M2の追加ルール「拍で開く扉」と複数部屋進行
- 製品完成ではない。全ルーム、音響、設定、保存、アクセシビリティ、ブラウザ通し監査は未実装

## 起動

```sh
cd ver05/game
npm install
npm run dev
```

キーボードで操作する。矢印またはWASDで移動、Spaceで1拍待機、Backspaceで現在フレーズを1手戻す、Rで現在フレーズを録り直す、Escapeでポーズする。

検証は `npm run verify` でまとめて実行する。M1は単体5/5、型検査、production build、Chrome実プレイに合格した。

## 独立性

v1〜v4のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。v5は空のディレクトリから新規実装し、過去版は変更しない。
