## 起動

```sh
cd ver05/game
npm install
npm run dev
```

キーボードで操作する。矢印またはWASDで移動、Spaceで1拍待機、Backspaceで現在フレーズを1手戻す、Rで現在フレーズを録り直す、Hで段階式ヒント、Escapeでポーズする。

タイトルでは左右で解除済み部屋を選択でき、`S`で音量と動きの軽減を設定できる。設定と到達部屋は自動保存され、途中の譜面は保存せず部屋の先頭から安全に再開する。

検証は `npm run verify` でまとめて実行する。現在は単体43/43、型検査、production build、Google Chrome E2E 4/4に合格し、全12部屋連続クリア、6拍・10拍HUD、変換床、拍扉、終演、保存・再読み込み、設定、ヒント、ポーズ、主要6画面の1280×720・640×800境界、高密度フレーム性能、フォーカス、読み上げ状態、キー長押し、狭幅14px表示を自動監査する。`npm run audit:release` は既存公開経路を含むartifactを組み立て、静的検査とキャッシュ無効Chrome起動を行う。

## 独立性

v1〜v4のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。v5は空のディレクトリから新規実装し、過去版は変更しない。
