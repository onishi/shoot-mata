# ゲーム設計

最終更新: 2026-11-03

## 基本規則

- 盤面はグリッド。入力1回で1拍進む。
- 1フレーズは8拍。移動4方向または待機を録音する。
- フレーズ終了時にその8手が過去の奏者となり、次フレーズ中に同時再生される。
- 過去フレーズは最大2本。3本目以降は最古が譜面から外れる。
- 現在と過去2人が、同じ拍に3枚すべての音盤へ1人ずつ乗ると部屋クリア。
- 奏者同士は重なれる。壁への入力はその場に留まるが1拍を消費する。

## 入力

- 矢印 / WASD: 移動して1拍進める
- Space: その場で1拍待つ
- Backspace: 現在フレーズの直前1手を戻す
- R: 現在フレーズを拍0から録り直す
- Escape: ポーズ / 再開
- Enter: タイトル開始、勝利後の再演

## 縦切りルーム「FIRST CHORD」

同じ開始点から3方向へ枝分かれする小部屋。3枚の音盤は短・中・長の経路終端に置き、待機の意味を自然に学ばせる。最初の2フレーズは音盤へ到達して待ち、3本目で同時成立させる。

### 学習順

1. 移動すると拍表示と現在の譜面が増える。
2. 8拍で分身が残り、同じ入力を再演する。
3. 2本目では1本目の軌跡を見ながら別の音盤を狙う。
4. 3本目で三和音が成立し、盤面全体が応答する。

## 失敗と回復

入力ミスはBackspaceで即時に戻せる。方針が違えばRで現フレーズだけ録り直す。3本録っても成立しなければ、最古だけが外れて次の試行へ進むため、全リセットを強制しない。

## 今後の展開

- 扉: 特定拍だけ音盤で開き、別奏者が通る
- 反転床: 通過後の左右入力を反転して再演する
- 静寂帯: そのマス上の入力だけ過去奏者では待機になる
- 拍子変更: 6拍と10拍の部屋。ただし同一部屋では全奏者が同じ長さ

## M3 3章構成

全12室を、規則の導入ではなく「過去の譜面をどう解釈し直すか」が段階的に変わる3章へ分ける。後続室の名称と組合せはプレイ検証で更新できるが、各室の判断役割は重複させない。

| 章 | 室 | 主な判断 |
| --- | --- | --- |
| I / UNISON | 1 FIRST CHORD | 距離差を待機で揃える |
| | 2 HELD NOTE | 同拍到着で拍扉を開く |
| | 3 LONG TONE | 起動盤の占有を保つ |
| | 4 FINAL CADENCE | 8拍全体で異なる経路を揃える |
| II / INVERSION | 5 MIRROR ENTRY | 録音時と再演時の左右分岐を読む |
| | 6 GLASS RETURN | 反転床を二度通り向きを戻す |
| | 7 REST MARK | 静寂帯で再演の一拍だけを消す |
| | 8 NEGATIVE SPACE | 反転と静寂で同じ譜面を別経路へ送る |
| III / CODA | 9 SHORT MEASURE | 6拍で余白の少ない同期を作る |
| | 10 LONG MEASURE | 10拍で複数の保持区間を設計する |
| | 11 SHIFTED GATE | 拍子変更と拍扉を組み合わせる |
| | 12 CHORUS SHIFT | 全規則を選んで使い終演へ到達する |

## M2ルーム「HELD NOTE」

横一列の隔壁中央に拍扉を置く。左の起動盤へ別奏者が着地している同じ拍だけ扉を通過でき、早く着いた奏者は扉の手前で待つ。起動役は5拍目に盤へ到達し、扉役は閉じた扉へ入力を重ねて5拍目に通過する。最後の奏者は右の音盤へ向かい、7拍目に三和音を作る。

拍扉は一度開けば残る鍵ではない。毎拍、全奏者の移動意図を同時に解決し、扉へ入る奏者とは別の奏者が対応する起動盤へその拍に到達するときだけ通過を許す。この順序により「過去の入力をスイッチとして使う」という中核体験を直接発展させる。

## M2ルーム「LONG TONE」

HELD NOTEの「同じ拍に到着する」関係を反転し、起動役が3拍目に盤へ着いた後、その場で音を保つ。扉役は6拍目まで入口を待ち、起動盤が占有され続けている間に通過する。起動役が盤を離れると扉は再び閉じるため、入力列の到着時刻だけでなく滞在時間も設計する必要がある。

## M2ルーム「FINAL CADENCE」

扉を使わず、位置合わせを8拍全体へ発展させる終止形。一人は始点の音盤で8拍待ち、一人は6拍経路の終点で待ち、最後の一人は上側からしか入れないポケットへ8拍すべてを使って到達する。最終入力まで成立しないため、短い経路の待機と長い経路の正確な譜面を同時に読む。

## M3ルーム「MIRROR ENTRY」

第2章の入口。反転床へ入る拍までは録音時と再演時が一致するが、その次の拍から過去奏者の左右入力だけを反転する。上下と待機は変わらない。床へ再度入り直した場合は反転状態を戻す。

最初の奏者は右、右、上、上と録音すると、録音時には右上へ進む。再演時には一拍目で反転床へ入り、二拍目の右が左へ変わるため中央へ戻り、そのまま上の音盤へ着く。残る二人を左右の音盤へ送り、4拍目に三和音を作る。画面上では反転床を青いガラス菱形と双方向矢印で示し、録音済み譜面と実際の軌跡の差を同時に読めるようにする。
