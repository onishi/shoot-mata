# 技術設計

最終更新: 2026-11-02

## 構成

- TypeScript + Vite、外部ランタイムライブラリなし
- `src/model.ts`: 決定的な盤面規則。DOM、時刻、音声へ依存しない
- `src/main.ts`: 入力、画面遷移、Canvas描画、Web Audio
- 固定入力単位のターン制。描画の経過時間は規則へ影響しない

## 状態

`GameState`は画面、現在拍、現在入力、過去2フレーズ、各奏者位置、勝利状態を持つ。移動のたびに開始状態から現フレーズを再計算できるため、undoが状態差分の破損を起こさない。

拍扉のある部屋では、各拍の全奏者の移動意図を先に算出する。壁と境界を解決後、対応する起動盤へ別奏者が同拍に到達する扉だけ移動を許可する。`ensemblePositions`が過去フレーズと現在フレーズを一括再計算するため、undo、reset、描画、勝利判定で扉状態が分岐しない。

## 決定性

同じ部屋、過去フレーズ、現在入力なら常に同じ位置と結果になる。ランダム性は縦切りに入れない。将来の演出乱数も規則乱数から分離する。

## 保存

M1では保存しない。M2でlocalStorageへ到達部屋、設定、ヒント閲覧だけをversion付きで保存する。途中フレーズは保存対象外とし、部屋開始へ安全に戻す。

## 配信

`npm run build`で静的ファイルを生成する。v5公開経路は完成監査まで既存Pages workflowへ接続しない。
