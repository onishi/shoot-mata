# 品質計画

最終更新: 2026-11-03

## 縦切り受け入れ条件

- タイトルから開始し、キーボードだけでFIRST CHORDをクリアして再挑戦できる
- 8手の録音、最大2本の再演、壁衝突、待機、undo、現フレーズresetが決定的に動く
- 3枚の音盤は同一拍に別々の奏者が乗った場合だけ成立する
- 最古フレーズの入替後も進行不能にならない
- 1280×720で盤面、拍、目的、操作が欠けない
- `npm run verify`が型、単体テスト、production buildを一括合格する

## テスト層

- 単体: 移動、壁、録音終了、再演、undo相当の再計算、勝利、rolling tracks
- 解法: 固定3フレーズでクリアまで到達する
- ブラウザ: M2でタイトル、入力、ポーズ、勝利、viewport、音声開始を自動検査する
- 目視: 主要状態をスクリーンショット採取し、重なり、コントラスト、状態差を確認する

M2完了時点でGoogle Chrome E2E 2件を追加した。第1シナリオはポーズとヒントを経て全室を固定解法で通し、保存内容と再読込時の部屋先頭復帰を検査する。第2シナリオは設定再読込と1280×720・640×800の主要画面境界を検査する。M4で第1シナリオへ20秒の通し予算を、第3シナリオへ高密度状態のp95 25ms未満・34ms超5%以下のフレーム予算を追加した。console errorとpage errorも失敗扱いとする。

M2の拍扉では、単独時に閉じること、起動役の到着前は閉じること、同拍到着で開くこと、固定3フレーズで扉通過後に勝利できることを単体・解法テストで固定する。

M2の4部屋組曲では、LONG TONEの起動役が盤を離れれば扉が閉じ、滞在すれば遅い扉役を通すこと、FINAL CADENCEの右盤へ上側の8拍経路でのみ到達できること、タイトルから4室完了までキーボード入力で連続到達できることを固定する。

M2の保存では、初回クリアで次室だけが解除されること、最終室で範囲外を作らないこと、途中フレーズを保存しないこと、設定の往復、破損JSON、未知version、範囲外値、storage例外から安全に復帰することを単体テストで固定する。Chromeでは設定と進行を再読み込みし、解除済み部屋が第1フレーズ・0拍・VOICEなしから始まることを目視する。

M2のヒントでは、各部屋に答えの入力列を明かさない3段階を設け、ゲーム中とポーズ中から開けること、元の状態を保持して戻れること、閲覧部屋を重複なく保存することを固定する。Chromeでは段階切替、盤面との重なり、ポーズへの復帰を目視する。

M3の反転床では、録音中の現在奏者は入力どおり進むこと、過去奏者は床へ入った次の拍から左右だけが反転すること、上下は維持されること、第5室の固定3フレーズが反転後の位置を使って4拍目に成立することを単体テストで固定する。Chromeでは5室連続進行、反転床と軌跡の視認性、完了後の保存と第5室先頭復帰を検査する。

M3の二重反転では、過去奏者が一枚目の床を越えた区間だけ左右反転し、上下入力で二枚目へ入った次の水平入力が元の向きへ戻ることを拍ごとに固定する。録音中の文字どおりの終点と再演時の終点が異なること、第6室が固定3フレーズの5拍目に成立することを単体テストで検査する。Chromeでは6室連続進行、二枚の床と復路軌跡、完了保存、第6室先頭復帰を確認する。

M3の静寂帯では、録音中は文字どおり進むこと、過去奏者は帯へ入った次の入力だけが待機になること、その後の入力で帯から出られること、第7室が固定3フレーズの4拍目に成立することを単体テストで固定する。Chromeでは7室連続進行、波紋の帯と一拍欠けた軌跡、完了保存、第7室先頭復帰を確認する。

M3の規則複合では、反転後の入力へ静寂を適用して一拍だけ待機にすること、静寂後も反転状態が続くこと、録音時と再演時が左右別の終点へ着くこと、第8室が固定3フレーズの6拍目に成立することを単体テストで固定する。Chromeでは8室連続進行、二種の床と変換後の軌跡、第2章完了表示、完了保存、第8室先頭復帰を確認する。

M3の6拍では、`phraseLength`が入力上限、録音確定、再演、HUDへ一貫して作用すること、6入力目で過去フレーズになること、最長経路が5拍目には未到着で6拍目に成立することを単体テストで固定する。Chromeでは9室連続進行、6個の拍マーカー、6手の録音済み表示、5/6拍と6/6拍、完了保存、第9室先頭復帰を確認する。

M3の10拍では、9入力目まで現在フレーズが継続して10入力目に確定すること、最長経路が9拍目にはポケット手前で10拍目に成立すること、複数の保持区間を含む3本が決定的に再演されることを単体テストで固定する。Chromeでは10室連続進行、パネル内の10個の拍マーカー、10手の録音済み表示、9/10拍と10/10拍、完了保存、第10室先頭復帰を確認する。

M3の6拍拍扉では、中央役が扉手前で二拍を保持する間は閉じ、左役が四拍目に起動盤へ着く同拍だけ通過できること、一拍遅い通過では六拍目に奥の盤へ届かないことを単体テストで固定する。Chromeでは11室連続進行、4/6拍の開扉、6拍目の成立、完了保存、第11室先頭復帰を確認する。

M3の終演では、変換役が録音時の右上ではなく再演時の左上起動盤へ七拍目に着くこと、その同拍だけ中央役が扉を通過し、保持役を含む三人が八拍目に成立することを単体テストで固定する。Chromeでは全12室を連続進行し、最終扉の開状態、`SCORE COMPLETE`、全室完了保存、第12室先頭復帰、console/page error 0件を確認する。

## 製品ゲート

12部屋すべてに少なくとも1つ固有の判断があり、全解法が自動到達可能であること。ヒントなし初回経路とヒント利用経路、保存、設定、音量、reduced motion、ポーズ復帰、全画面目視、性能を監査する。
