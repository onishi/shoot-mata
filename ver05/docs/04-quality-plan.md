# 品質計画

最終更新: 2026-11-02

## 縦切り受け入れ条件

- タイトルから開始し、キーボードだけでFIRST CHORDをクリアして再挑戦できる
- 8手の録音、最大2本の再演、壁衝突、待機、undo、現フレーズresetが決定的に動く
- 3枚の音盤は同一拍に別々の奏者が乗った場合だけ成立する
- 最古フレーズの入替後も進行不能にならない
- 1280×720で盤面、拍、目的、操作が欠けない
- `npm run verify`が型、単体テスト、production buildを一括合格する

## テスト層

- 単体: 移動、壁、録音終了、再演、undo相当の再計算、勝利、rolling tracks
- 解法: 固定3フレーズでクリアまで到達する
- ブラウザ: M2でタイトル、入力、ポーズ、勝利、viewport、音声開始を自動検査する
- 目視: 主要状態をスクリーンショット採取し、重なり、コントラスト、状態差を確認する

## 製品ゲート

12部屋すべてに少なくとも1つ固有の判断があり、全解法が自動到達可能であること。ヒントなし初回経路とヒント利用経路、保存、設定、音量、reduced motion、ポーズ復帰、全画面目視、性能を監査する。

## 未検証リスク

現段階では実プレイ時間、初見理解、音の聴感、Chrome E2E、異なるviewport、キーロールオーバーを未検証とする。
