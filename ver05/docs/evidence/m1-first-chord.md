# M1 FIRST CHORD 証跡

実施日: 2026-11-02

## 自動検証

`ver05/game`で`npm run verify`を実行した。

- Vitest: 1ファイル、5/5件合格
- 規則: 床移動、壁衝突、過去フレーズ再演、同一拍の3音盤、最古フレーズ入替
- 解法: 上、左、右の固定3フレーズで勝利
- TypeScript: `tsc --noEmit`合格
- Vite production build: 合格、JS 10.36kB、CSS 1.01kB（非圧縮表示値）

## Chrome実プレイ

開発サーバーをChromeで開き、次をキーボードで実入力した。

1. EnterでタイトルからFIRST CHORDへ遷移。
2. `↑↑↑↑・・・・`を録音し、VOICE 1へ確定。
3. `↑↑←←←・・・`を録音し、VOICE 2へ確定。
4. `↑↑→→→`の5拍目で、上・左・右の3音盤が同時に占有され勝利。
5. 勝利表示は`CHORD FOUND`、第3フレーズ、Enter再挑戦を示した。

## 画面所見

- タイトルは作品名、中核説明、開始入力を一画面で読める。
- プレイ画面は盤面とHUDを左右へ分け、目的、現在拍、入力譜面、録音済み2本、操作一覧が1280×720の論理解像度内に収まる。
- 現在奏者は塗りと外周、過去奏者は輪郭と破線軌跡で区別できる。
- 3色は菱形、円、六角形も併用し、色だけに依存しない。
- 勝利オーバーレイ背後にも成立した3音盤が残り、結果と原因の関係を確認できる。
