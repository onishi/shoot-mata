## 2026-11-02 — M1 FIRST CHORD縦切り

- 8拍の移動・待機を録音し、過去2本を同じ開始点から同時再演する。3人が同一拍に別々の3音盤へ乗ると勝利し、不成立の3本目以降は最古を入れ替える。
- 壁衝突、再演位置、同時成立、rolling tracks、固定3フレーズ解法を5テストで固定した。初回検証で左右通路を壁データが塞ぐ不整合を検出し、意図した三方向分岐へ修復した。

- `npm run verify`に合格。単体5/5、型検査、production buildを確認した。
- Chromeで `↑↑↑↑・・・・`、`↑↑←←←・・・`、`↑↑→→→` を実入力し、第3フレーズ5拍目で三和音成立へ到達した。タイトル、2本録音後、勝利画面を目視し、主要情報の欠けや重なりを認めなかった。

## 2026-11-03 — M2 拍扉と2部屋進行

- 拍扉を「別奏者が対応する起動盤へ着地している同じ拍だけ通過可能」と定義した。全奏者の移動意図を同時解決する`ensemblePositions`を追加し、個別再生では扱えなかった相互作用を決定的にした。
- 第2ルームHELD NOTEを追加した。起動役`←←←↑↑・・・`、扉役`↑↑↑↑↑↑↑・`、右役`→→→・・・・`で、5拍目に扉を通過し7拍目に成立する。
- 2部屋メタデータを画面へ接続し、FIRST CHORD勝利後は次の部屋へ、HELD NOTE勝利後は最初へ戻る連続フローを実装した。扉は閉状態と開状態で幅・色・発光を変え、起動盤との対応を金の破線で示す。
- `npm run verify`は単体8/8、型検査、production buildに合格した。Chrome実入力でタイトルから2部屋完了まで到達し、閉扉での停止、同拍開扉、主要文字と盤面の重なりがないことを目視した。
- 詳細は`evidence/m2-held-note.md`に記録した。次はM2残り2部屋の固定解法と連続進行を作る。

## 2026-11-03 — M2 4部屋組曲

- 第3ルームLONG TONEを追加した。起動役は3拍目に盤へ着いて待ち続け、扉役が6拍目に通過する。起動役が早く盤を離れれば扉が閉じる回帰テストも追加し、拍扉が到着イベントではなく現在の占有で動くことを固定した。
- 第4ルームFINAL CADENCEを追加した。始点で待つ役、6拍経路で左盤へ行く役、上側からしか入れない右盤へ8拍で行く役を最終拍に同期させる。扉を外し、8手の長さそのものを位置合わせへ使った。
- 4部屋メタデータと連続遷移を画面へ接続し、タイトル表記をfour-room scoreへ更新した。
- `npm run verify`は単体13/13、型検査、production buildに合格した。Chromeでタイトルから4室を固定解法により連続クリアし、LONG TONEの6拍目の開扉とFINAL CADENCEの8拍目のSCORE COMPLETEを目視した。コンソール警告・エラーはなかった。
- 詳細は`evidence/m2-four-room-score.md`に記録した。次は到達部屋と設定のversion付き保存を実装する。
