# RIPPLEKEEP v6.0

月夜の池を滑るアメンボとなり、弾を撃たず、広がる波紋だけで眠る月花を漂着胞子から守るリアルタイム防衛ゲーム。

## 現在地

- M0 企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了
- M2 3面・製品機能: 完了
- M3 2章8面・終演: 進行中（7/8面）
- タイトル、1面「FIRST RAIN」、2面「SHORE CALL」、3面「SPLIT CURRENT」、4面「REED GATE」、5面「RESONANT POOL」、6面「MOONWAKE」、7面「DEW CROSSING」、勝敗、ポーズ、再挑戦を実装済み
- 第2面は初期3波紋では敗北し、岸で1回補充する固定戦略で全10胞子を排除できることを規則テストとChrome実入力の両方で確認済み
- 第3面は同時に現れる高速群と遠方低速群を、1.15秒・6.15秒の2波紋へ分けて全6胞子を排除できる。初期3波紋の即時連打は低速群を処理できず敗北する
- 第4面は右側の葦帯が波紋を遮る。中央待機では敗北し、葦の外へ1.2秒移動して2.0秒・7.2秒に放つと全6胞子を排除できる
- 第5面は単独波紋を受け付けない重い胞子を導入する。開始位置と少し右へ移動した位置から2波紋を重ねると、共鳴で3体を同時に押し返せる
- 第6面は月花が左右へ漂い、胞子が未来の花位置へ収束する。花の航路を追って2.0秒・7.3秒・13.0秒に短い波紋を置くと全6体を排除でき、開始位置に留まると敗北する
- 第7面は移動する月花へ4群9胞子が迫る。初期3波紋だけでは敗北し、2群目の後に岸へ離れて露を1回補充すると全9体を無傷で排除できる

## 起動

```sh
cd ver06/game
npm install
npm run dev
```

矢印またはWASDで水面を滑り、Spaceで波紋を放つ。波紋は胞子を外へ押し返す。波紋は3回分まで保持でき、岸辺を滑ると補充される。Escapeでポーズ、Rで最初からやり直す。タイトルまたはポーズ中にSで設定を開く。

検証は `npm run verify` でまとめて実行する。現在は単体25/25、型検査、production build、Google Chrome E2E 3/3に合格している。E2Eは7面の代表勝敗、ポーズ、設定保存、1280×720と640×800の画面境界を実入力で検査する。

## 独立性

v1〜v5のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。v6は空のディレクトリから新規制作する。
