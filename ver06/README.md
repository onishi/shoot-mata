# RIPPLEKEEP v6.0

月夜の池を滑るアメンボとなり、弾を撃たず、広がる波紋だけで眠る月花を漂着胞子から守るリアルタイム防衛ゲーム。

## 起動

```sh
cd ver06/game
npm install
npm run dev
```

矢印またはWASDで水面を滑り、Spaceで波紋を放つ。波紋は胞子を外へ押し返す。波紋は3回分まで保持でき、岸辺を滑ると補充される。Escapeでポーズ、Rで最初からやり直す。

検証は `npm run verify` でまとめて実行する。現在は単体5/5、型検査、production buildに合格している。

## 独立性

v1〜v5のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。v6は空のディレクトリから新規制作する。
