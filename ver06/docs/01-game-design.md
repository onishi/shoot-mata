# Game design

## コアループ

1. 池の外周から月花へ漂う胞子を読む。
2. 移動して波紋の中心を決める。
3. Spaceで有限の波紋を放ち、拡大する円周を胞子へ重ねる。
4. 残量が減ったら岸辺を滑り、露を集めて補充する。
5. 制限時間まで月花の耐久を残す。

## FIRST RAIN

- 18秒の導入面。
- 6個の胞子が異なる角度と間隔で侵入する。
- 月花の耐久は3、波紋は最大3。
- 波紋に触れた胞子は外向きに弾かれ、池外へ出ると浄化される。
- 何もしなければ敗北するが、1つの波紋で複数の胞子を扱える。

## 操作

- 矢印 / WASD: 八方向移動
- Space: 波紋
- Escape: ポーズ / 復帰
- R: 面を再開
- Enter: タイトル開始、結果から再挑戦

## 発展仮説

今後は速度の異なる胞子、波紋を遮る葦、波紋同士の共鳴、守る花の移動を一つずつ導入する。まずFIRST RAINで「円周を未来位置へ重ねる」判断が視認できるかを検証する。
