# Game design

## コアループ

1. 池の外周から月花へ漂う胞子を読む。
2. 移動して波紋の中心を決める。
3. Spaceで有限の波紋を放ち、拡大する円周を胞子へ重ねる。
4. 残量が減ったら岸辺を滑り、露を集めて補充する。
5. 制限時間まで月花の耐久を残す。

## FIRST RAIN

- 18秒の導入面。
- 6個の胞子が異なる角度と間隔で侵入する。
- 月花の耐久は3、波紋は最大3。
- 波紋に触れた胞子は外向きに弾かれ、池外へ出ると浄化される。
- 何もしなければ敗北するが、1つの波紋で複数の胞子を扱える。

## SHORE CALL

- 22秒の第2面。FIRST RAINの勝利後に続けて開始する。
- 4群10個の胞子が反対方向から同時に入り、1回の波紋で群全体を扱う読みを試す。
- 第4群まで守るには4波紋が必要で、初期3回を撃つだけでは月花の耐久3を失う。
- 第1群の処理後に淡い岸の輪へ移動し、露を1回補充して中央へ戻れば全排除できる。
- HUDの目的文、岸の帯、プレイヤー周囲の補充進捗、補充音とlive通知で回復条件を伝える。

## SPLIT CURRENT

- 12秒の第3面。SHORE CALLの勝利後に続けて開始する。
- 左から来る橙色の高速胞子3体と、右の遠方から来る紫色の低速胞子3体が0.6秒に同時出現する。
- 高速群は長い尾、低速群は外周の輪で、色だけに依存せず速度種別を見分けられる。
- 1.15秒の波紋は高速群だけを排除する。6.15秒まで2波紋目を温存すると低速群を排除し、耐久3・残量1で勝利する。
- 初期3波紋を高速群へ連打すると、低速群へ届く前に全波紋が消え、3体同時被弾で敗北する。
- HUDで「高速は先、低速は後」と短く伝え、波紋を今使うか残すかを速度差から判断させる。

## REED GATE

- 14秒の第4面。SPLIT CURRENTの勝利後に続けて開始する。
- 月花の右側、中心から半径132の弧に葦が生え、波紋と胞子を結ぶ線が葦帯を横切るとその波紋は胞子へ届かない。
- 右側から2群6個の胞子が侵入する。中央側から2.0秒・7.2秒に放っても全て葦に遮られ、3体同時被弾で敗北する。
- 開始直後に葦の外側へ移動し、同じ時刻に2波紋を放つと耐久3のまま全6体を排除できる。
- 黄緑の穂、破線の根元、手前に重なる描画、目的文とfooterで、葦が波紋を遮ることを色だけに頼らず示す。

## RESONANT POOL

- 8秒の第5面。点線の硬い殻を持つ重い胞子3体が月花の近くへ同時に現れる。
- 重い胞子は単独の波紋面に入っても動かず、異なるIDの2波紋が同時に覆う領域だけで共鳴して押し返される。
- 開始直後に1波紋を放ち、右へ短く滑って2波紋目を放つと、2つの中心から広がる面が3体の位置で重なり全てを排除できる。
- 1波紋だけでは0排除で敗北する。点線殻、淡い波紋面、重なりの加算発光、目的文とfooterで規則を色だけに頼らず示す。

## MOONWAKE

- 16秒の第6面。月花は左右へ周期的に漂い、3群6個の胞子は出現時点から花の未来位置へ向かう。
- 花の点線航路、1.5秒後と3秒後の輪、胞子から予測着地点への破線で、危険が固定中心ではなく未来位置へ集まることを示す。
- この面の波紋は半径132で消える。開始位置からでは左右端を守れず、花の航路を追い、2.0秒・7.3秒・13.0秒に波紋を置くと耐久3のまま6体を排除できる。
- 同じ時刻に開始位置から3波紋を放つと一部へ届かず敗北する。第1群は長い尾を持つ高速胞子で、既出の速度判読も再利用する。

## DEW CROSSING

- 20秒の第7面。移動する月花へ4群9個の胞子が迫り、短い波紋で航路上を守る。
- 4群すべてに1波紋ずつ必要なため、初期3回だけでは最後の3体が同時に到達し、月花の耐久を失って敗北する。
- 第2群を処理した直後、花が次の危険位置へ向かう間に左下の岸へ離れて露を1回だけ集め、航路へ戻れば全9体を無傷で排除できる。
- 点線航路と未来位置、淡い岸の輪、補充進捗を同時に見せ、今いる花へ付き続けるか、次の群までの猶予を使って補充するかを判断させる。

## 操作

- 矢印 / WASD: 八方向移動
- Space: 波紋
- Escape: ポーズ / 復帰
- R: 面を再開
- Enter: タイトル開始、結果から再挑戦

## 発展仮説

M2の3面で、単体群、補充を要する反対群、時間を分ける速度群まで導入した。M3第4面で葦による位置取り、第5面で2つの発射位置を使う共鳴、第6面で移動する防衛対象への先回り、第7面で防衛位置を離れる補充判断を導入した。次は既出規則を選択的に再構成する最終第8面と終演へ発展させる。
