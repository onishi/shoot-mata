# Quality plan

## M1ゲート

- タイトルからFIRST RAINの勝利・敗北・再挑戦へ到達できる
- 無操作では敗北し、計画的な波紋で勝利できる
- 波紋、胞子、月花、残量、残り時間が同時に判読できる
- 単体テスト、型検査、production buildに合格する
- Chromeで主要画面を目視し、console errorがない

## 後続ゲート

- M2: 3面、段階導入、設定、保存、Chrome E2E
- M3: 2章8面、固有規則、終演
- M4: 通し、性能、アクセシビリティ、release artifact

## 手動観点

- Space直後に反応を感じるか
- 円周が胞子へ届く時刻を予測できるか
- 岸での補充が中央防衛との明確な交換になるか
- 色覚に依存せず対象を区別できるか

## M2進捗

- SHORE CALLは初期3波紋のみでは敗北し、岸で露を1回集める固定戦略では耐久3・10排除で勝利する。
- Chrome実入力でFIRST RAINからの面遷移、淡い岸の帯、補充、4波紋による勝利を確認した。
- SPLIT CURRENTは3波紋の即時連打では敗北し、1.15秒と6.15秒へ分ける固定戦略では耐久3・6排除・残量1で勝利する。
- Chrome実入力でFIRST RAINから3面を連続クリアし、高速群の尾、低速群の輪、HUD、最終結果に欠けや重なりがないことを確認した。console error / warningは0件だった。
- 音量、高コントラスト、モーション軽減をキーボード操作し、リロード後の復元をChromeで確認した。破損値と保存不能は単体テストで安全な継続を固定した。
- PlaywrightのGoogle Chrome E2E 3件で、ポーズ、FIRST RAINの無操作敗北、3面連続勝利、設定保存、1280×720と640×800の境界を実入力から固定した。
- console error / warning 0件。初回E2Eでfavicon 404、目視で狭幅ポーズ時の誤った操作案内を発見し、修正後に回帰検査を加えた。
- M2ゲートは完了。証拠は`docs/evidence/m2-browser-e2e.md`に記録する。

## M3進捗

- REED GATEは中央側から同じ2波紋を放つと0排除で敗北し、開始直後に葦の外へ移動すると耐久3・6排除で勝利する。
- 葦帯と波紋の交差判定を単体テストで固定し、Google Chrome E2Eでタイトルから4面連続勝利を実入力から確認した。
- プレイ中と結果画面を1280×720で目視し、葦、アメンボ、波紋、胞子、HUDの欠けや重なりがないことを確認した。証拠は`docs/evidence/m3-reed-gate.md`に記録する。
- RESONANT POOLは単独波紋で0排除・敗北し、異なる位置からの2波紋を重ねると耐久3・3排除で勝利する。
- Google Chrome E2Eを5面連続勝利へ拡張した。プレイ中と結果画面を目視し、重い胞子の点線殻、2波紋の中心差、重なり領域、HUDに欠けや重なりがないことを確認した。証拠は`docs/evidence/m3-resonant-pool.md`に記録する。
- MOONWAKEは開始位置に留まる3波紋では敗北し、花の航路を追う3波紋では耐久3・6排除で勝利する。Google Chrome E2Eを6面連続勝利へ拡張し、航路、未来位置、短い波紋、結果overlayに欠けや重なりがないことを目視した。証拠は`docs/evidence/m3-moonwake.md`に記録する。
- DEW CROSSINGは花へ追従するだけでは初期3波紋を使い切って敗北し、第2群後に岸へ寄って1回補充する経路では耐久3・9排除で勝利する。Google Chrome E2Eを7面連続勝利へ拡張し、目的文の時間表示への重なりを初回目視で発見して修正した。証拠は`docs/evidence/m3-dew-crossing.md`に記録する。
