# M2 Settings and persistence evidence

実施日: 2026-11-03

## 実装

- タイトルとポーズから`S`で開く設定画面を追加した。音量は0〜100%の10%刻み、高コントラストとモーション軽減はチェックボックスで切り替える。
- 音量は全Web Audio出力へ即時反映し、0%ではAudioContextを生成しない。
- 高コントラストはCanvasのコントラスト、彩度、外周を強める。モーション軽減は星、水面、花、胞子の装飾アニメーションを静止し、ゲーム規則と波紋の位置情報は維持する。
- `ripplekeep:v6:settings`へ即時保存する。JSON不正、欠落、型違い、範囲外の音量は保存値を削除して既定値へ戻し、localStorageが利用不能でもセッション内設定で続行する。

## 自動検証

- `npm run verify`: Vitest 16/16、TypeScript、production build合格。
- 設定テストは未保存、正常往復、壊れたJSON、範囲外、型違い、欠落、書込例外を含む7ケースを検証した。

## Chrome確認

- Chromeの開発サーバーでタイトルから`S`を押し、設定カード、3設定、保存状態、戻る操作に欠けや重なりがないことを1280×720相当で目視した。
- 初回確認でゲーム用の矢印・Space抑止がフォームにも適用される問題を発見した。設定画面では標準フォーム操作を優先するよう修正した。
- 修正後、キーボードだけで音量を0%から30%へ変更し、TabとSpaceで2チェックを有効化できた。リロード後も30%・両チェック有効が復元された。
- Escapeでタイトルへ戻り、高コントラスト時もタイトル、説明、操作、池の対象が判読できることを目視した。
