# Development log

## 2026-11-03 — v6白紙企画

- 完成済みv5.1は人間の初見・聴感評価だけを残し、追加の機械的微調整より新作の価値が高いと判断した。
- UNDERROOT POST、KITE WEATHER、RIPPLEKEEPを比較し、位置と時間差を一つの波紋操作へ集約できるRIPPLEKEEPを採用した。

- 次はFIRST RAINをタイトルから勝敗まで接続する。

## 2026-11-03 — M1 FIRST RAIN縦切り

- 60Hz固定刻みの純粋モデルへ、移動、波紋、岸辺補充、胞子侵入、外向き反射、月花耐久、18秒の勝敗を実装した。
- タイトル、演奏中ではなく防衛中のHUD、ポーズ、勝利、敗北、再挑戦を接続した。Canvasの手続き描画とWeb Audioだけを使い、外部素材はない。
- 無操作敗北、波紋上限、岸辺補充、決定的スポーン、3波紋勝利を5件の単体テストで固定した。`npm run verify`は5/5、型検査、production buildに合格した。
- Chromeでタイトル、接近する胞子、拡大する二重波紋、ポーズ、耐久0の敗北を目視した。2.2秒、7.6秒、12.7秒のSpace実入力では月花耐久3のまま全6胞子を排除し、`FIRST RAIN HELD`へ到達した。
- 1280×720相当でHUD、池、対象、overlayに欠けや重なりはなかった。次は岸辺補充を勝利に必須とする第2面を規則から作る。

## 2026-11-03 — M2 SHORE CALL

## 2026-11-03 — M2 SPLIT CURRENT

- 3波紋を1.15秒に連打すると高速3体だけを排除して敗北し、1.15秒と6.15秒へ分けると耐久3・6排除・残量1で勝利することを2件の規則テストで固定した。
- 初回の画面確認で低速群1体が初期位置で画面外になる配置を発見し、右側に3体すべて見える進入角へ修正した。

- `npm run verify`は単体9/9、型検査、production buildに合格した。次は設定とlocalStorage保存を製品機能として実装する。

## 2026-11-03 — M2 設定と保存

## 2026-11-03 — M2 Chrome E2E

- Playwrightを導入し、Google ChromeへEnter、Space、移動、Escape、設定フォームの実入力を送る3件のE2Eを追加した。仮想時計で60Hzループを決定的に進め、無操作敗北と3面連続勝利を固定した。
- Canvasへ画面、面、耐久、波紋残量、排除数、表示設定の読み取り専用属性を追加した。E2Eはゲーム状態を直接書き換えず、製品入力だけで進行する。
- 設定3項目の保存復元、1280×720と640×800のCanvas・設定カード境界、16:9比率を検査した。証拠画像を目視し、主要情報の欠け・重なりがないことを確認した。
- 初回実行でfavicon 404を検出して固有SVGを追加した。狭幅ポーズ画像では補助文言が実操作と不一致だったため状態別文言へ修正し、回帰検査を追加した。
- `npm run verify`は単体16/16、型検査、production build、Google Chrome E2E 3/3に合格した。M2を完了し、次は葦で位置取りを導入する第4面へ進む。
