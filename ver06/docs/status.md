## 達成内容

- 3案を比較し、波紋の未来位置を読むリアルタイム防衛RIPPLEKEEPを採用した。
- 過去版を変更せず、v6固有の製品・ゲーム・表現・技術・品質文書を作成した。
- DOMと描画から分離した60Hz固定刻みモデルへ、八方向移動、3波紋、岸辺補充、6胞子の決定的スポーン、外向き反射、月花耐久、18秒の勝敗を実装した。
- Canvasで月夜の池、月花、アメンボ、珊瑚色の胞子、二重波紋、HUDを新規描画し、Web Audioの波紋・排除・被弾・勝利音を加えた。
- タイトル、FIRST RAIN、ポーズ、勝利、敗北、再挑戦をキーボードだけで接続し、Canvasの動的な読み上げ名とlive通知を追加した。
- `npm run verify`は単体5/5、型検査、production buildに合格した。無操作で耐久0の敗北、2.2秒・7.6秒・12.7秒の3波紋で全6胞子を排除して耐久3の勝利になる。
- Chrome実入力でタイトル、接近胞子、拡大中の波紋、ポーズ、敗北、勝利を確認した。勝利経路は3波紋で6胞子を排除し、`FIRST RAIN HELD`へ到達した。主要情報の欠けや重なりはなかった。
- データ駆動の面定義を導入し、第2面SHORE CALLを追加した。4群10胞子を22秒で処理し、初期3波紋のみでは最終群に耐久を奪われて敗北する。
- 岸の淡い帯、目的文、補充進捗、補充音とlive通知を追加した。第1群後に岸へ移動して1波紋を補充し中央へ戻る固定戦略は、耐久3・10排除で勝利する。
- FIRST RAIN勝利からSHORE CALLへ進む面遷移を実装した。`npm run verify`は単体7/7、型検査、production buildに合格した。
- Chrome実入力で2面を連続クリアした。SHORE CALLでは2.2秒に発射後、岸へ2.25秒移動、中央へ1.4秒で戻り、6.6秒・11.0秒・15.4秒に発射して`SHORE CALL HELD`へ到達した。HUDの目的文とタイマーの重なりを修正後、欠けや重なりがないことを再確認した。
- 第3面SPLIT CURRENTを追加した。同時出現する橙色の高速3体と紫色の低速3体を、長い尾と外周の輪でも識別できる。3波紋の即時連打は高速群だけを排除して敗北し、1.15秒・6.15秒へ分けると耐久3・6排除・残量1で勝利する。
- FIRST RAIN、SHORE CALL、SPLIT CURRENTの結果画面を連結した。Chrome実入力で3面を連続クリアし、速度別表現、HUD、結果overlayに欠けや重なりがないこと、console error / warningが0件であることを確認した。
- `npm run verify`は単体9/9、型検査、production buildに合格した。
