# PALIMPSEST POST v7.1

閉館後の記録局で、直前の自分の行動を「残務影」として再生し、ひとりでは通れない仕掛けを解くターン制協力パズル。

## v7.1

v7.0の完成版を自己批評し、規則や6面構成を変えずに初見理解と試行の手触りを改善した。

- 第1面の盤面直下に、移動とEnter確定を実際の位置に応じて示す2段階ガイドを追加
- 確定済みの各残務影について、行動列、現在拍、感圧印へ到着する拍を示す拍台帳を追加
- Zで現在シフトを1手戻すUndoを追加。局員、全残務影、封書、扉、記録を同じ状態へ戻す
- 従来の全6面、保存、設定、キーボード操作、終演を維持

矢印/WASDで移動、Spaceで1手待機、Enterで現在の行動列を残務影として確定、Zで1手Undo、Rで面を再開、Escapeでポーズする。

## 起動

```sh
cd ver07.1/game
npm install
npm run dev
```

`npm run verify`で単体テスト、型検査、production build、Google Chrome E2Eをまとめて実行する。v7.1は単体22/22、Chrome E2E 8/8、全6面の新規通し、1280×720と640×800、代表的な描画間隔に合格している。

`npm run release`はproduction buildを`release/palimpsest-post-v7.1/`へまとめ、ファイルサイズとSHA-256を記録したmanifestを作り、全ファイルと`index.html`の参照先を再検証する。

## 独立性

v7.1は同じゲームの改善版としてv7.0のコードと素材を継承する。v1〜v6のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムは使用していない。
