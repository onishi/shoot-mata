# v7.0 self-critique and v7.1 response

## 評価

v7.0は6面を通して「過去の入力列を未来の自分の同僚にする」中核が一貫し、保持、通過、待機、複数影、主体別床の順で意味の異なる判断へ発展していた。全面が短く、失敗に時間制限や罰がない点も企画に合っている。紙片、複写インク、封印、帳票の画面表現と合成音は統一され、技術的完成度も高い。

一方、最初の30秒では「ENTER FILE ECHO + REWIND」というフッターだけが確定を説明し、赤い印へ着いた後に何をすべきかを盤面から受け取れなかった。第2面以降ではヘッダーの手数は分かるが、影の入力列と印へ届く拍を記憶して比較する必要があり、同期パズルの情報が頭の中に偏っていた。また入力を1回誤るとRで面全体をやり直すため、複数影面ほど再入力が中核の思考を遮った。

6面のうち4面が「同じ拍に合わせる」問題であるため反復感はあるが、待機、複数影、複写床の導入で解法の意味は変化しており、新規面の追加より情報提示と修正操作の改善が優先と判断した。戦闘、物語、追加収集、長いチュートリアルは中核を薄めるため追加しない。

## v7.1で採用した改善

1. 第1面だけに状態連動の2段階ガイドを置き、最初は赤い印、到達後はEnter確定を示す。
2. 確定後は同じ領域を拍台帳へ切り替え、最大2影の行動列、現在拍、印到着拍を常時示す。
3. Zで現在シフトの完全な状態スナップショットへ1手戻し、Enter確定時に履歴境界を設ける。

## 採用しなかった改善

- 解答経路の常時表示: 発見と計画を答え合わせへ変えてしまう。
- 確定済み影の個別削除: どの記録から再生するかという新しい編集UIが必要になり、6面の規模に対して複雑すぎる。
- 面追加: 現行の発展弧はFINAL AUDITで閉じており、同種の同期面を足す効果が低い。

## 結論

v7.1で機械的な完成度を保ったまま、理解、予測、修正の3つの摩擦を減らした。残る最大の不確実性は外部の初見プレイであり、同じゲームへ推測的な小幅調整を重ねるより新作へ移る価値が上回る。
