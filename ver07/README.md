# PALIMPSEST POST v7.0

閉館後の記録局で、直前の自分の行動を「残務影」として再生し、ひとりでは通れない仕掛けを解くターン制協力パズル。

## 現在地

- M0 企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了
- M2 段階導入: 3/3面を実装。保存・設定は未実装
- 「DEAD LETTER」から第3面「MISSING MINUTE」まで連続プレイ可能
- 矢印/WASDで1マス移動、Spaceで1手待機、Enterで現在の行動列を残務影として確定して入口へ戻る
- 第1面では残務影が感圧印を保持し、第2・第3面では移動中の影が印を横切る一瞬だけ検閲扉が開く
- 封書を回収して投函口へ届けると勝利

## 起動

```sh
cd ver07/game
npm install
npm run dev
```

検証は`npm run verify`で単体テスト、型検査、production buildをまとめて実行する。現在は単体11/11、型検査、production buildに合格している。Google Chrome実入力で3面を連続プレイし、第3面のSpace待機、一時的な扉開放、封書回収、投函、勝利まで確認済み。

## 独立性

v1〜v6のコード、素材、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。標準的なVite/TypeScript/Canvasの開発手法だけを再利用し、空のディレクトリから制作する。
