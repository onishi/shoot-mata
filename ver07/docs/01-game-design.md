# Game design

## 基本規則

- 矢印/WASDの1入力で局員と残務影がそれぞれ1手進む。Spaceではその場で1手待機する。
- 壁または閉じた扉へ向かった主体はその場に留まるが、1手は経過する。
- Enterで現在の行動列を確定する。局員、封書、扉は初期状態へ戻り、影が記録を先頭から再生する。
- 影は記録の末尾へ達するとその場に残る。
- 保持印は影が上にいる間、通過印はまだ再生中の影が踏み込んだ1手だけ対応する扉を開く。
- 局員が封書のマスへ入ると回収し、投函口へ到達すると面クリア。
- Rで面を初期化、Escapeでポーズ。

## M1面: DEAD LETTER

入口から感圧印までの2手を記録して確定すると、影が印で停止する。現在の局員は開いた検閲扉を抜け、封書を回収して投函口へ届けられる。記録せず扉へ向かうと通れない。

狙う発見は「影は過去を飾る演出ではなく、未来の自分へ状態を残す同僚である」。最初の面では失敗ペナルティを置かず、入力と因果を画面内の変化で教える。

## M2面: MOVING DEADLINE

入口から上、上、右5手を記録すると、影は6手目に上段の感圧印を踏み、7手目に通過する。巻き戻った局員が下段を右へ進むと6手目に検閲扉へ到達するため、影が印を踏む一瞬だけ通過できる。

上下の経路を同じ横幅で並べ、印と扉を斜めの作動線で結ぶことで、説明文より先に距離と同期を比較できるようにする。第1面の「影を置く」理解を、第2面では「影の到着時刻を設計する」判断へ発展させる。

## M2面: MISSING MINUTE

局員は下段を右へ7手進むと扉へ着くが、影の上段最短経路は6手目に通過印へ着き、7手目には離れてしまう。上・上・右3手の後などにSpaceで空白の1手を記録し、続けて右2手を記録すると、7手目に影と局員が印と扉へ同時到着する。

通過印は印上で記録を終えても開かず、再生中の影が踏み込む瞬間だけ作動する。長さ7以下の非衝突記録には解がなく、長さ8の最短解は必ず待機を含むことを列挙テストで監査する。印へ到着した後の末尾待機は結果を変えない代替として残るが、待機なしの迂回はない。

## 発展仮説

- 2つの影を異なる長さで同期する
- 影には通れるが現在の局員には通れない複写床
- 封書を置く、受け渡す、順序を変える

追加はM1の初見理解を確認してから行い、単なる手数増加は避ける。
