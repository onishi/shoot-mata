# Technical design

## 構成

- TypeScript + Canvas 2D + Web Audio
- Viteによる開発・production build
- DOMと描画から独立した決定的なターン制モデル
- Vitestで同期、衝突、扉、回収、勝利を検証

ゲーム状態は画面状態、局員位置、現在の記録、確定記録、影位置と再生位置、通過印の1手パルス、封書状態から成る。行動は4方向移動と待機で、`move`は影の次手、感圧印による扉状態、局員の次手の順に同一ターンで解決する。保持印は位置、通過印は再生が続く影の新規到着で判定し、記録を印上で終える短絡を許さない。

面は型付きデータで定義し、歩行可能領域だけを可読な行データから生成する。規則モデルはCanvas座標を知らず、面番号を含むスナップショットだけを描画へ渡す。勝利後は次の面へ進み、最終面後は先頭へ戻る。

## 性能予算

- 1280×720と640×800で画面内に全盤面と操作を収める
- 60fps描画、規則更新は入力時だけ
- 外部runtime requestなし

## アクセシビリティ

キーボード完結、ポーズ、即時再開、色以外の形状差、Canvasの動的な読み上げ名をM1から実装する。音量、高コントラスト、モーション軽減、保存はM2で追加する。
