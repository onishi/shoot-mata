# Quality plan

## M1ゲート

- タイトルからDEAD LETTERを開始し、意図した記録で勝利できる
- 記録なしでは閉じた扉を通れない
- 2手の記録確定後、影が印へ到着した同じ手で扉を通れる
- 封書なしで投函口へ到達しても勝利しない
- 局員、影、印、扉、封書、投函口、現在の手数が同時に判読できる
- 単体テスト、型検査、production buildが合格する
- Chrome実入力で主要画面を目視し、console errorがない

## 後続ゲート

- M2: 3面、段階導入、設定、保存、Chrome E2E
- M3: 6〜9面、複数影または受け渡し、終演
- M4: 通し、性能、アクセシビリティ、release artifact

## 手動観点

- Enterによる確定が「やり直し」でなく「過去を配置する」と伝わるか
- 局員と影が同時に1手進むことを予測できるか
- 扉の開閉原因が文章なしでも読めるか
- 移動の音と短い沈み込みが1手の確定感を作るか
