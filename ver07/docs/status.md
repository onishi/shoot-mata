## 達成内容

- 3案を比較し、記録した過去の自分と同期するターン制パズルPALIMPSEST POSTを採用した。
- v1〜v6を変更せず、v7固有の製品・ゲーム・表現・技術・品質文書を作成した。
- DOMと描画から分離した決定的なターン制モデルへ、移動記録、Enterでの確定と巻き戻し、残務影の同期再生、感圧印、検閲扉、封書回収、投函勝利を実装した。
- タイトル、DEAD LETTER、ポーズ、勝利、再挑戦をキーボードだけで接続し、Canvasの動的な読み上げ名とlive通知、移動・阻止・確定・回収・勝利の合成音を追加した。
- 記録なしでは扉を通れず、右2手を確定後、残務影が印へ到着した同じ手で扉が開く。現在の局員が封書を回収して投函口へ着くと勝利することを5件の単体テストで固定した。
- Google Chrome実入力でタイトルから、右2手の記録、Enter確定、残務影による扉開放、封書回収、投函、`LETTER DELIVERED`まで到達した。初回確認で面名と目的文の重なりを発見して修正し、再確認後は主要要素の欠けや重なりがなく、console error / warningは0件だった。
- `npm run verify`は単体5/5、型検査、production buildに合格した。M1完成条件を満たした。
- 第2面MOVING DEADLINEを追加した。影は上段を7手移動し、6手目だけ感圧印を通過する。現在の局員が下段を6手進んで同じ手に扉へ到達する同期解を実装した。
- 面定義を型付きデータへ一般化し、面ごとの床、印、扉、封書、投函口、見出し、目的、勝利文をモデルと描画で切り替えられるようにした。第1面勝利後のEnterで第2面へ進み、Rは現在面だけを再開する。
- 第2面の一時開放、影が印を離れた後の再閉鎖、意図した勝利経路を含む3件を追加し、`npm run verify`は単体8/8、型検査、production buildに合格した。
- Google Chrome実入力で第1面から第2面へ進み、上・上・右5手を記録、巻き戻し後に右6手で扉を通過し、次手で影が印を離れて扉が閉じること、封書回収、投函、勝利を確認した。主要要素に欠けや重なりはなく、console error / warningは0件だった。
