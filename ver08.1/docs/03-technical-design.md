# Technical design

## 構成

- TypeScript + Vite + Canvas 2D
- `model.ts`: 盤面、移動、敵更新、領域確定、勝敗。DOMとCanvasを参照しない。
- `main.ts`: 固定時間刻み、入力、描画、合成音、画面遷移。
- `preferences.ts`: 音量・モーション軽減の正規化、version付き保存、破損値からの復旧。
- `progress.ts`: 最高到達面・キャンペーン完了の正規化、version付き保存、破損値からの復旧。
- `model.test.ts`: 決定的入力による規則テスト。
- Playwright: インストール済みGoogle Chromeへ実入力し、主要遷移、console、スクリーンショットを監査する。

## 決定性

ゲーム規則は整数セルと整数tickだけを扱う。描画補間は規則へ戻さない。敵は初期位置と斜め方向を面データとして持ち、壁または修復面で軸ごとに反射する。稲妻の針は同じ整数tickから予告、落雷、対象列を導出し、独立した実時間タイマーを持たない。

敵の実時間タイマーは開始、再挑戦、再開時に現在時刻へ戻す。タイトルやポーズ中の経過時間を持ち越して、操作可能になった直後に敵が移動することを防ぐ。

設定画面中も敵更新を止め、閉じるときに同じタイマーを現在時刻へ戻す。設定は`duskloom.preferences.v1`へJSON保存する。読み込みと書き込みは例外をゲーム本体へ伝播させず、欠損・型不正・範囲外の音量を既定値または対応する25%刻みへ正規化する。

モーション軽減は規則tickを変えず描画時間だけを固定する。背景、セル、星、蛾、織り子の装飾動作を止め、claim / winの全画面パルスを抑制する。

キャンペーン進捗は`duskloom.progress.v1`へ、最高到達面の0始まりindexと完了フラグだけを保存する。面数を上限に正規化し、完了フラグは最終面到達済みの場合だけ受理する。勝利した瞬間に次面を解放し、最終面勝利時は完了を保存する。第1面からの再走は解放状態を巻き戻さない。

## 領域確定

露出糸を修復済み境界へ変換した後、各未修復連結成分を4近傍で列挙する。敵を含まない成分を修復済みに変える。すべての成分に敵がいる場合は露出糸だけが修復済み境界になり、敵のいる領域を誤って布にしない。二体を分断する縫い目は即座に大面積を得られないが、新しい安全な境界を作る前進にはなる。

## 面データ

`LEVELS`へ面名、目標修復率、織り子の開始位置、ほどき蛾の初期位置と斜め方向、任意の初期修復矩形`clothPatches`、任意の周期ハザード`flashNeedle`、任意の方向制約領域`grainPatches`を定義する。`GameState.levelIndex`から現在の定義を参照し、再挑戦は同じ面、勝利後は次の面、最終面勝利後はタイトルへ戻る。「CROSSED SHUTTLES」は速度を変えず逆向きに進む二体の位置と軌道を読む判断を、「LOOM'S EYE」は4×4の内側安全島を中継点として使う経路選択を、「FLASH NEEDLE」は3tickの列予告から安全な確定時刻を読む判断を、「WARP GATE」は縫える軸を読む判断を導入する。「DAWN SAMPLER」は同じデータ要素を併用し、新しい分岐コードなしで安全島、木目、稲妻を統合する。

`flashNeedleFor`は現在tickを周期内phaseへ変換し、`dormant`、`warning`、`active`、対象列、落雷までのtickを返す。落雷tickでは、その列に露出糸が1セルでもあれば通常の切断処理を使う。落雷中に同じ列へ新しく糸を出した場合も即時切断する。描画とARIAは同じ導出値を参照するため、表示と規則がずれない。

`grainAt`は移動先の未修復セルが方向制約領域に含まれるかを返す。入力方向の軸が領域の`horizontal`または`vertical`と一致しない場合は、プレイヤー、糸、敵、tickを変えず`grain`イベントだけを返す。描画、専用音、live通知、E2E datasetはこの面データとイベントを参照する。

## 性能予算

盤面は280セルで、領域探索は再接続時のみO(セル数)。通常tickは敵数と入力だけを更新する。60fps描画でp95フレーム間隔35ms未満をM4の予算とする。

## 配布

`npm run release`は型検査とproduction build後、`release/duskloom-v8.0/`へ静的配布物を生成する。manifestは各ファイルのbyte数とSHA-256を保持し、独立スクリプトが内容、必須ファイル、`index.html`の全ローカル参照先を再検証する。実行時の外部通信とサーバー処理は必要としない。
