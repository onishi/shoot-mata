# DUSKLOOM v8.0

裂けた夜空の縁から光の縫い糸を伸ばし、ほどき蛾に切られる前に布へ戻すリアルタイム領域獲得ゲーム。

## 現在地

- M0 企画比較・独立性確認: 完了
- M1 コアループ縦切り: 実装・自動検証済み。実ブラウザ画面確認のみ環境障害で保留
- 1画面の織枠で、縁からSpaceを押しながら未修復領域へ入り、別の修復済み領域へ接続すると囲んだ夜空を修復する
- ほどき蛾が露出中の糸へ触れると糸巻きを1つ失い、3つ失うと敗北する
- 62%修復すると勝利し、Enterで再挑戦できる

## 起動

```sh
cd ver08/game
npm install
npm run dev
```

矢印/WASDで織り子を動かす。修復済みの縁からSpaceを押しながら未修復領域へ入り、別の修復済みセルへ戻ると縫い目が確定する。Escapeでポーズ、Rで面を最初からやり直す。

`npm run verify`で単体テスト、型検査、production buildをまとめて実行する。現在は単体7/7、型検査、production buildに合格している。

## 独立性

v1〜v7のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。DUSKLOOMは空の`ver08/`から新規制作し、標準的なVite、TypeScript、Canvas、固定時間刻みの手法だけを利用する。
