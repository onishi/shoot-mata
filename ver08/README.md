# DUSKLOOM v8.0

裂けた夜空の縁から光の縫い糸を伸ばし、ほどき蛾に切られる前に布へ戻すリアルタイム領域獲得ゲーム。

## 現在地

- M0 企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了。規則、実Chrome E2E、主要6画面の目視に合格
- M2 段階導入: 進行中。3面、段階導入、音量・モーション軽減設定と設定保存を実装済み。到達面保存が残る
- 1画面の織枠で、縁からSpaceを押しながら未修復領域へ入り、別の修復済み領域へ接続すると囲んだ夜空を修復する
- ほどき蛾が露出中の糸へ触れると糸巻きを1つ失い、3つ失うと敗北する
- 面ごとの目標（62% / 64% / 68%）まで修復すると勝利し、Enterで次の面へ進む

## 起動

```sh
cd ver08/game
npm install
npm run dev
```

矢印/WASDで織り子を動かす。修復済みの縁からSpaceを押しながら未修復領域へ入り、別の修復済みセルへ戻ると縫い目が確定する。第1面の基本、第2面の交差する二体、第3面の内側安全島を順に攻略する。Escapeでポーズ、Rで現在面を最初からやり直す。タイトルまたはプレイ中にOで設定を開き、左右で音量、Mでモーション軽減を変更する。設定はブラウザへ保存される。

`npm run verify`で単体テスト、型検査、production build、Google Chrome E2Eをまとめて実行する。現在は単体15/15、型検査、production build、Chrome E2E 3/3に合格している。

## 独立性

v1〜v7のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。DUSKLOOMは空の`ver08/`から新規制作し、標準的なVite、TypeScript、Canvas、固定時間刻みの手法だけを利用する。
