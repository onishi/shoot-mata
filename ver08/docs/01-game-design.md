# Game design

## コアループ

1. 修復済みの外周を移動し、敵の位置と進行方向を見る。
2. Spaceと方向入力で未修復領域へ踏み出し、露出した光糸を引く。
3. 別の修復済みセルへ戻るまで、より大きな囲みと接触リスクを比較する。
4. 再接続すると、敵から隔離された側が布になり、安全地帯と修復率が増える。

## 規則

- 盤面は20×14セル。外周1セルは最初から修復済み。面によって内側にも修復済みの足場がある。
- 織り子は修復済みセル上を自由に移動できる。未修復セルへはSpaceを押した移動だけで入れる。
- 糸を引いている間は隣接セルへ1セルずつ進む。自分の露出糸へ交差できない。
- 修復済みセルへ再接続すると露出糸を境界として、ほどき蛾から到達できない未修復セルを修復する。複数領域が残る場合は、敵が存在しない領域だけが修復される。
- ほどき蛾は未修復領域を斜めに漂い、壁で反射する。糸へ触れると糸巻きを失い、露出糸を消して直前の安全位置へ戻す。
- 修復率62%で勝利。糸巻き3個を失うと敗北。

## 初回30秒

- タイトルに「HOLD SPACE + MOVE OFF THE EDGE」を表示する。
- 開始直後は外周が琥珀色、未修復夜空が濃紺、敵が赤紫、露出糸が白金色である。
- 最初の再接続時に面が織り上がる走査演出と上昇音を返す。
- HUDは修復率、糸巻き、現在状態だけに絞る。

## 発展案

M2以降はコアルールを維持し、二体の敵、糸を短時間だけ焼く火花、内側の安全島、一定方向にしか縫えない木目を一つずつ導入する。速度や敵数だけで難易度を作らない。

## 面構成

1. **FIRST LIGHT**: 一体のほどき蛾で、短い縫い目と大きい囲みの基本を学ぶ。目標62%。
2. **CROSSED SHUTTLES**: 逆向きに進む二体を盤面の上下へ置く。片方だけを見て長い糸を出すと、もう片方が別角度から切り込む。目標64%。両側に敵が残る分断では糸だけが安全な境界となり、次の縫い目の足場を作る。
3. **LOOM'S EYE**: 中央の4×4セルが最初から修復済みの安全島。外周から島へ糸を確定し、島を横切って反対側へ再出発することで長い横断を二つの短い危険区間へ分けられる。横断後も島を別方向の接続先として使い、目標68%へ到達する。
4. **FLASH NEEDLE**: 10tick周期のうち6tickの猶予後、列を水色で3tick予告し、最後のphaseに金色の稲妻でその列の露出糸を焼く。6列目と15列目を交互に狙うため、予告中に短く確定するか、落雷後に長い横断を始めるかを選ぶ。目標66%。
5. **WARP GATE**: 上辺中央から始まり、中央3列の縦木目を上から下へ縫う。木目内の横入力は位置も糸も変えず拒否される。最初の縦断で61%を確保し、右側の通常領域にもう一本の縫い目を作って目標70%へ到達する。
6. **DAWN SAMPLER**: 上辺と中央の4×4安全島を短い縦木目でつなぎ、島から下辺へ抜けて盤面を分ける。残った左側は島から稲妻の予告列を横切って外周へつなぐ。経路の軸と着手時刻をともに読み、目標74%へ到達する。

第2面は敵数だけを物量として増やすのではなく、二つの現在位置と進行方向から「今どちら側へ出るか」を選ばせる。敵速度は第1面と同じに保つ。

第3面は敵を一体へ戻し、危険量ではなく安全地帯の形で発展させる。中央島は修復率を底上げするだけでなく、露出糸を一度確定できる中継点と、複数方向から使える新しい境界を兼ねる。

第4面の稲妻の針は修復済みの布や織り子を傷つけず、落雷列に残っている露出糸だけを切る。敵の現在位置に加えて周期を読むが、列の枠、HUDの残りtick、警告音で必ず事前に判別できる。モーション軽減時も予告枠と稲妻本体は消さない。

第5面の木目は未修復セルだけに作用し、修復済みの布上は自由に移動できる。青緑の破線と矢印、HUDの`FOLLOW THE GRAIN`、二段の拒否音、読み上げ通知を同じ規則へ接続し、入力が無視された理由を即座に返す。敵数や速度、時間ハザードは増やさず、空間の向きだけを新しい判断にする。

第6面は新規規則を追加しない。安全島までの上側接続を縦木目で制限し、島から左外周への仕上げ線上へ稲妻列を置く。前半は安全な経路形成、後半は予告を見た着手判断となり、過去3面の知識を一つの短い最終課題にまとめる。

## 設定

- タイトルまたはプレイ中にOで設定を開く。設定中は敵と規則時間を止め、復帰直後にも敵の移動猶予を保証する。
- 左右キーで合成音の音量を0 / 25 / 50 / 75 / 100%から選ぶ。0%ではAudioContextを新規作成しない。
- Mでモーション軽減を切り替える。有効時は背景の漂い、星の明滅、蛾の羽ばたき、織り子の揺れ、画面パルスを止め、規則上必要なセル移動だけを残す。
- 設定は変更時にブラウザへ保存し、再読み込み時に復元する。OSのモーション軽減設定は、保存値がない初回だけ既定値として使う。

## キャンペーン継続

- 面を勝利した時点で次の到達面を保存する。最終面では全6面完了も記録する。
- 到達記録があるタイトルでは上下キーで「最高到達面から続ける」と「第1面から」を選ぶ。第1面から遊び直しても到達記録は消さない。
- 最終面勝利後は自動的に第1面を始めずタイトルへ戻す。完了表示を残し、最高到達面の再挑戦か第1面からの再走をプレイヤーが選ぶ。
- 保存が欠損または破損している場合は第1面のみの初期状態へ安全に戻す。
