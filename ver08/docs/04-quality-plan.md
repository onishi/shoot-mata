# Quality plan

## M1自動検証

- タイトル状態と開始
- 修復面上の移動と、Spaceなしでの未修復領域侵入拒否
- Spaceによる糸開始、経路記録、再接続後の修復率増加
- 敵と糸の接触による残機減少と安全位置復帰
- 閾値到達による勝利、残機0による敗北
- 型検査とproduction build

## ブラウザ確認

- 1280×720でタイトル、初期盤面、露出糸、領域確定、勝敗を確認する
- Canvasがviewport内に収まり、文字・盤面・操作表示が重ならない
- キーボードだけで開始、プレイ、ポーズ、再開、再挑戦できる
- console error / warningがない

M1ではPlaywrightからGoogle Chromeへ実入力し、タイトル、露出糸、61%までの領域確定、勝利、敗北、ポーズ、再挑戦を2件のE2Eで固定した。主要6画面を1280×720で撮影し、盤面、HUD、overlay、操作表示を目視する。

## M2追加検証

- 面定義から第2面の目標値、二体の初期位置、互いに逆向きの進行方向が復元される
- 第1面の勝利後に第2面へ進み、現在面の再挑戦では第2面を維持する
- 二体が縫い目の両側にいる場合、敵を含む領域を誤って修復済みにしない
- Chrome上で `PANEL 2 / 3`、二体の輪郭と向き、目標値を同時に判読できる
- 第3面の4×4安全島が初期布として復元され、外周と島の間で糸を確定できる
- 島を中継する二段階の横断で68%へ到達し、第3面の勝利後は第1面へ循環する
- Chrome上でタイトルから3面完了まで通し、`PANEL 3 / 3`、初期28%、安全島、最終勝利を判読できる
- Oだけでタイトルとプレイ中から設定を開閉でき、左右で音量、Mでモーション軽減を変更できる
- 音量とモーション軽減が再読み込み後に復元され、破損した保存値は安全な既定値へ戻る
- モーション軽減時に背景の漂い、星の明滅、羽ばたき、画面パルスが停止し、設定中は敵が進まない
- Chrome上で設定画面の値、操作、復帰先を判読でき、console error / warningがない
- 第1面勝利後の再読み込みで第2面から続けられ、タイトルの上下キーで第1面開始も選べる
- 第1面から遊び直しても最高到達面を失わず、破損した進捗保存は第1面へ安全復旧する
- 全3面完了後は完了表示付きタイトルへ戻り、再読み込み後も完了状態と第3面からの継続を維持する

## 未測定を合格扱いにしない

外部初見プレイヤーの理解、実スピーカーでの聴感、スクリーンリーダー実機、低性能端末はM1では未評価として記録する。
