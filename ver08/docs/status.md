## 達成内容

- DUSKLOOM、ROOFTOP CHOIR、TIDELINE KITCHENを比較し、短い入力からリスクと報酬が生じ、決定的検証が可能なDUSKLOOMを採用した。
- 過去作を参照元にせず、夜空を縫い戻すリアルタイム領域獲得ゲームの製品、ゲーム、表現、技術、品質方針を作成した。
- 20×14セルの決定的モデルへ、安全な外周、Spaceを伴う縫い出し、自己交差阻止、再接続、連結成分による領域確定、斜めに反射するほどき蛾、糸切断、3残機、62%勝利を実装した。
- タイトル、プレイ、ポーズ、勝利、敗北、再挑戦をキーボードだけで接続した。Canvasへ天体織機、織り目のある修復面、流れる未修復面、露出糸、方向が読めるほどき蛾、修復率と糸巻きHUDを新規描画し、Web Audioの合成音を追加した。
- Spaceなしの侵入拒否、縫い出し、敵のいない領域の確定、蛾から糸への接触、織り子から蛾への接触、残機0、再挑戦、勝利を7件の単体テストで固定した。`npm run verify`は単体7/7、型検査、production buildに合格した。
- PlaywrightとGoogle Chromeを導入し、タイトル、露出糸、領域確定、勝利、敗北、ポーズ、再挑戦を2件のE2Eで固定した。console error / warningは0件だった。
- 実ブラウザ確認で、タイトルまたはポーズ中の時間が敵タイマーへ持ち越され、開始・再開直後に蛾が動く公平性の欠陥を発見した。開始、再挑戦、再開時にタイマーを戻し、実入力E2Eで回帰を防いだ。
- Chromeが要求するfaviconの404を専用SVGの明示参照で解消した。タイトル、露出糸、61%修復、勝利、敗北、ポーズの6画面を1280×720で目視し、左HUDが織枠へはみ出す問題を2行表示へ直した。再確認後は欠け、重なり、低コントラストの重大問題がない。
- `npm run verify`は単体7/7、型検査、production build、Google Chrome E2E 2/2に合格し、M1完成条件を満たした。
