- DUSKLOOM、ROOFTOP CHOIR、TIDELINE KITCHENを比較し、短い入力からリスクと報酬が生じ、決定的検証が可能なDUSKLOOMを採用した。

- Spaceなしの侵入拒否、縫い出し、敵のいない領域の確定、蛾から糸への接触、織り子から蛾への接触、残機0、再挑戦、勝利を7件の単体テストで固定した。`npm run verify`は単体7/7、型検査、production buildに合格した。
