# CANDLEWICK v9.0

光を絞れば追跡者から隠れられ、光を広げれば道と星種が見える、リアルタイム潜光探索ゲーム。

## 現在地

- M0 白紙企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了。規則、Google Chrome E2E、主要7画面の目視に合格
- M2 段階導入: 進行中。3室、鏡による反射光、燐の残光、面進行を実装・検証済み
- 第2室では強灯を三角鏡へ当てると上方へ光が曲がり、通常半径外の星種と経路を先読みできる
- 第3室では強灯を当てた燐の菱形が約2.5秒光を記憶し、消灯後の安全な移動経路になる

## 起動

```sh
cd ver09/game
npm install
npm run dev
```

矢印またはWASDで移動する。Spaceを押している間は灯りが広がり、星種と遠くの壁が見えるが、灰の番人が現在地へ近づく。Spaceを離すと灯りが小さくなり、灯油が回復する。星種を3個集めて右上の扉へ到達すると勝利し、Enterで次の室へ進む。第2室の三角鏡は強灯を上方へ曲げ、離れた星種を照らす。第3室の燐は照射した範囲を短時間だけ残し、暗所移動の目印になる。Escapeでポーズ、Rで現在室を最初からやり直す。

`npm run verify`でモデルテスト、構文検査、production build、Google Chrome E2Eを実行する。現在は単体14/14、構文検査、production build、Chrome E2E 4/4に合格している。E2Eには3室通し、鏡の点灯、燐の蓄光と消灯後の残光、最終タイトル復帰を含む。

## 独立性

v1〜v8のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。CANDLEWICKは空の`ver09/`から新規制作し、標準的なCanvas、Web Audio、固定tick、テスト手法だけを利用する。
