# Game design

## 基本ループ

1. 小さな常夜灯で近傍と番人の方角だけを読む。
2. Spaceを押して照射半径を広げ、壁、星種、出口までの経路を確認する。
3. 強い灯りで星種へ進む。灯油は減り、番人は現在地へ追跡する。
4. Spaceを離して暗がりへ入り、番人の追跡を切りながら灯油を戻す。
5. 星種を3個集め、開いた出口へ到達する。

## M1規則

- 16×10セル。外周と内部の石壁は通れない。
- 移動はキー入力ごとの1セル。規則時間は125msの固定tick。
- 常夜灯は半径2、強灯は半径5。星種は強灯中に同じセルへ入った場合だけ回収する。
- 灯油は最大24。強灯中は1/tick消費し、通常灯中は1/tick回復する。0になると自動的に通常灯へ戻る。
- 番人は4tickごとに動く。強灯中はマンハッタン距離を縮め、通常灯中は決められた巡回方向へ進む。
- 接触で残火を1失い、プレイヤーと番人を初期位置へ戻す。回収済み星種は維持する。
- 星種3個で出口が開く。出口へ入ると勝利。残火0で敗北。

## 公平性

- 暗闇でもプレイヤー、近傍2セル、番人の方角を示す画面縁の煤煙マーカーは見える。
- 番人が追跡中か巡回中かを、輪郭色とHUDの語で示す。
- 強灯開始時に即座に番人を動かさず、最大4tickの判断猶予を残す。
- 被弾後は双方を離れた初期位置へ戻し、入力をいったん解除する。

## 発展仮説

後続室では、光を反射する鏡、一定時間だけ記憶する燐壁、二体で異なる光色に反応する番人を、一つずつ導入する。敵数や速度だけで難度を上げない。

## M2 第2室: PRISM WALK

- 面の壁、開始位置、番人、星種、出口をデータ化し、第1室の勝利後にEnterで進む。
- 三角鏡は強灯の半径内に入ると点灯し、向いている上方向へ壁まで反射光を伸ばす。
- 最初の星種は開始位置から7セル以上離れ、直接の強灯半径外だが、鏡の反射線上にある。強灯を移動中ずっと維持せず、先に経路を読んでから暗所を進める。
- 鏡は収集や扉開放を代行しない。星種は従来どおり強灯中に同じセルへ入って回収する。
- 番人は一体、移動周期は4tickのままとし、難しさを物量や速度ではなく照射位置から作る。

## M2 第3室: AFTERGLOW GALLERY

- 燐の菱形は強灯の半径内に入ると20tick蓄光し、消灯後も自身と隣接セルを照らす。再照射すると残光時間を最大まで戻す。
- 左の上り道、中央の横断路、右へ抜ける上り道へ燐を配置し、強灯で経路を描いてから消灯し、番人の追跡を切って残光上を進む判断を作る。
- 残光は星種回収を代行しない。星種のセルでは再び強灯を使う必要があり、安全移動と回収の危険を分ける。
- 第2室の鏡は置かず、新規規則だけを読める。番人は一体、移動周期は4tickのままとする。

## M2 設定と進行

- 室をクリアした瞬間に次室を解放し、再読込後も保持する。タイトルでは解放済み室だけを左右で選択できる。
- 設定は音量、画面揺れ、明滅軽減の3項目とし、すべてキーボードで変更できる。
- 明滅軽減は規則時間を変えず、背景、光、番人、出口などの周期的な描画だけを静止化する。

## M3 第4室: TWIN VIGIL

- 炎番人は従来どおり強灯中だけ追跡し、宵番人は反対に通常灯中だけ追跡する。灯りを切り替えるたび、追跡役と巡回役が入れ替わる。
- 上下を交互に塞ぐ壁と、右下・右上に分かれた二体の初期位置により、片方から隠れ続けるだけでは出口へ届かない。二体との距離を見て、どちらを起こすか選ぶ。
- 炎番人は赤い菱形眼、宵番人は青い三角眼とし、暗所方向マーカー、HUD文言、読み上げ名でも区別する。
- 鏡と燐は置かず、二体の規則だけを読める。両者とも4tick周期で、速度上昇は行わない。

## M3 第5室: BORROWED GLOW

- 燐の道と通常灯を追う宵番人を組み合わせる。強灯中は宵番人が巡回へ戻り、燐へ20tickの残光を蓄えるが、灯油を消費する。
- 消灯すると灯油が回復し、描いた残光で屈曲路を読み続けられる一方、宵番人の追跡が始まる。安全な強灯だけを維持できず、残光時間、灯油、番人との距離を見て再点灯する。
- 3本の縦壁を上下交互に回り込む経路へ燐を連ねる。進路を光で記憶してから消灯し、追跡される短い区間を抜ける往復を繰り返す。
- 鏡、複数番人、速度上昇は併設しない。第3室と第4室で単独導入した規則の組合せだけで新しい交換関係を作る。
