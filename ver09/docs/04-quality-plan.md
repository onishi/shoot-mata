# Quality plan

## M1自動検証

- タイトルから開始、ポーズ、再開、再挑戦
- 壁による移動拒否
- 強灯の灯油消費、通常灯の回復、0での自動消灯
- 通常灯では星種を回収せず、強灯では回収する
- 強灯中の番人追跡、通常灯中の巡回
- 接触による残火減少、初期位置復帰、残火0の敗北
- 星種3個による出口解放と勝利
- 構文検査、production build

## ブラウザ確認

- 1280×720でタイトル、通常灯、強灯、回収、追跡、勝利、敗北、ポーズを確認する
- Canvasがviewport内に収まり、HUD、盤面、凡例が重ならない
- キーボードだけですべてのM1状態へ到達できる
- console error / warningがない

## 未測定を合格扱いにしない

外部初見プレイヤーの暗所理解、実スピーカーの聴感、スクリーンリーダー実機、低性能端末はM1では未評価として記録する。

## M4 最終監査結果

- 単体22/22、構文検査、production build、Google Chrome E2E 9/9、配布監査に合格した。保存注入なしの全6室通しも回帰していない。
- 1280×720と640×800でCanvas全体と16:9比率を自動検査し、タイトルとポーズの4画像を目視した。狭幅では上下をletterboxとして使い、文字、HUD、overlay、操作表示に欠けや重なりはない。
- Tabフォーカス、フォーカス後の開始・照射・移動・ポーズ、状態に追従するCanvasのaccessible name、星種回収のlive region通知をChromeで確認した。追跡者がいない状態は明示的に`no warden pursuing`と読む。
- 強灯中の代表描画でsteady-state 110フレーム間隔を測定し、平均16.67 ms、p95 16.70 msだった。平均35 ms未満、p95 50 ms未満の合格条件を満たした。
- `release/candlewick-v9.0/`を再現生成し、必須ファイル、hashed JS/CSS、タイトル、500 kB上限を検査した。実測は6ファイル、24,560 bytesだった。
- 外部初見プレイヤー、実スピーカー、スクリーンリーダー実機、低性能端末は未評価のまま明記する。自動監査で代替したとは扱わない。
