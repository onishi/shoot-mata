# Quality plan

## M1自動検証

- タイトルから開始、ポーズ、再開、再挑戦
- 壁による移動拒否
- 強灯の灯油消費、通常灯の回復、0での自動消灯
- 通常灯では星種を回収せず、強灯では回収する
- 強灯中の番人追跡、通常灯中の巡回
- 接触による残火減少、初期位置復帰、残火0の敗北
- 星種3個による出口解放と勝利
- 構文検査、production build

## ブラウザ確認

- 1280×720でタイトル、通常灯、強灯、回収、追跡、勝利、敗北、ポーズを確認する
- Canvasがviewport内に収まり、HUD、盤面、凡例が重ならない
- キーボードだけですべてのM1状態へ到達できる
- console error / warningがない

## 未測定を合格扱いにしない

外部初見プレイヤーの暗所理解、実スピーカーの聴感、スクリーンリーダー実機、低性能端末はM1では未評価として記録する。

## M1結果

- 単体9/9、構文検査、production build、Google Chrome E2E 3/3に合格した。
- Chromeでタイトル、通常灯、回収直前の強灯、回収後、ポーズ、勝利、敗北を1280×720で撮影した。
- 7画像を目視し、HUDと盤面の重なり、文字欠け、重要状態の判別不能はなかった。
- console error / warningは0件だった。開発サーバー起動時のNode環境変数警告はページconsoleには入らず、ゲーム動作へ影響しない。

## M2 第2室結果

- 単体12/12、構文検査、production build、Google Chrome E2E 4/4に合格した。
- 第2室固有の壁、面進行、現在室再挑戦、反射線、通常半径外の星種点灯、消灯、最終室後のタイトル復帰を単体テストで固定した。
- Chromeで第1室から第2室へ通常進行し、鏡点灯、2室完了、タイトル復帰までを状態注入なしで通した。console error / warningは0件だった。
- `m2-prism-beam.png`と`m2-two-rooms-kindled.png`を1280×720で目視し、反射方向、遠方星種、HUD、最終操作案内が判読できることを確認した。
