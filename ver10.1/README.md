# SIGNAL GARDEN v10.1

流れる光種より先に枝路を切り替え、三つの花を咲かせて受信樹へ帰す、リアルタイム経路先読みゲーム。

## 現在地

- v10.0完成後の自己批評: 完了。初回理解、第1・第2庭園の反復、終演の余韻を改善対象に選定
- v10.1 M1 初回理解と第2庭園固有化: 完了。1.8秒の盤面プレビュー、プレイ内の段階案内、固有の螺旋配置を実装
- v10.1 M2 終演強化: 完了。6庭園の習熟が約3.9秒で順に合流するリプライズを実装
- v10.1 M3 最終監査・配布物: 完了。通し、2 viewport、性能、ARIA、保存互換、配布物に合格
- 3個の分岐を左右キーで選び、Spaceで行先を切り替える
- 光種は一定拍で枝路を進み、花を3個通った後だけ受信樹へ届けられる
- 第3庭園「TURNING ROOT」は受信分岐が花環より先にあり、出発時と2周目の途中で遅延予約が必要
- 第4庭園「TWIN CURRENT」はFORKとGRAFTが連動し、雨花へ向けた後、光種がGRAFTへ着く前に安全路へ戻す必要がある
- 第5庭園「QUICKENING VINE」は1100ms拍で始まり、金色のQUICKEN通過後は520ms拍へ加速する。青色のCALM帰路で次周の経路を先に整える
- 第6庭園「TENDING CROWN」はSpaceを押している間だけCROWNが周回路へ曲がる。1周目は通過まで保持し、通過後に離して2周目を受信樹へ届ける
- 枯枝または早すぎる受信でライフを失い、経路と開花状況がリセットされる

## 起動

```sh
cd ver10.1/game
npm install
npm run dev
```

Enterで開始する。最初の庭園では盤面を読む1.8秒の猶予と、進行に応じた短い案内が表示される。左右キーまたはA/Dで分岐を選び、Spaceで選択中の分岐を切り替える。第2・第3庭園ではCROWNの切替だけが2拍後に確定し、第4庭園ではFORKとGRAFTが同時に切り替わる。第5庭園ではQUICKENとCALMで拍長が変わる。第6庭園ではCROWN選択中にSpaceを押している間だけ周回路へ曲がる。Escapeでポーズ、Rで現在の庭園を最初からやり直す。Mで音量を100%・50%・0%の順に切り替え、Vで動き軽減を切り替える。設定と進行はv10.0から引き継ぐ。`npm run verify`は単体33/33、構文検査、production build、Chrome E2E 9/9、配布物生成とSHA-256監査に合格している。`npm run release`は`ver10.1/release/signal-garden-v10.1/`へ静的配布物を生成する。

## 独立性

v10.1は完成したv10.0を批評して磨く同一ゲームのマイナー版である。v1〜v9のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムは使用していない。
