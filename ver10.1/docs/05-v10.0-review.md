# v10.0 自己批評

評価日: 2026-11-06

## 結論

SIGNAL GARDENの「流れる光種より数拍先に経路を予約する」中核判断は、第1庭園から終盤の遅延・同期・速度・保持まで一貫している。一方、完成監査の画像と6庭園Chrome通しを再評価すると、改善効果が高い課題が3件あるため、v11へ移らずv10.1を作る。

## 証拠に基づく課題

1. 最初の30秒は、タイトルで3行を読んだ直後に800ms拍が始まる。操作と目的は説明されるが、盤面上の明るい予約路と動く光種の関係を観察してから判断する時間がない。
2. 第2庭園は遅延CROWNという固有規則を持つ一方、第1庭園と同じノード配置だった。スクリーンショットでも差が紫の予約線に集中し、庭園を進んだ空間的な新鮮さが弱い。
3. 終演は色枝と3花の静止構図が中心で、6庭園で習得した遅延・同期・速度・保持の積み上げが視覚的な時間変化として返ってこない。

## v10.1で行うこと

- M1: 初回開始に短い盤面プレビューを設け、タイトルの説明を減らし、目的に応じた案内をプレイ中へ段階移行する。
- M1: 第2庭園を螺旋状の固有配置へ変え、規則と固定解法は保ったまま空間認識を刷新する。
- M2: 終演を6庭園の規則が順に呼応する短い動的リプライズへ強化する。スキップ不能な長演出にはしない。
- M3: 6庭園通し、2 viewport、性能、ARIA、保存互換、配布物を再監査する。

## 行わないこと

- 庭園数、新しい分岐規則、スコア、物語、マウス操作を追加しない。
- v10.0の固定解法、保存キー、難易度曲線を変更しない。
