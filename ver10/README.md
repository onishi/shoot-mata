# SIGNAL GARDEN v10.0

流れる光種より先に枝路を切り替え、三つの花を咲かせて受信樹へ帰す、リアルタイム経路先読みゲーム。

- M2 3庭園・設定・保存: 完了。到達済みの最新庭園から安全に再開できる
- M3 6庭園・終演: 完了。第6庭園の保持式CROWNと専用終演までChrome通しに合格

- 3個の分岐を左右キーで選び、Spaceで行先を切り替える
- 光種は一定拍で枝路を進み、花を3個通った後だけ受信樹へ届けられる
- 第3庭園「TURNING ROOT」は受信分岐が花環より先にあり、出発時と2周目の途中で遅延予約が必要
- 第4庭園「TWIN CURRENT」はFORKとGRAFTが連動し、雨花へ向けた後、光種がGRAFTへ着く前に安全路へ戻す必要がある
- 第5庭園「QUICKENING VINE」は1100ms拍で始まり、金色のQUICKEN通過後は520ms拍へ加速する。青色のCALM帰路で次周の経路を先に整える
- 第6庭園「TENDING CROWN」はSpaceを押している間だけCROWNが周回路へ曲がる。1周目は通過まで保持し、通過後に離して2周目を受信樹へ届ける
- 枯枝または早すぎる受信でライフを失い、経路と開花状況がリセットされる

## 起動

```sh
cd ver10/game
npm install
npm run dev
```

Enterで開始する。左右キーまたはA/Dで分岐を選び、Spaceで選択中の分岐を切り替える。第2・第3庭園ではCROWNの切替だけが2拍後に確定し、第4庭園ではFORKとGRAFTが同時に切り替わる。第5庭園ではQUICKENとCALMで拍長が変わる。第6庭園ではCROWN選択中にSpaceを押している間だけ周回路へ曲がる。Escapeでポーズ、Rで現在の庭園を最初からやり直す。Mで音量を100%・50%・0%の順に切り替え、Vで動き軽減を切り替える。画面上部のボタンでも変更でき、設定は再読み込み後も保持される。庭園を完了すると到達状況が保存され、再読み込み後は最新庭園の先頭から再開する。`npm run verify`でモデル・設定・進行保存テスト、構文検査、production build、Google Chrome E2Eを実行する。現在は単体30/30、構文検査、production build、Chrome E2E 6/6に合格している。

## 独立性

v1〜v9のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。SIGNAL GARDENは空の`ver10/`から新規制作し、標準的なCanvas、Web Audio、固定tick、テスト手法だけを利用する。
