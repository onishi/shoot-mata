# SIGNAL GARDEN v10.0

流れる光種より先に枝路を切り替え、三つの花を咲かせて受信樹へ帰す、リアルタイム経路先読みゲーム。

## 現在地

- M0 白紙企画比較・独立性確認: 完了
- M1 コアループ縦切り: 完了。モデル、Google Chrome E2E、主要4画面の目視に合格
- M2 3庭園・設定・保存: 完了。到達済みの最新庭園から安全に再開できる
- M3 6庭園・終演: 進行中。第4庭園で同期分岐を単独導入済み。次は拍長が途中で変わる第5庭園
- 3個の分岐を左右キーで選び、Spaceで行先を切り替える
- 光種は一定拍で枝路を進み、花を3個通った後だけ受信樹へ届けられる
- 第3庭園「TURNING ROOT」は受信分岐が花環より先にあり、出発時と2周目の途中で遅延予約が必要
- 第4庭園「TWIN CURRENT」はFORKとGRAFTが連動し、雨花へ向けた後、光種がGRAFTへ着く前に安全路へ戻す必要がある
- 枯枝または早すぎる受信でライフを失い、経路と開花状況がリセットされる

## 起動

```sh
cd ver10/game
npm install
npm run dev
```

Enterで開始する。左右キーまたはA/Dで分岐を選び、Spaceで選択中の分岐を切り替える。第2・第3庭園ではCROWNの切替だけが2拍後に確定し、第4庭園ではFORKとGRAFTが同時に切り替わる。Escapeでポーズ、Rで現在の庭園を最初からやり直す。Mで音量を100%・50%・0%の順に切り替え、Vで動き軽減を切り替える。画面上部のボタンでも変更でき、設定は再読み込み後も保持される。庭園を完了すると到達状況が保存され、再読み込み後は最新庭園の先頭から再開する。`npm run verify`でモデル・設定・進行保存テスト、構文検査、production build、Google Chrome E2Eを実行する。現在は単体26/26、構文検査、production build、Chrome E2E 5/5に合格している。

## 独立性

v1〜v9のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。SIGNAL GARDENは空の`ver10/`から新規制作し、標準的なCanvas、Web Audio、固定tick、テスト手法だけを利用する。
