# Game design

## M1の規則

- 光種は固定800msごとに有向枝路を1本進む。
- 左右キーで3個の分岐を選択し、Spaceで表示中の二つの行先を切り替える。
- 第1分岐は月花と雨花、第2分岐は鐘花と枯枝、第3分岐は受信樹と周回路を選ぶ。
- 三花を全て通過してから受信樹へ入ると勝利する。
- 枯枝へ入る、または三花が揃う前に受信樹へ入るとライフを1失い、開花と光種を初期化する。
- ライフ3個を失うと敗北。Rで即再挑戦できる。

## 意図する初回攻略

初期状態は「月花・枯枝・受信樹」。光種が第2分岐へ着く前に鐘花へ切替え、第3分岐は周回路へ変える。周回後に第1分岐を雨花へ変え、次の第3分岐到達前に受信樹へ戻す。現在位置だけを追うと間に合わず、分岐までの拍を読むと安定する。

## フィードバック

- 選択中の分岐は二重輪、予約された枝路は太い発光線で示す。
- 光種は枝路上を補間移動し、次の到着先を小さな予告光で示す。
- 開花は色、花弁数、HUDの3点で示す。
- 危険な予約は枯色、未達受信は警告文で事前に示す。
- 切替、移動、開花、損傷、勝利へ異なる合成音を割り当てる。

## 難易度仮説

800msの一拍と常時停止可能なポーズにより、初回でも1〜2回の失敗で経路を理解できる想定。速度ではなく「どの分岐をいつ戻すか」を難所にする。M1実測後に拍長とライフ数を調整する。

## M2 第2庭園 — SLEEPING CROWN

- 操作、枝路、花、危険、拍長は第1庭園から変えず、新規則をCROWNの「2拍遅延」一つに限定する。
- CROWNでSpaceを押すと行先が紫の点線で予約され、光種が2本の枝路を進んだ後に実線へ確定する。確定前にもう一度押すと予約を取り消せる。
- 最初の周回予約は出発直後に行う。帰路ではRETURN ROOTへ入った時点で受信樹を予約し、RAINへ向かうまでに確定させる。
- 現在位置だけを見てCROWN直前で切り替える第1庭園の手癖は間に合わない。どの枝路を通る間に予約が育つかを読む判断へ発展させる。

候補には、一度通ると閉じる花、二つの分岐の同期、短時間だけ開く枝を比較した。閉じる花は周回数だけを増やし、同期は後続庭園用の組合せ規則、時間制限は反射速度を主役にしやすい。2拍遅延が操作を増やさず先読みを最も直接深めるため採用した。

## M2 第3庭園 — TURNING ROOT

- 受信分岐CROWNを入口から2拍の位置へ移し、その先に周回路、FORK、2花、GRAFT、鐘花を環状に並べる。第1・第2庭園の左から右へ進む枝路とは空間構成と判断順が異なる。
- 初期CROWNは受信樹を向くため、出発直後に周回路を予約しなければ未開花のまま受信して損傷する。GRAFTも鐘花へ切り替えてから環へ入る。
- 1周目で月花と鐘花を開き、CROWNから再び周回へ入った後にFORKを雨花へ切り替える。同時にCROWNを受信へ予約し、RETURN ROOTとFORKを進む2拍で確定させる。
- 遅延規則を増やさず、受信分岐を「最後に処理する出口」から「先に予約する入口」へ変えることで、同じ操作に別の時間的意味を持たせる。
