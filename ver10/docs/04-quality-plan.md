# Quality plan

## M1合格条件

- Enterから説明なしでも、選択分岐とSpaceによる行先変更を識別できる。
- 三花、周回、受信、枯枝、ライフ、勝利、敗北、R再挑戦が接続する。
- 少なくとも二度の切替判断が必要で、初期状態の放置では勝てない。
- モデルテスト、構文検査、production build、Chrome E2Eが合格する。
- 主要画面に欠け、重なり、判別不能な状態がない。
- console error / warningがない。

## 後続ゲート

- M2: 3庭園の段階導入、設定、進行保存、破損保存復旧。
- M3: 6庭園通しと終演。規則追加は単独導入してから再構成する。
- M4: 1280×720と狭幅、キーボード、ARIA、性能、配布物を監査する。

## 既知の検証限界

外部初見プレイヤー、実スピーカー、スクリーンリーダー実機、低性能端末はローカル自動検証で代替しない。

## M2途中検証 — 第2庭園

- CROWNの現行経路と2拍後の予約経路を、実線と紫の点線、HUDの行先と残り拍、accessible nameの3系統で区別する。
- 予約は2拍後に決定的に確定し、確定前の再入力で取り消せる。
- 第1庭園を完了してEnterを押すと第2庭園へ進み、Rと敗北後のEnterは現在の庭園から再開する。
- 実キー入力で両庭園を通し、console error / warningなしで最終勝利へ到達する。
