# Quality plan

## M1合格条件

- Enterから説明なしでも、選択分岐とSpaceによる行先変更を識別できる。
- 三花、周回、受信、枯枝、ライフ、勝利、敗北、R再挑戦が接続する。
- 少なくとも二度の切替判断が必要で、初期状態の放置では勝てない。
- モデルテスト、構文検査、production build、Chrome E2Eが合格する。
- 主要画面に欠け、重なり、判別不能な状態がない。
- console error / warningがない。

## 後続ゲート

- M2: 3庭園の段階導入、設定、進行保存、破損保存復旧。
- M3: 6庭園通しと終演。規則追加は単独導入してから再構成する。
- M4: 1280×720と狭幅、キーボード、ARIA、性能、配布物を監査する。

## 既知の検証限界

外部初見プレイヤー、実スピーカー、スクリーンリーダー実機、低性能端末はローカル自動検証で代替しない。

## M2途中検証 — 第2庭園

- CROWNの現行経路と2拍後の予約経路を、実線と紫の点線、HUDの行先と残り拍、accessible nameの3系統で区別する。
- 予約は2拍後に決定的に確定し、確定前の再入力で取り消せる。
- 第1庭園を完了してEnterを押すと第2庭園へ進み、Rと敗北後のEnterは現在の庭園から再開する。
- 実キー入力で両庭園を通し、console error / warningなしで最終勝利へ到達する。

## M2途中検証 — 第3庭園

- 入口側CROWNから下側の花環へ向かう別グラフを使い、第1・第2庭園と経路の形と分岐順を変える。
- 出発時の周回予約と2周目途中の受信予約を、同じ2拍遅延で決定的に検証する。
- 実キー入力で3庭園を通し、最終勝利、console error / warningなし、入口予約と最終画面の目視確認へ合格する。

## M2途中検証 — 永続設定

- 音量は100%・50%・0%を循環し、動き軽減は装飾アニメーションと光種の補間を停止する。ボタンとM/Vキーの両方から操作できる。
- 設定はゲーム進行モデルから分離し、再読み込み後も保持する。不正JSON、対応外version、範囲外値、storage拒否は既定値へ安全に復旧する。
- Chrome E2Eで設定保持と破損復旧を確認し、`m2-settings-reduced-motion.png`を目視する。

## M2完了検証 — 進行保存

- 庭園完了時に到達済みの最新庭園だけを保存し、再読み込み後のEnterでその庭園の先頭から始める。途中の拍、経路、開花、ライフは持ち越さない。
- 不正JSON、将来version、範囲外値、storage拒否は第1庭園へ安全に復旧する。既に到達した庭園が古い完了通知で巻き戻らない。
- 単体24/24、構文検査、production build、Chrome E2E 5/5に合格し、`m2-progress-resume.png`を1280×720で目視する。

## M3途中検証 — 第4庭園

- FORKとGRAFTのどちらを選んでも両分岐が同時に反転し、CROWNは独立する。遅延CROWNとは同じ庭園で併用しない。
- 雨花へ向かう同期切替はGRAFTを枯枝へ向け、FORK通過後かつGRAFT到着前に戻した場合だけ安全に完走できる。
- 水色の接続線、両分岐の選択輪、HUDの二経路表示、ARIA通知で連動を識別できる。
- 単体26/26、構文検査、production build、Chrome E2E 5/5、console error / warning 0件に合格し、同期中と最終勝利を1280×720で目視する。

## M3途中検証 — 第5庭園

- 同期・遅延と併用せず、QUICKENで1100msから520ms、CALMで1100msへ戻る。損傷と再挑戦でも初期拍長へ復旧する。
- 低速区間でGRAFTとCROWNを先に整え、加速後は短い猶予を入力速度で追わずに通過できる攻略をモデルと実キー操作の両方で確認する。
- 金色と水色のテンポ門、名称、現在の`ms / BEAT`、二音、ARIA通知で速度状態と変化地点を識別できる。
- 単体28/28、構文検査、production build、Chrome E2E 5/5、console error / warning 0件に合格し、`m3-quickening-vine-fast.png`と`m3-fifth-garden-won.png`を1280×720で目視する。

## M3完了検証 — 第6庭園と終演

- CROWN選択中のSpace keydownで周回路へ曲がり、キーリピートで状態が揺れず、選択分岐を移動した後でもkeyupで必ず受信樹へ戻る。
- 1周目はCROWN通過まで保持し、RETURN ROOTで解放してから雨花へ向ける攻略を、モデルと実キー操作の両方で確認する。損傷と再挑戦は保持状態を残さない。
- 保持状態を二重輪、`HELD / RELEASED`、行先、操作案内、ARIAで識別できる。終演は三色の枝が一つの光へ合流する専用画面を持つ。
- 単体30/30、構文検査、production build、Chrome E2E 6/6、console error / warning 0件に合格し、`m3-tending-crown-held.png`と`m3-finale.png`を1280×720で目視する。
