- SIGNAL GARDEN、KITE PARCEL、FOLDWARDを白紙から比較し、数拍先の行先を予約する判断を最短で検証できるSIGNAL GARDENを採用した。

- 決定的な有向グラフモデルへ、固定800ms拍、3分岐、3花、周回路、枯枝、受信樹、ライフ3、勝敗、ポーズ、再挑戦を実装した。
- 初期放置では枯枝へ入り、勝利には第2分岐を鐘花、第3分岐を周回へ予約し、次周に第1分岐を雨花、第3分岐を受信へ戻す必要がある。現在位置ではなく数拍先を読む中核判断を接続した。
- Canvasへ二重の根、分岐の萼、3種の花弁、光種、受信樹、予約路の流動粒子を新規描画し、切替、移動、開花、損傷、勝利のWeb Audio合成音を接続した。
- 単体9/9、構文検査、production build、Google Chrome E2E 3/3に合格した。実キー入力で2周の勝利、初期危険路による損傷、R再挑戦、ポーズを確認し、console error / warningは0件だった。
- `m1-title.png`、`m1-two-flowers-return.png`、`m1-won.png`、`m1-strike-reset.png`を1280×720で目視し、文字欠け、HUDと盤面の重なり、分岐・開花・光種・勝敗の判別不能がないことを確認した。M1完成条件を満たした。
- 第2庭園「SLEEPING CROWN」を追加した。CROWNの切替だけが2拍後に確定し、現在経路は実線、予約経路は紫の点線、HUDとaccessible nameには行先と残り拍を表示する。確定前の再入力で予約を取り消せる。
- 第1庭園の最終受信を`gardenWon`として区切り、Enterで状態を初期化して第2庭園へ進む2庭園通しを接続した。R、敗北後のEnter、最終勝利後のEnterの再開範囲をモデル化した。

- 第3庭園「TURNING ROOT」を追加した。受信分岐を入口から2拍の位置へ移し、その先に花環を置く別グラフにより、出発直後に周回を予約し、2周目途中に受信を予約する攻略へ変えた。
