SIGNAL GARDEN v10.0

Serve this directory with a static web server, then open it in Google Chrome.

Controls
- Enter: start, continue, or resume
- Left/Right or A/D: select a branch
- Space: switch the selected branch; hold it in Garden 6
- Escape: pause or resume
- R: retry the current garden
- M: cycle sound volume
- V: toggle reduced motion

Progress and preferences are stored locally in the browser. All visuals and audio are generated by the game code; no third-party media is included.
