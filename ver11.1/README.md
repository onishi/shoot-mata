突風の予告を読み、糸を巻く／緩める判断で三つの風鈴片を集めて着地点へ戻る、リアルタイム凧航行ゲーム。

## 起動

```sh
cd ver11/game
npm install
npm run dev
```

Enterで開始する。タイトルでは左右キーで解除済み空域を選び直せる。プレイ中は左右キーまたはA/Dで凧を操り、Spaceを押している間は糸を巻いて上昇する。Spaceを離すと糸を緩めて下降する。空の帯に表示される突風予告中に進路を整え、突風が吹いている間は巻き続けない。第1空域では最初の突風前に解放を促す文脈ガイドが出て、張力計は百分率と安全／危険域を示す。三つの風鈴片を集めたら、地上中央の着地点へ降りる。第2空域では銀色の雲帯へ入ると突風を遮れる。第3空域では下降気流の矢印帯を横切る間、上昇が鈍り、糸を緩めると高度を速く失う。第4空域では予告矢印と同じ向きの風受け帯へ先回りし、突風中にSpaceを離すと張力を逃がしながら上昇できる。第5空域の音門は張力32〜68%の間だけ通れるため、門前で巻く／緩めるを切り替えて調律する。Escapeでポーズ、Rで再挑戦する。Sで設定を開き、矢印キーで音量と動き軽減を変更する。設定と到達済み空域はブラウザへ自動保存される。

第6空域では雲、下降気流、風受け、音門を一つの航路で順に使い、18片をすべて持ち帰ると六空の終演へ到達する。

`npm run verify`で規則テスト、構文検査、production build、Chrome E2E、配布物生成・監査をまとめて実行する。E2Eは実キー入力で初回突風ガイド、空域選択、ポーズ、糸切断、再挑戦、全6空域の18片回収、雲帯利用、下降気流横断、風受け上昇、音門の遮断と調律通過、着地に加え、設定・進行の再読込、破損保存の復旧、2 viewport、ARIA、フレーム性能を検証する。`npm run release`は`ver11.1/release/gale-thread-v11.1/`へ静的配布物とSHA-256一覧を生成する。
