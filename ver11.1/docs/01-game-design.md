# Game design

## M1ループ

1. 地上から凧を上げる。
2. 左右入力で次の風鈴片へ寄せ、Spaceで巻いて上昇する。
3. 画面上部の予告が示す風向と強さを読む。
4. 突風中は糸を緩めて張力を逃がすか、短く巻いて位置を優先する。
5. 三片を集めた後、Spaceを離して中央の着地点へ戻る。

## 規則

- 凧は左右入力、風、糸の復元力で横移動する。
- Space保持で上昇し張力が増える。解放で下降し張力が減る。
- 突風中の巻き上げは張力増加が大きい。張力100%が一定時間続くと切断。
- 風鈴片は高度ごとに置かれ、接触で回収する。
- 3片回収後、地面近くの着地帯へ低速で入ると勝利する。
- Rは即時再挑戦、Escapeはポーズ。

## M1調整仮説

- 予告1.2秒、突風1.8秒なら反応ではなく事前の横位置調整ができる。
- 張力は瞬間上限でなく猶予時間を持たせ、短いリスク選択を許す。
- 片は低・中・高の順に置き、上昇方法を自然に学ばせる。

## v11.1 初回理解と再訪

- 第1空域は最初の突風予告中に`GALE COMING · RELEASE SPACE`を着地点上の専用パネルへ表示する。突風中は張力に応じて解放要求または安全確認へ変わり、巻く／緩める結果を一周期で閉じる。
- 張力計は百分率、`SAFE`／`DANGER`／`BREAKING`、78%以上の危険帯を同じ場所に示す。突風予告には短い二音を鳴らす。
- タイトルは最遠到達空域を初期選択し、左右キーで0から解除済み上限まで選択できる。未解除空域には進めない。連続攻略時のEnter進行は従来どおり維持する。

## M2 第2空域: CLOUD LEE

- 第1空域を帰還するとEnterで連続して進む。
- 中央の銀色の雲帯へ入ると、突風の横押しと突風中の追加張力を遮る。
- 低空右、中空左、高空右へ片を置き、直行するか中央の風下へ寄って安全に巻くかを選ばせる。
- 風は第1空域より強くし、雲を単なる背景でなく経路上の安全地帯にする。
- 雲内はHUDの`SHELTERED`、雲上の`WIND SHADOW`、動的accessible nameで色以外にも伝える。

## M2 第3空域: FALLING WEFT

- 中央を縦に貫く下降気流帯と、右上の雲帯を同時に配置する。
- 下降気流内では巻き上げによる上昇が遅くなり、糸を緩めると通常のほぼ2倍の速度で高度を失う。
- 左低空、右中空、左高空の順で片を置き、中央帯を最低2回横断させる。突風に対して緩める安全策にも、高度を失う位置取りの代償が生まれる。
- 下降矢印、半透明の帯、`SINKING AIR`、HUDの`SINKING`、動的accessible nameで状態を色以外にも伝える。

## M2 設定と再開

- Sで設定を開き、上下で項目、左右またはEnterで値を変更する。プレイ中に開く場合は安全にポーズする。
- 音量は0〜100%の5段階。動き軽減は風線、下降矢印、片の脈動を静止させるが、風のフェーズやゲーム規則は変えない。
- 新しい空域へ入った時点で到達状況を保存し、再訪時は最も先の到達済み空域から始める。

## M3 第4空域: TURNING TACK

- 左右に、対応する向きの突風だけを上昇へ変える風受け帯を置く。右向き予告なら左帯、左向き予告なら右帯へ先回りする。
- 発動中にSpaceを離すと、張力を減らしながら下降より強い揚力を得る。巻けば通常どおり上昇するが突風張力を受けるため、安全な利益にはならない。
- 左低空、右中空、左高空へ片を置き、交互の予告方向と経路を結びつける。通常の巻き上げでも到達可能にしつつ、風受けを使うと張力と高度を同時に改善できる。
- 非発動帯は破線、次に発動する帯は予告中に明るくし、発動中は上向き山形、金色の帯、HUDの`LIFTING`、動的accessible nameで伝える。

## M3 第5空域: RESONANT PASS

- 左右に地上から高空まで続く音門を置く。張力32〜68%の間だけ横断でき、範囲外では手前へ穏やかに押し戻す。
- 開始地点を二門の間、片を左低空、右中空、左高空へ置き、片を追うたびに門前で張力を調律させる。糸を緩め続ける従来の安全策では通れない。
- 適正時は破線が金色の実線と共鳴輪へ変わり、`GATE IN TUNE`、HUDの`IN TUNE`、上昇二音で成功を返す。範囲外は橙色、`OUT OF TUNE`、低い短音で伝える。
- 門を上下から迂回できないよう全可動高度を覆う一方、適正帯は十分広くし、突風を読んだ巻く／緩める切替で必ず通過できる。

## M3 第6空域: LAST HORIZON

- 新規則を増やさず、中央低空の雲、左中高空の下降気流、右側の左向き風受け、中央右の音門を一つずつ再配置する。
- 左低空の片は雲で最初の強風をしのいで取る。右中空の片へ向かう際は音門で張力を整え、右側で左向き突風を待てば風受けで安全に高度を得られる。
- 最後の左高空片へは再び音門を越え、下降気流を横断する。既習判断を短い間隔で連続させつつ、各領域の形とラベルが同時に読める余白を残す。
- 3片を着地点へ戻すと`THE SIX-SKY CHORUS`を表示する。Enter後は進行を失わず最終空域を再飛行できる。
