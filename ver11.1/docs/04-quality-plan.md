# Quality plan

## M1ゲート

- 単体: 開始、上昇／下降、風予告、張力回復、切断、3片、着地、ポーズ、再挑戦
- ブラウザ: 実キー入力で開始から勝利、意図的切断から再挑戦
- 目視: タイトル、通常航行、突風危険、全回収、勝利を1280×720で確認
- 構文検査とproduction build

## M2途中ゲート

- 第1空域勝利から第2空域へEnterで遷移する。
- 雲内外で突風の横力と張力差が規則テストに現れる。
- 実キー入力だけで雲帯へ入り、第2空域の3片と着地まで到達する。
- 入口、突風中の雲内、勝利画面を目視し、雲が風線を遮り`SHELTERED`が読める。
- 第2空域から第3空域へ連続遷移し、下降気流内外の上昇・下降速度差が規則テストに現れる。
- 実キー入力だけで下降気流を横断し、全9片と最終着地まで到達する。
- 第3空域の入口、下降気流内、最終勝利を目視し、下降矢印、雲、片、凧、糸、状態表示が判別できる。
- 設定を実キーだけで変更し、音量・動き軽減・到達空域が再読込後も維持される。
- 不正JSONと範囲外保存を既定値へ復旧し、起動不能にしない。
- 設定画面の選択状態、値、操作説明を目視し、accessible nameからも同じ値を取得できる。

## 完成時ゲート

- 通常操作と自動操縦で全空域を通す
- 1280×720と640×800で主要画面がviewport内に収まる
- フレームp95 25ms未満、console error / warning 0件
- キーボードフォーカス、動的名称、音量、動き軽減、保存破損復旧
- 外部runtimeのない静的配布物とchecksum

## M3 第4空域ゲート

- 第3空域から第4空域へ遷移し、到達状況が保存される。
- 方向が一致する突風中だけ風受け帯が有効になり、Space解放中に張力を減らしながら上昇することが規則テストに現れる。
- 実キー入力で風受け上昇を行い、3片回収と着地まで到達する。
- 入口、発動中、勝利を目視し、左右帯、予告方向、上向き山形、凧、糸、片、`LIFTING`が判別できる。

## M3 第5空域ゲート

- 第4空域から第5空域へ遷移し、到達状況が保存される。
- 低すぎる／高すぎる張力では音門が横断を遮り、32〜68%では通過できることが規則テストに現れる。
- 実キー入力で門前の張力調律と左右2門の横断を行い、3片回収と着地まで到達する。
- 入口、共鳴通過、勝利を目視し、二門、張力範囲、破線／実線、共鳴輪、凧、糸、片、`IN TUNE`が判別できる。

## M3 第6空域ゲート

- 第5空域から第6空域へ遷移し、到達状況が保存される。
- 雲、下降気流、方向付き風受け、音門が既存と同じ規則で作動することを単体テストで固定する。
- 新規保存から実キー入力だけで全6空域18片を回収し、六空の終演まで到達する。console error / warningは0件とする。
- 入口、音門通過、終演を目視し、全領域、凧、糸、片、張力、終演文に欠けや重なりがない。

## 未測定として残すもの

実スピーカー、実スクリーンリーダー、低性能物理端末、人間の初見操作感。

## v11.1改善ゲート

- 第1空域で最初の突風前にSpace解放ガイドがARIAと画面へ現れ、実キー解放後に張力55%未満のplaying状態を維持する。
- 張力計の百分率、安全域、危険域が1280×720画像で片、凧、予告を隠さず判別できる。
- 保存済み解除上限から左右キーで過去空域を選び、Enterで選択空域を開始できる。未解除空域へは進めない。
- 単体、構文、build、全Chrome E2E、配布物監査を再実行する。
