# v11.0 self-review

実施日: 2026-11-06

## 証拠に基づく評価

- 最初の30秒: タイトル下部には巻く／緩める操作があるが、開始直後の強い中央メッセージは`HOLD SPACE TO CLIMB`だけだった。指示どおり押し続けると最初の突風で張力が急増し、約6秒で切断し得る。失敗から規則は推測できるが、「予告を読み入力を切り替える」という中核を事前に教えられていない。
- 予告と張力: 風向予告と張力棒は視認できる一方、棒に数値、安全域、危険域がなく、Spaceを離した結果が安全になったかを瞬時に確信しにくい。
- 空域間の反復: 6空域の追加規則は固有だが、保存後は最遠空域からしか始められず、過去空域の比較・練習・再訪ができない。完成したコンテンツの再利用性を下げている。
- 固定解法: 片の順序は固定だが、突風周期に対して直行、待機、安全地帯、風受けを選べるため、許容範囲。v11.1では経路や物理を変更しない。
- 音と手触り: 回収、門、切断、勝利に反応音はあるが、最重要の突風予告には音がない。視線が片や凧へ向いている時の切替合図として不足している。
- 終演: 短いが18片と6空域を明示し、2〜4分想定の規模に合う。演出追加より初回理解と再訪性の改善効果が高い。
