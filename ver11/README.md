# GALE THREAD v11.0

突風の予告を読み、糸を巻く／緩める判断で三つの風鈴片を集めて着地点へ戻る、リアルタイム凧航行ゲーム。

- M2 段階導入: 進行中。第2空域「CLOUD LEE」と横風を遮る雲帯を実装済み

## 起動

```sh
cd ver11/game
npm install
npm run dev
```

Enterで開始する。左右キーまたはA/Dで凧を操り、Spaceを押している間は糸を巻いて上昇する。Spaceを離すと糸を緩めて下降する。空の帯に表示される突風予告中に進路を整え、突風が吹いている間は巻き続けない。三つの風鈴片を集めたら、地上中央の着地点へ降りる。第2空域では銀色の雲帯へ入ると突風を遮れる。Escapeでポーズ、Rで再挑戦する。

`npm run verify`で規則テスト、構文検査、production build、Chrome E2Eをまとめて実行する。E2Eは実キー入力でポーズ、糸切断、再挑戦、第1・第2空域の6片回収、雲帯利用、着地までを検証する。
