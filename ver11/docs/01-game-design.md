# Game design

## M1ループ

1. 地上から凧を上げる。
2. 左右入力で次の風鈴片へ寄せ、Spaceで巻いて上昇する。
3. 画面上部の予告が示す風向と強さを読む。
4. 突風中は糸を緩めて張力を逃がすか、短く巻いて位置を優先する。
5. 三片を集めた後、Spaceを離して中央の着地点へ戻る。

## 規則

- 凧は左右入力、風、糸の復元力で横移動する。
- Space保持で上昇し張力が増える。解放で下降し張力が減る。
- 突風中の巻き上げは張力増加が大きい。張力100%が一定時間続くと切断。
- 風鈴片は高度ごとに置かれ、接触で回収する。
- 3片回収後、地面近くの着地帯へ低速で入ると勝利する。
- Rは即時再挑戦、Escapeはポーズ。

## M1調整仮説

- 予告1.2秒、突風1.8秒なら反応ではなく事前の横位置調整ができる。
- 張力は瞬間上限でなく猶予時間を持たせ、短いリスク選択を許す。
- 片は低・中・高の順に置き、上昇方法を自然に学ばせる。
