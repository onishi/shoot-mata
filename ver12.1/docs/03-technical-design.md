# Technical design

- Vite + vanilla ES modules + Canvas 2D。外部runtime依存を持たない。
- `src/model.js`はDOMから独立した純粋な状態遷移とする。
- 室は`LEVELS`の鍛冶師、種、受け口、壁、固定鉄塊、軸極データとして定義し、種の任意`respondsTo`で反応する磁場を限定する。状態は`levelIndex`で現在室を参照する。
- 盤面更新は入力単位で決定的。描画補間だけrequestAnimationFrameを使う。
- 現在磁場へ反応する金属種の移動候補を先に全件計算し、重複先、壁、軸極、静止種との競合を除いて同時適用する。反応しない極性種は静止種として衝突解決へ含める。軸極は移動元と移動先から進入軸を判定する。
- Node testで規則、衝突、収容、室進行、各室の既知解を固定する。
- Playwrightは実キー入力、タイトル、反転、再挑戦、既知解、室進行、勝利、ポーズをChromeで検証する。
- Canvasへ動的なaccessible nameを設定し、状態、極性、収容数、操作を伝える。
- `preferences.js`がlocalStorage境界を担当する。保存値は室数と0.1刻みへ正規化し、JSON破損、型不正、範囲外、storage例外では既定値を返す。
- 保存対象は到達済みの最も先の室、音量、動き軽減。盤面途中状態は保存せず、再開時は到達室の初期盤面へ戻して決定性を保つ。
- Canvas論理解像度は960×720の4:3。中央960×540に既存ゲーム面を置き、上下90pxを筐体マーキーと操作帯へ固定する。CSSも4:3を維持してviewportへ収める。
