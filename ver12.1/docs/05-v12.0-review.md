## Independent critique

1. **反転前の因果が読めない**: HUDは現在の`PULL/PUSH`を強調するが、ボタンを押すと逆極性へ切り替わってから種が動く。移動軸の優先、衝突、極性種の休拍は実行後の軌跡か文章からしか分からず、初見の失敗が計画ではなく記号の解読になりやすい。
2. **視認性は静止状態の識別に偏る**: 種、受け口、鉄塊、軸極は見分けられる一方、「今ここで押すと何が起きるか」という最重要情報が盤面にない。観客も立ち位置の巧拙を反転後まで評価できない。
3. **既知解のテンポは短い**: 2方針とも3分下限を下回る。ただし固定ルートなし探索は14分23.6秒で、盤面を読む時間が体験の大半を占める。ここで室数や待ち時間を増やすより、読みを支えることを優先する。
4. **人間の初見理解と音の主観評価は未確認**: 自動検証で代替できないため未達のまま維持する。

## Selected improvement

各レバー位置で次の反転結果を常時予告する。次極性をHUDへ明記し、全未収容種について、移動は点線と着地点、収容／TEMPERは真鍮の強調、衝突停止は外周と×、極性休拍は灰色の外周と×で示す。予告は本番の反転と同じ純粋計算を共有し、画面専用の近似規則を作らない。スクリーンリーダー向け名称にも各種の予告結果を含める。

代替案の長文チュートリアルはプレイ中の比較を助けず、軌跡だけの強調は失敗後にしか働かず、解答手順表示は判断を奪うため採用しない。
