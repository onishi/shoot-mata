## 起動

```sh
cd ver12.2/game
npm install
npm run dev
```

Cまたは5でコインを投入し、Enterで開始する。コイン前のアトラクトは第1室の移動、磁極反転、2種収容を6.5秒で自動実演する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。反転前は次の極性と各種の移動先を点線で予告し、収容／TEMPERは真鍮、停止／休拍は外周と×で示す。Uは室ごとに一度だけ、直前の反転前へ盤面・鍛冶師・得点・FORGE HEAT・TEMPERをまとめて戻す。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば次の室へ進む。全室の菱形`TEMPER`へ種を通すと室ごとに一度だけ3000〜6000点を得るが、安全解より多くFORGE HEATを消費する。第2室の銀色の固定鉄塊は鍛冶師と種を止める。第3室の縞極は示された軸から入る種だけを止め、鍛冶師は通れる。第4室の内向き印を持つ種はPULLだけに反応し、第5室ではその休拍と鉄塊・軸極を組み合わせる。第6室は外向き印のPUSH限定種も加え、7反転の安全解または9反転のTEMPER解で最終炉を完成させる。1種収容で1000点、室完成で5000点、少ない反転に最大1750点のボーナスが入る。室ごとのFORGE HEAT上限までに完成できないとゲームオーバーになり、Cで追加クレジットを投入して同室を室開始得点から続行するか、Enterで成績入力へ進む。Rはプレイ中だけ現在室を得点ごと戻し、Escapeでポーズする。

最終炉の完成後はEnterで成績へ進み、上下で文字、左右で桁を選び、Spaceで3文字のイニシャルを登録する。ローカル上位5件は自動保存され、ランキングのEnterでアトラクトへ戻る。本編ではFM音源風の短いBGMが流れ、開始、室完成、最終炉、ランキングは固有ジングルで区別される。`M`で設定を開き、上下で音量／動き軽減を選び、左右で変更する。設定と到達済みの最も先の室は自動保存される。`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。

`npm run audit:campaign`は、1入力850ms、各室6秒の盤面確認、結果4秒の確認を論理時計で積算しながら全6室の安全／TEMPER入力を実ブラウザへ送り、室別時間と180フレーム性能を`docs/evidence/m4-campaign-audit.json`へ記録する。ターン制のため入力間をCI上では短縮し、環境のsleepや負荷で人間ペース換算が揺れないようにしている。

`npm run audit:discovery`は室固有の入力列を持たず、全室へ同じ幅優先探索規則を適用してTEMPER込みの経路をその場で導出する。各室の初回反転を観察してUNDOする学習試行、盤面確認45秒、反転結果確認12秒を論理時計へ積算し、初見相当8〜15分の代替証拠を`docs/evidence/m4-discovery-audit.json`へ残す。探索器は規則と盤面を正確に知るため、実人間テストの代用ではなくルート暗記を外した到達性上限として扱う。

`npm run audit:audio`はChromeのOfflineAudioContextで全12効果音・ジングルと4秒BGMをPCMへ描画し、無音・ピーク・クリップを`docs/evidence/m4-audio-waveform-audit.json`へ記録する。`npm run audit:release`は既存`dist`を削除してクリーンビルドし、全ファイルのSHA-256を記録後、production previewで版表示と6室通しを検証する。
