# LODESTAR FORGE v12.0

磁極を反転して三つの金属種を同時に押す／引くことで、炉床の受け口へ導くターン制磁力パズル。

## 起動

```sh
cd ver12/game
npm install
npm run dev
```

Cまたは5でコインを投入し、Enterで開始する。コイン前のアトラクトは第1室の移動、磁極反転、2種収容を6.5秒で自動実演する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば次の室へ進む。第2室の銀色の固定鉄塊は鍛冶師と種を止める。第3室の縞極は示された軸から入る種だけを止め、鍛冶師は通れる。第4室の内向き印を持つ種はPULLだけに反応し、第5室ではその休拍と鉄塊・軸極を組み合わせる。第6室は外向き印のPUSH限定種も加え、7反転で最終炉を完成させる。1種収容で1000点、室完成で5000点、少ない反転に最大1750点のボーナスが入る。室ごとのFORGE HEAT上限までに完成できないとゲームオーバーになり、Cで追加クレジットを投入して同室を室開始得点から続行するか、Enterで成績入力へ進む。Rはプレイ中だけ現在室を得点ごと戻し、Escapeでポーズする。

最終炉の完成後はEnterで成績へ進み、上下で文字、左右で桁を選び、Spaceで3文字のイニシャルを登録する。ローカル上位5件は自動保存され、ランキングのEnterでアトラクトへ戻る。本編ではFM音源風の短いBGMが流れ、開始、室完成、最終炉、ランキングは固有ジングルで区別される。`M`で設定を開き、上下で音量／動き軽減を選び、左右で変更する。設定と到達済みの最も先の室は自動保存される。`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。
