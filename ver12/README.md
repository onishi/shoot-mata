# LODESTAR FORGE v12.0

磁極を反転して三つの金属種を同時に押す／引くことで、炉床の受け口へ導くターン制磁力パズル。

- M2 製品基盤: 完了。3室、段階導入、音量・動き軽減設定、到達室保存、破損保存復帰を実装済み

## 起動

```sh
cd ver12/game
npm install
npm run dev
```

Enterで開始する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば次の室へ進む。第2室の銀色の固定鉄塊は鍛冶師と種を止める。第3室の縞極は示された軸から入る種だけを止め、鍛冶師は通れる。第4室の内向き印を持つ種はPULLだけに反応する。Rで現在の室をやり直し、Escapeでポーズする。

`M`で設定を開き、上下で音量／動き軽減を選び、左右で変更する。設定と到達済みの最も先の室は自動保存される。`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。
