# LODESTAR FORGE v12.0

磁極を反転して三つの金属種を同時に押す／引くことで、炉床の受け口へ導くターン制磁力パズル。

## 現在地

- M0 白紙企画比較・独立性確認: 完了
- M1 中核縦切り: 完了。1室、移動、磁極反転、3種、受け口、再挑戦を実装・検証済み
- 単体6/6、構文検査、production build、Chrome E2E 2/2、依存監査に合格

## 起動

```sh
cd ver12/game
npm install
npm run dev
```

Enterで開始する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば完成。Rで室をやり直し、Escapeでポーズする。

`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。

## 独立性

v12は白紙から制作する新作であり、v1〜v11のコード、素材、文章、固有名詞、世界観、数値、画面構成、ゲームシステムを使用しない。
