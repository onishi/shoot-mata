磁極を反転して三つの金属種を同時に押す／引くことで、炉床の受け口へ導くターン制磁力パズル。

## 起動

```sh
cd ver12/game
npm install
npm run dev
```

Cまたは5でコインを投入し、Enterで開始する。コイン前のアトラクトは第1室の移動、磁極反転、2種収容を6.5秒で自動実演する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。Uは室ごとに一度だけ、直前の反転前へ盤面・鍛冶師・得点・FORGE HEAT・TEMPERをまとめて戻す。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば次の室へ進む。全室の菱形`TEMPER`へ種を通すと室ごとに一度だけ3000〜6000点を得るが、安全解より多くFORGE HEATを消費する。第2室の銀色の固定鉄塊は鍛冶師と種を止める。第3室の縞極は示された軸から入る種だけを止め、鍛冶師は通れる。第4室の内向き印を持つ種はPULLだけに反応し、第5室ではその休拍と鉄塊・軸極を組み合わせる。第6室は外向き印のPUSH限定種も加え、7反転の安全解または9反転のTEMPER解で最終炉を完成させる。1種収容で1000点、室完成で5000点、少ない反転に最大1750点のボーナスが入る。室ごとのFORGE HEAT上限までに完成できないとゲームオーバーになり、Cで追加クレジットを投入して同室を室開始得点から続行するか、Enterで成績入力へ進む。Rはプレイ中だけ現在室を得点ごと戻し、Escapeでポーズする。

最終炉の完成後はEnterで成績へ進み、上下で文字、左右で桁を選び、Spaceで3文字のイニシャルを登録する。ローカル上位5件は自動保存され、ランキングのEnterでアトラクトへ戻る。本編ではFM音源風の短いBGMが流れ、開始、室完成、最終炉、ランキングは固有ジングルで区別される。`M`で設定を開き、上下で音量／動き軽減を選び、左右で変更する。設定と到達済みの最も先の室は自動保存される。`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。

`npm run audit:campaign`は、1入力850ms、各室6秒の盤面確認、結果4秒の確認を論理時計で積算しながら全6室の安全／TEMPER入力を実ブラウザへ送り、室別時間と180フレーム性能を`docs/evidence/m4-campaign-audit.json`へ記録する。ターン制のため入力間をCI上では短縮し、環境のsleepや負荷で人間ペース換算が揺れないようにしている。

## 独立性

v12はv1〜v11のゲーム内容を企画・設計の参考にせず、白紙から制作する新作である。白紙から選んだ結果としてジャンルや一般的な仕組みが過去作と似ることは妨げない。一方、過去作のコード、素材、文章、固有名詞、世界観、ステージデータ、数値を直接コピーまたは改変して流用しない。
