# LODESTAR FORGE v12.0

磁極を反転して三つの金属種を同時に押す／引くことで、炉床の受け口へ導くターン制磁力パズル。

## 現在地

- M0 白紙企画比較・独立性確認: 完了
- M1 中核縦切り: 完了。1室、移動、磁極反転、3種、受け口、再挑戦を実装・検証済み
- M2 製品基盤: 進行中。第2室「IRON BRAKE」と室進行を実装し、固定鉄塊で不要な種だけを止める判断を追加
- 単体9/9、構文検査、production build、Chrome E2E 3/3、依存監査に合格

## 起動

```sh
cd ver12/game
npm install
npm run dev
```

Enterで開始する。矢印キーまたはWASDで鍛冶師を移動し、Spaceで磁極を反転する。青い`PULL`では金属種が鍛冶師へ、橙の`PUSH`では鍛冶師から離れる方向へ一枡進む。三つを金色の受け口へ収めれば次の室へ進む。第2室の銀色の固定鉄塊は鍛冶師と種を止める。Rで現在の室をやり直し、Escapeでポーズする。

`npm run verify`で単体テスト、構文検査、production build、Chrome E2Eをまとめて実行する。
