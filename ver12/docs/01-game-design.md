# Game design

## 規則

- 9×7の炉床。鍛冶師は矢印キー/WASDで一枡移動する。壁と未収容の金属種は通れない。
- Spaceで`PULL`と`PUSH`を反転し、その直後に全未収容種が一枡動く。
- `PULL`は鍛冶師へ近づく軸、`PUSH`は遠ざかる軸を選ぶ。縦横差が同じなら横を優先する。
- 壁、他の種、同じ移動先との衝突が起きる種はその場に留まる。結果は同時解決する。
- 種が空いている受け口へ入ると固定され、それ以降は動かない。
- 銀色の固定鉄塊は鍛冶師と種の両方を止める。磁場は鉄塊を動かさない。
- 青緑環と橙縞の固定極は、縞と平行な軸からそのセルへ入る種だけを止める。鍛冶師と直交方向から入る種は通れる。
- 内向きシェブロンを持つ極性種は`PULL`だけに反応し、`PUSH`ではその場に留まる。停止した種は他の種の移動を通常どおり塞ぐ。
- 3個すべてを収容すると勝利。Rで初期状態へ戻る。Escapeでポーズする。

## M1の学習順

1. タイトルで「MOVE TO AIM / SPACE TO FLIP」を伝える。
2. 最初の反転で全種が同時に反応し、磁力線と移動軌跡を見せる。
3. 1個を収容すると受け口が閉じ、残りだけが反応することを見せる。
4. 3個収容で完成手数と反転数を返す。

## M2第2室の学習順

1. 第1室完成後、Enterで盤面と室名を切り替え、固定鉄塊の目的を一文で示す。
2. 初期位置右隣から最初のPUSHを行うと、青い種だけが収容され、橙の種は固定鉄塊で止まる。
3. 鍛冶師がさらに右へ移動してPULL/PUSHを続けると、残る2種を別方向の受け口へ収容できる。
4. 第1室の2反転に対して第2室は3反転を要求し、「全部動かす」から「一部を止める」へ判断を発展させる。

## M2第3室の学習順

1. 第2室から進むと、固定鉄塊に加えて一軸だけを遮る縞極を示す。
2. 最初のPUSHで青い種を収容し、橙の種を鉄塊で止める。
3. 鍛冶師が壁を回り込んだPULLでは、橙の種を壁、白い種を横軸極で同時に待たせる。
4. 次のPUSHで待たせた2種を異なる受け口へ同時収容し、全体移動と選択的停止を組み合わせる。

## M3第4室の学習順

1. 第3室から進むと、内向きシェブロンを持つ青い極性種を示す。
2. 最初のPUSHで通常種2個だけが収容され、極性種が動かないことを盤面とaccessible nameで返す。
3. PULLで極性種を動かした後、反応しないPUSHを立ち位置調整の休拍として使う。
4. 次のPULLで中央の受け口へ収容する4反転解とし、交互反転を制約から計画資源へ発展させる。

## 面白さの仮説

- 鍛冶師の移動自体は盤面を変えないため、次の反転を安全に試算できる。
- 全種同時操作により、局所最短では解けない順序判断が生まれる。
- 極性が交互にしか変わらないため、同じ位置から同じ方向を連打できず、立ち位置変更が必要になる。

## 失敗と復帰

進行不能を自動断定しない。いつでもRで即再開できる。M2で手数巻き戻しを検討する。
