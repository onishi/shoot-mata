# Quality plan

## M1合格条件

- タイトルから3種収容の結果まで通常キーと自動操縦の両方で到達できる。
- PULL/PUSH、同時移動、壁・種衝突、受け口固定が決定的テストに合格する。
- R再挑戦、Escapeポーズから入力不能にならない。
- 1280×720のタイトル、反転中、完成画面を目視し、文字切れ、重なり、判別不能がない。
- production buildとconsole error 0件に合格する。

## 後続監査

M2で保存破損、音量、動き軽減を追加する。M4で640×800、Tab操作、実スクリーンリーダー相当の名称、180フレーム性能、配布物checksumを監査する。
