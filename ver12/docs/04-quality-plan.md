# Quality plan

## M1合格条件

- タイトルから3種収容の結果まで通常キーと自動操縦の両方で到達できる。
- PULL/PUSH、同時移動、壁・種衝突、受け口固定が決定的テストに合格する。
- R再挑戦、Escapeポーズから入力不能にならない。
- 1280×720のタイトル、反転中、完成画面を目視し、文字切れ、重なり、判別不能がない。
- production buildとconsole error 0件に合格する。

## 後続監査

M2で保存破損、音量、動き軽減を追加済み。M4で640×480、Tab操作、実スクリーンリーダー相当の名称、180フレーム性能、配布物checksumを監査する。

## M2第2室の合格条件

- 第1室の完成からEnterで第2室へ進み、Rが第2室だけを初期化する。
- 最初の反転では収容が1種に留まり、同じ反転で固定鉄塊が別の種を止める。
- 通常キーの既知解で3反転後に全種を収容できる。
- 固定鉄塊が種および鍛冶師を止める規則を単体テストで固定する。
- 1280×720の固定鉄塊作動時と完成画面を目視する。

## M2第3室の合格条件

- 第2室から通常キーで進み、固定鉄塊、壁、横軸極で複数種を選択的に待たせられる。
- 軸極が指定軸の種だけを止め、鍛冶師と直交方向の種を通す規則を単体テストで固定する。
- 通常キーの既知解で3反転後に全種を収容できる。
- 1280×720の軸極作動時と3室完了画面を目視する。

## M2製品基盤の合格条件

- 音量と動き軽減をキーボードだけで変更でき、再読込後も値を保持する。
- 到達した室を保存し、再読込後は進行を失わず、その室の初期状態から安全に始められる。
- 壊れたJSON、型不正、範囲外、storage例外で起動不能にならず既定値へ復帰する。
- 1280×720の設定画面を目視し、現在値、選択行、操作を判別できる。

## M3第4室の合格条件

- PULL限定種がPUSHでは静止し、PULLでは通常の衝突規則に従って動くことを単体テストで固定する。
- 最初のPUSHで通常種2個だけを収容し、通常キーの既知解で4反転後に全種を収容できる。
- 第1〜第3室、設定、到達室保存が非退行である。
- 1280×720の極性種停止時と4室完了画面を目視し、印、極性、収容数、完成表示を判別できる。

## M3本編完成の合格条件

- 第6室でPULL限定種とPUSH限定種を鉄塊・軸極と組み合わせ、既知解が7反転で終演へ到達する。
- 第1室から第6室まで状態注入なしの実キーE2Eで通し、各室進行と到達室保存を非退行にする。
- 960×720の4:3論理画面へ移行し、最終炉と終演を1280×720 viewportで採取して比較目視する。
- `arcade-authenticity.md`と受入IDを追加し、未実装のコイン、アトラクト、得点、ランキング、BGMをM4必須として残す。

## M4ゲームオーバー／コンティニューの合格条件

- 各室のFORGE HEAT上限は既知解へ4反転の余裕を持ち、既存6室通しを妨げない。
- 上限到達でBGMを止め、ゲームオーバー画面とジングルを出し、Rでクレジットを迂回できない。
- C投入後のEnterで同室を室開始得点から再開し、クレジット消費とコンティニュー回数を記録する。
- コンティニューしない場合はEnterで成績入力、ランキング、アトラクトまで到達できる。
- 1280×720のゲームオーバーとコンティニュー待ちを比較目視する。

## M4通し時間・性能監査

- `npm run audit:campaign`は通常の高速回帰と分離し、1入力850ms、各室6秒の盤面確認、結果4秒の確認を固定した人間相当ペースで新規保存の6室を通す。
- コイン投入から最終炉、室別滞在、入力数、最大無入力時間、最終得点を`m4-campaign-audit.json`へ残す。既知解3〜6分を下回る場合はM4を完了せず、短い試作感を改善する。
- 180連続フレームはp95 20ms未満、最大25ms未満、25ms超0、50ms以上のLong Task 0を合格条件とする。
- 2026-11-07の実測は103.4秒、56入力、最大無入力6秒、53,750点で時間目標未達。性能は平均16.67ms、p95 16.7ms、最大16.8ms、25ms超0、Long Task 0で合格した。

## M4初見相当の探索監査

- `npm run audit:discovery`は室固有の既知入力列を持たず、全室へ同じ幅優先探索規則を適用し、TEMPER点灯と完成を満たす経路を現在の盤面定義から導出する。
- 各室の最初の反転は結果観察後に一手UNDOし、盤面確認45秒、反転結果確認12秒、入力850ms、結果確認4秒を論理時計へ積算する。初見相当の目標はコイン投入から最終炉まで8〜15分とする。
- 2026-11-08の実測は14分23.6秒、96操作、UNDO 6回、失敗0、76,500点で時間枠に合格した。第5・第6室はそれぞれ51,944・53,484状態を展開し、後半の探索負荷が高いことも確認した。
- 探索器は正確な規則と盤面状態を利用するため、人間の誤読や視線誘導を測れない。人間の初見理解そのものは未確認のまま残し、本監査は固定ルート暗記を外した到達性と論理時間上限の代替証拠に限定する。

## M4実波形・配布物監査

- `npm run audit:audio`はChrome OfflineAudioContextで全12効果音・ジングルと4秒BGMを44.1kHz PCMへ描画する。各音は100サンプル超、BGMは10,000サンプル超が0.0001を上回り、ピーク1.0未満、クリップ0を合格条件とする。
- 2026-11-08の実測は効果音・ジングル最大ピーク0.022224、BGM最大ピーク0.012004、全音クリップ0。全状態別音とBGMが非無音だった。
- `npm run audit:release`は既存`dist`を削除してからbuildし、全ファイルのbytesとSHA-256を記録する。生成物だけをpreviewし、v12.0表示、アトラクト、コイン、全6室、最終炉、HTTPエラー0を確認する。
- 2026-11-08の配布物は3ファイル・32,140 bytes。安全経路53,750点で第6室の終演へ到達し、配布画面`m4-release-attract.png`も目視合格した。
