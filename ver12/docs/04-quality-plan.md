# Quality plan

## M1合格条件

- タイトルから3種収容の結果まで通常キーと自動操縦の両方で到達できる。
- PULL/PUSH、同時移動、壁・種衝突、受け口固定が決定的テストに合格する。
- R再挑戦、Escapeポーズから入力不能にならない。
- 1280×720のタイトル、反転中、完成画面を目視し、文字切れ、重なり、判別不能がない。
- production buildとconsole error 0件に合格する。

## 後続監査

M2で保存破損、音量、動き軽減を追加済み。M4で640×800、Tab操作、実スクリーンリーダー相当の名称、180フレーム性能、配布物checksumを監査する。

## M2第2室の合格条件

- 第1室の完成からEnterで第2室へ進み、Rが第2室だけを初期化する。
- 最初の反転では収容が1種に留まり、同じ反転で固定鉄塊が別の種を止める。
- 通常キーの既知解で3反転後に全種を収容できる。
- 固定鉄塊が種および鍛冶師を止める規則を単体テストで固定する。
- 1280×720の固定鉄塊作動時と完成画面を目視する。

## M2第3室の合格条件

- 第2室から通常キーで進み、固定鉄塊、壁、横軸極で複数種を選択的に待たせられる。
- 軸極が指定軸の種だけを止め、鍛冶師と直交方向の種を通す規則を単体テストで固定する。
- 通常キーの既知解で3反転後に全種を収容できる。
- 1280×720の軸極作動時と3室完了画面を目視する。

## M2製品基盤の合格条件

- 音量と動き軽減をキーボードだけで変更でき、再読込後も値を保持する。
- 到達した室を保存し、再読込後は進行を失わず、その室の初期状態から安全に始められる。
- 壊れたJSON、型不正、範囲外、storage例外で起動不能にならず既定値へ復帰する。
- 1280×720の設定画面を目視し、現在値、選択行、操作を判別できる。
