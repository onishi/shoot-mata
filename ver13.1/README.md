# RINGWARD v13.1

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13.1/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

v13.0のM4横断品質をbaselineとして固定し、M5最初の独立批評を完了した。初回の投擲・往路・復路・回収を行動に追従する短いコーチへ変え、鐘へ迫る敵を危険線と`!`で示し、回収失敗後の再投擲待ちを円形ゲージで見せる。全17波説明には「きっかけ→結果」の規則帯を追加した。新規Chromeのv13.1版確認付き横断監査は、破損保存復旧、動き軽減ON、投擲`Z`、コンティニュー1回のまま15.55分で全18波三陣と6守護者を完走し、60fps、console error 0、勝利成績まで合格した。次はv13.2で戦略の深さ、終盤、得点選択、再挑戦価値を独立批評する。
