# RINGWARD v13.2

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13.2/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

v13.1をbaselineとしてM5第二批評を完了した。危険線内の撃破を2倍得点にし、CHAIN 4/8へECHO DRIVE節目を追加して、安全完走と危険な高得点狙いを分けた。最終守護者は第2封印で逆歩、第3封印で投擲反応を再構成し、終演とランキングへC〜S成績を保存する。クリーン配布物6ファイル82,998 bytesのSHA-256、14公開経路、ローカル配布候補のアトラクト→コイン→開始を監査済みで、現在は公開前Release Candidate。次はPagesへ公開し、本番URLと旧版保持を独立再監査する。
