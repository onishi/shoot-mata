# v13.2 第二批評 — 戦略・終盤・再挑戦価値

## v13.1 baseline

- 新規Chrome横断: 15.55分、全18波×三陣・6守護者、コンティニュー1回、BELL 3、8,637,450点、60fps、console error 0。
- 得点: 連続回収で倍率は上がるが節目がなく、安全に最接近敵を倒す方針と危険を取る方針が明示的に分かれていない。
- 終盤: 第18波は全8種を再構成する一方、最終守護者は過去5体と同じ「予告移動→往路で開封→復路で破壊」の速度違いに留まる。
- 再挑戦: 順位は得点、到達、コンティニュー数を残すが、完走品質を一目で比較する共通ランクがない。
- 非退行条件: 習熟14〜20分、初見代理18〜28分、18波三陣と6守護者、筐体フロー、2 viewport全画面、60fps、保存・設定・音響を維持する。

## 独立批評

1. 危険線は失敗原因を示すだけで、そこまで引き付ける腕前に報酬がなく、安全な最接近順がほぼ常に得になる。
2. CHAINは連続値だけで、観客が「いま節目を越えた」と理解できる得点上の山場がない。
3. RING MATRIARCHが既習規則を組み替えず、最終試験の通常波より攻略の種類が減る。
4. 最終得点だけでは、無傷、ノーコンティニュー、連続回収、危険撃破という異なる上達目標が伝わらない。

## 採用した改善

- 危険線内の敵への命中・撃破を`DANGER STRIKE ×2`とし、撃破数を成績へ追跡する。安全な早撃ちと、鐘を危険にさらす高得点待ちを別方針にした。
- CHAIN 4と8へ`ECHO DRIVE I/II`の節目ボーナスとHUD表示を追加した。試作では槌速度も最大20%上げたが、習熟12.08分まで短縮して規模契約を破ったため、テンポを壊さない得点節目へ修正した。
- 最終守護者の第2封印はMIRRORの三歩目静止を、第3封印はCHORISTERの投擲反応移動を再構成する。第1封印の予告周回と合わせ、三段階が異なる判断を要求する。
- 完走、鐘、コンティニュー、最大CHAIN、危険撃破からC/B/A/Sを算出し、終演と保存ランキングへ表示する。通常の安全完走はB、BELL 2以上かつCHAIN 8でA、無傷・ノーコンティニュー・CHAIN 16・危険撃破12でSとした。
