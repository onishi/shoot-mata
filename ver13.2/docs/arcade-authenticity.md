# Arcade authenticity

- 想定筐体: 1人用アップライト、8方向レバー、響槌ボタン、START、コイン。
- 画面: 4:3、640×480論理解像度、15kHz風の太い輪郭と限定色。
- 1クレジット: 習熟14〜20分、初見18〜28分。6幕、コンティニューあり。
- 観客情報: SCORE、CHAIN、BELL耐久、残敵、響槌の往路／復路、接近方位を常時表示。
- フロー目標: 自動実演、INSERT COIN、START、遊び方、6幕、ゲームオーバー／コンティニュー、成績入力、上位5件、アトラクト復帰。
- 10秒: 移動か投擲。30秒: 命中、回収、鐘への危険のうち2つ以上。
- 再挑戦: 復路撃破、連続PERFECT CATCH、無傷、早期撃破、幕別得点。
- M4筐体後半: 10秒の敗北カウント、追加クレジットによる失敗波の開始得点からの再開、方向＋響槌ボタンだけの3文字入力、保存される上位5件、12秒またはボタンでのアトラクト復帰を接続した。新規Chromeの製品キーだけで全経路とconsole error 0を確認し、カウントとランキングを1280×720で比較目視した。
- M4音響: 6幕へ音域、テンポ、アクセントの異なるFM音源風変奏を割り当て、場面転換時に拍頭から切り替える。Chromeの48kHz実PCMで全27効果音、全曲、最悪重畳を監査し、無音欠落、非有限値、クリップがなく、ポーズと非プレイ状態では停止することを確認した。
- M4横断: 新規Chromeで破損保存を復旧し、動き軽減ON、響槌`Z`再配置のまま14.69分で全18波三陣と6守護者を完走した。60.00fps、BELL 1、勝利後`BBB`首位、アトラクト復帰、console error 0に合格した。筐体フロー12状態を640×480と1280×720で比較し、遠目の状態、操作表示、得点、危険、結果に切れ・重なり・判別不能がないことを確認した。
- M3第1・2幕: 通常波3回の学習を大型守護者の3段階復路封印へ再構成した。白い側方予告を待つか先回りする判断、大型シルエット、封印数HUD、専用ジングルにより、観客にも幕山場と進行が伝わることを640×480と1280×720で確認した。
- M3第4幕: 折返しに連動するREFRACTORの移動先を白いシェブロン、実移動を青白い同心演出と音で示した。第12波から第4守護者までを製品入力のみで到達し、鏡炉とPRISM EMPERORの大型輪郭、封印HUDが2 viewportで識別できることを確認した。
