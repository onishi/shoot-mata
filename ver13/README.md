# RINGWARD v13.0

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

M0の製品規模契約、M1の中核縦切り、M2の製品基盤を完了し、M3本編制作を進行中。第1幕の基本往復、BULWARK、高速RUSHERに続き、第2幕では方位を横移動するORBITERを単独導入し、既存敵との混成、第6波の3種同時山場まで連続プレイできる。各幕末には大型守護者DAWN WARDENとVORTEX REGENTが現れ、往路で封印を開き復路で破壊する3段階戦、段階ごとの方位・速度・横移動変化を攻略する。暁の社殿と灯籠渦の2背景、真鍮の鐘、固有シルエット、命中・破壊・回収演出を備える。無操作時はタイトルと自動実演を循環し、`C`でコイン投入、`ENTER`で保存地点、`N`で第1波から1クレジットを開始する。`S`のオペレーター設定から音量、動き軽減、左右／投擲キーを保存でき、到達波は再読込後にも復帰できる。FM音源風BGMと主要合成効果音も実装済み。残る4幕と4守護者、コンティニュー、ランキング、公開は後続マイルストーンで実装する。
