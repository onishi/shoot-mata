# RINGWARD v13.0

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

M0の製品規模契約、M1の中核縦切り、M2の製品基盤、M3の本編制作と実時間規模監査を完了し、M4の横断品質を進めている。6幕18波へ8種の敵を単独導入、混成、全種最終試験の順で配置し、各波は方位、距離順、反応方向が変わる三陣を連続攻略する。各幕末には往路で封印を開き復路で破壊する3段階の大型守護者が現れ、暁の社殿から星唱庭まで6つの固有背景、敵シルエット、命中・破壊・回収演出を備える。無操作アトラクト、コイン、START、コンティニュー、3文字成績入力、ローカル上位5件、設定・保存を一続きにした。決定的モデルの通しは習熟14.67分、初見代理18.29分、状態注入なしの実Chrome習熟通しは14.19分・BELL 1・console error 0で契約帯へ入り、全18波の三陣と6守護者を確認した。6幕ごとに音域、拍間隔、旋律輪郭を変えるFM音源風BGM変奏を実装し、Chromeの48kHz実PCMで27効果音、全6曲、最悪重畳、停止状態、音量0を監査した。全画面・性能・アクセシビリティ監査と公開は後続マイルストーンで実施する。
