# RINGWARD v13.0

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

M0の製品規模契約、M1の中核縦切り、M2の製品基盤を完了し、M3本編制作へ進む。第1波の基本往復、第2波のBULWARK、第3波の高速RUSHERを、暁の社殿、真鍮の鐘、固有シルエット、命中・破壊・回収演出を備えた完成表現の代表区間として連続プレイできる。無操作時はタイトルと自動実演を循環し、`C`でコイン投入、`ENTER`で保存地点、`N`で第1波から1クレジットを開始する。`S`のオペレーター設定から音量、動き軽減、左右／投擲キーを保存でき、到達波は再読込後にも復帰できる。FM音源風BGMと主要合成効果音も実装済み。全6幕、コンティニュー、ランキング、公開は後続マイルストーンで実装する。
