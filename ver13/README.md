# RINGWARD v13.0

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

M0の製品規模契約とM1の中核縦切りを完了し、M2を進行中。第1波の基本往復に続き、第2波では往路を防ぐBULWARKを復路で崩す。アトラクト、コイン、全6幕、音響、保存、ランキング、公開は後続マイルストーンで実装する。
