# RINGWARD v13.0

巨大な暁鐘の周囲を走り、投げた響槌の往路と復路で侵入者を打ち払い、帰還点へ自分から飛び込んで連撃をつなぐ一画面アクション。

## 起動

```sh
cd ver13/game
npm run serve
```

`http://127.0.0.1:4173` をPC版Chromeで開く。矢印キーで鐘の周囲を移動し、Spaceで響槌を投げる。Enterで開始、Pでポーズ、Rで再挑戦する。

## 現在地

M0の製品規模契約、M1の中核縦切り、M2の製品基盤、M3の本編制作と実時間規模監査、M4の横断品質を完了し、M5の独立批評へ進む。6幕18波へ8種の敵を単独導入、混成、全種最終試験の順で配置し、各波は方位、距離順、反応方向が変わる三陣を連続攻略する。各幕末には往路で封印を開き復路で破壊する3段階の大型守護者が現れ、暁の社殿から星唱庭まで6つの固有背景、敵シルエット、命中・破壊・回収演出を備える。無操作アトラクト、コイン、START、コンティニュー、3文字成績入力、ローカル上位5件、設定・保存を一続きにした。決定的モデルの通しは習熟14.67分、初見代理18.29分、状態注入なしの実Chrome習熟通しは14.19分で契約帯へ入った。M4横断監査は破損保存復旧、動き軽減ON、投擲`Z`再配置のまま14.69分・BELL 1で全18波三陣と6守護者を完走し、60fps、勝利後`BBB`成績、console error 0を確認した。主要12状態は640×480と1280×720の24画面で比較目視済みで、48kHz実PCMの27効果音・全6曲監査も合格した。公開はM5で実施する。
