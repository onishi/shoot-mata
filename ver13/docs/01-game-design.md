# Game design

## 中核ループ

プレイヤーは鐘の外周16位置を左右に走る。Spaceで現在位置から外向きに響槌を投げる。響槌は外縁で折り返し、投げた位置へ戻る。投擲中も走れるため、敵へ軌道を重ねる攻めと、帰還点へ戻って受け止める守りが競合する。

- 往路命中: 敵へ1ダメージ、100点。
- 復路命中: 敵へ2ダメージ、撃破点を2倍にする。
- PERFECT CATCH: 帰還時に投擲位置の隣接範囲へいれば連撃が増え、次の得点倍率が上がる。
- MISS: 受け止められないと連撃が切れ、短い再装填が発生する。
- 敵が中心へ達すると鐘の耐久が減る。耐久0でゲームオーバー。

## M1第1波

3方向から耐久2のMARCHERが近づく。正面から一度当てるだけでは止められず、同じ響槌の復路を重ねるか再投擲が必要。近い敵を確実に倒すか、遠い敵を往復で高得点撃破するかを選ぶ。

## M2第2波

MARCHER 1体とBULWARK 2体が異なる方位から進む。BULWARKの水色の前面装甲は最初の往路命中を無効化するため、響槌を最後まで戻して復路の2ダメージを重ねる必要がある。波間には色と攻撃方向を対応させた短い実演前説明を出し、ガード時は白い閃光、50点、`GUARD SHATTERED`表示で失敗ではなく折返し準備だと伝える。

## M2第3波

橙色のRUSHER 3体を単独導入する。MARCHERの約2倍で鐘へ迫る一方、耐久は1なので往路または復路の一撃で止まる。翼状の速度記号、距離をずらした3方向、`ONE CLEAN STRIKE`の波間説明により、硬い敵ではなく素早い照準切替の試験だと予告する。

## M3第2幕

- 第4波: 紫のORBITER 3体を単独導入する。各個体は白い側方記号を点灯してから隣の方位へ移る。現在位置への即射と、移動先へ先回りして復路を重ねる判断を作る。
- 第5波: MARCHER 2体とORBITER 2体を交互に置き、固定線を確実に処理するか、動く標的の移動後を狙うかを競合させる。
- 第6波: BULWARK、RUSHER、ORBITERを同時に出す最初の山場。接近の速い敵、復路が必要な敵、照準をずらす敵から最初に処理する脅威を選び、回収位置へ戻る。
- 灯籠渦の背景は青緑の地平、紫の回転灯、同心環を用い、第1幕と戦闘規則を保ちながら幕の切替を遠目にも示す。

## M3第3幕

- 第7波: 緑のDANCER 3体を単独導入する。耐久2で、往路を受けて生き残ると白緑の移動記号側へ1方位だけ跳ぶ。プレイヤーも同じ方向へ一歩追えば元の投擲を隣接回収でき、次投を新レーンへ合わせられる。
- 第8波: DANCERとBULWARK、RUSHERを混成し、命中後に追う標的、復路を維持する標的、即座に止める標的のリズムを切り替える。
- 第9波: DANCER、ORBITER、RUSHER、BULWARKを同時に出す第3幕山場。命中反応と時間予告という2種の横移動を区別し、最初の脅威を処理しながら連撃を保つ。
- 幕末のGALE SOVEREIGNは3つの復路封印と、段階ごとに速まる接近・横移動を持つ。天空風庭は青緑の高空、風旗、雲状の欄干を使い、前2幕とは異なる開放的な輪郭を作る。

## M3第4幕

- 第10波: 青白いREFRACTOR 3体を単独導入する。響槌が外縁で折り返すと全個体が白いシェブロン側へ一方位跳ぶため、現在位置でなく移動先へ投げ、復路2ダメージを置く。
- 第11波: REFRACTORとMARCHER、DANCERを混成し、折返し反応の先読み、固定線、往路命中反応の追従を切り替える。一度の折返しが全REFRACTORを同時に動かすため、次の投擲先も変化する。
- 第12波: REFRACTOR、RUSHER、BULWARK、ORBITER、DANCERの5種を同時に出す第4幕山場。投擲すること自体が敵配置を変えるため、即時脅威と次の復路線を両方選ぶ。
- 幕末のPRISM EMPERORは3つの復路封印と段階ごとの加速・方位変化を持つ。鏡炉は紫紅の炉、青白い吊鎖、溶融槽で閉鎖的な工業輪郭を作る。

## M3第5幕

- 第13波: 白銀のMIRROR 3体を単独導入する。プレイヤーが1方位走るたび全個体が逆方向へ1方位動くため、偶数方位差を縮めて交差線を自分で作ってから投げる。
- 第14波: MIRROR、DANCER、REFRACTORを混成し、レバー移動、往路命中、折返しという3種の異なる契機で変わる標的を区別する。
- 第15波: MIRROR、RUSHER、BULWARK、ORBITER、DANCER、REFRACTORの6種を同時に出す第5幕山場。投擲前の走路でMIRRORを揃えつつ、接近速度と投擲後の配置変化から最初の線を選ぶ。
- 幕末のTIDE ORACLEは3つの復路封印と段階ごとの加速・方位変化を持つ。月鏡庭は紺の夜空、銀門、対の反射円、水路で逆歩の主題を遠目にも示す。

## 発展

- M2: 装甲敵、高速敵、第1〜3波、失敗復帰、設定と進行保存を実装済み。続けて代表区間の音響と完成表現を確立する。
- M3: 第5幕15波・5守護者まで実装済み。続けて最終幕、固有環境、第6守護者、幕間、終演を制作する。
- M4: 筐体フロー、得点、ランキング、コンティニュー、音、性能、配布物。

## 難易度原則

画面外生成をせず、敵の方向と到達までを常時表示する。新規則は安全な単独導入の後に既存規則と組み合わせる。被弾原因は鐘の閃光、該当方位、耐久減少音で同時に返す。
