# Quality plan

## マイルストーンゲート

- M0: 3案比較、規模契約、筐体仕様、受入ID、非目標が揃う。
- M1: 実操作で照準、投擲、往路／復路、回収成功／失敗、敵撃破、鐘被弾、勝敗を確認する。
- M2: 3波と2敵種、設定、保存、失敗復帰を単体・実ブラウザで確認する。
- M3: 全6幕を通し、初見代理18〜28分、既知方針14〜20分を分離計測する。
- M4: 全筐体フロー、640×480と1280×720、60fps、音、アクセシビリティ、配布物を監査する。
- M5: 初回理解・視認性・テンポと、戦略・終盤・表現・再挑戦を別々に批評して改善する。

## M1検証

- `npm run verify`: 規則単体、構文検査。
- Chrome実キー: タイトル開始、移動、投擲、折返し、回収、撃破、勝利と敗北。
- 目視: 1280×720と640×480で主要状態、文字切れ、重なり、色だけに依存しない方向表示。

## M2途中検証

- 第1波を状態注入せず実キーだけで突破し、波間説明から第2波へ進む。
- 単体テストでBULWARKの往路無効化、装甲消費、復路撃破を固定する。
- `m2-wave-brief-1280x720.png`と`m2-guard-block-1280x720.png`で説明、装甲シルエット、攻撃色、反応表示を比較目視する。
- 設定は正常値、破損JSON、不正値、保存不能、キー重複を単体で固定し、Chrome実キーで変更、再読込、再配置後の投擲を確認する。
- `m2-settings-1280x720.png`と`m2-settings-640x480.png`で設定項目、値、選択、操作案内の切れ・重なりを目視する。
- 音イベント列で投擲、折返し、往路命中、復路撃破、回収、鐘被弾を単体固定する。実ChromeではOscillator発音を監査し、保存音量0%で0件、100%で発音とunity gain、ポーズ中の追加スケジュール0件、再開後の復帰、console error 0を確認する。
- アトラクトは単体でコイン必須、クレジット消費、決定的デモ、デモ割込みを固定する。実Chromeでは無操作デモ開始、`C`、CREDIT 1、保存地点START、新規START、console error 0を確認し、`m2-attract-1280x720.png`、`m2-demonstration-1280x720.png`、`m2-credit-start-640x480.png`を比較目視する。

## M3規模監査

- `npm run audit:campaign`は状態や敵を直接変更せず、製品の移動、投擲、波開始、守護者開始だけを120Hzの決定的モデルへ入力する。習熟は0.12秒判断・説明1.2秒、初見代理は0.2秒判断・説明6秒・17判断ごとの読取り停止として分離する。
- モデル監査は高速な規模下限と戦略偏りの回帰であり、実ブラウザ全編通しを代替しない。M3終了には新規開始、物理キー配送、実フレーム時間、console errorをChromeで測る。
- 三陣HUDとMIRROR静止は`m3-three-formation-hud-1280x720.png`、`m3-mirror-anchor-1280x720.png`、`m3-depth-browser-audit.json`で代表目視する。
- `npm run audit:browser-campaign`は新規Chromeプロファイルへ`C`、`N`、方向、投擲だけを送り、保存地点や状態注入を使わず全18波×三陣と6守護者、14〜20分、終演、console error 0を検査する。`m3-browser-campaign-audit.json`へ全遷移、`m3-browser-campaign-ending-1280x720.png`へ終演を残す。
