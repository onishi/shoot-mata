# Quality plan

## マイルストーンゲート

- M0: 3案比較、規模契約、筐体仕様、受入ID、非目標が揃う。
- M1: 実操作で照準、投擲、往路／復路、回収成功／失敗、敵撃破、鐘被弾、勝敗を確認する。
- M2: 3波と2敵種、設定、保存、失敗復帰を単体・実ブラウザで確認する。
- M3: 全6幕を通し、初見代理18〜28分、既知方針14〜20分を分離計測する。
- M4: 全筐体フロー、640×480と1280×720、60fps、音、アクセシビリティ、配布物を監査する。
- M5: 初回理解・視認性・テンポと、戦略・終盤・表現・再挑戦を別々に批評して改善する。

## M1検証

- `npm run verify`: 規則単体、構文検査。
- Chrome実キー: タイトル開始、移動、投擲、折返し、回収、撃破、勝利と敗北。
- 目視: 1280×720と640×480で主要状態、文字切れ、重なり、色だけに依存しない方向表示。
