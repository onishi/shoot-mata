# Decisions

## 2026-11-09 — M2代表表現は外部画像でなくCanvasベクターを深化する

- 比較: ラスターの単体スプライトへ置換／既存の単純図形を維持／限定色のCanvasベクターを背景からエフェクトまで一体で深化。
- 採用: 第1幕はCanvasベクターを深化し、社殿空間、陰影、非対称輪郭、装飾、モデル駆動エフェクトを同じ描画系で制作する。
- 理由: 640×480で輪郭と即時結果を強く保ち、決定的モデル検証と描画を分離したまま、1995年の2D基板らしい拡大耐性と統一感を得られる。制作速度だけを理由に単純図形を残さず、2 viewportの画面比較を完了条件にした。
- 結果: 初回目視で上端の戦闘物がHUDへ入る問題を検出し、戦闘半径を外周装飾の内側へ制限して再監査に合格した。M3はこの規格を幕差と主要動作へ展開する。

## 2026-11-14 — 通常波を三陣化し、待ち時間でなく再判断で製品時間を満たす

- 一陣の習熟代理は第12波まで4分54秒で、18波完走でも14分下限を大幅に割る見込みだった。
- 敵速度を落とす案と波間を長くする案は、無操作時間を増やすため不採用とした。各波の既存規則を、方位回転、距離順反転、反応方向反転を持つ三陣として連続させ、近い脅威と狙う順番を再評価させる案を採用した。
- 三陣化後の決定的通しは習熟14.67分、初見代理18.29分。MIRRORの偶奇進行不能と最終守護者の常時警告も同じ監査で発見・修正した。
- モデル時間だけでM3完了とはせず、次回は状態注入なしの実ブラウザ習熟通しで同等性を確認する。
