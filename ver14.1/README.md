# TIDEBREAK 95 v14.1

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14.1/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4315` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0〜M4を完了したv14.0を固定し、M5第1回独立批評の最大欠陥だった主要操作の手触りを改善した。慣性操舵へ艇の即時ロール、走路のバンク、流線加速、荷重側の飛沫、左右へ移動する水音を同期し、Spaceサージでは流線と水音の勢いも増す。実Chromeの左右反転監査で速度・姿勢・画面・音の方向一致と無傷のサージ旋回を確認し、製品横断監査はフォーカス停止、入力解放、連続音停止、復帰後60.715秒・平均8.333msに合格した。5区間、構造攻略ボス、救助・直行・WAKE SKIMの三方針は維持している。次はv14.1を固定し、M5第2回独立批評でFLOOD CUTの体感と全編の商品性を比較して`ver14.2/`を改善する。
