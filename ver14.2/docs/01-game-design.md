# Game design

## 中核ループ

前方のSOS・充電門・障害を読む → 慣性操舵で進路を作る → Spaceのサージを救助または破砕へ使う → 救助連鎖とニアミスで充電する。サージ中は救助範囲が広がり軽瓦礫を砕くが、コンクリートと大型船は避ける必要がある。

## M1ルール

- 左右矢印は横加速度を与え、離しても短く滑る。水路端では跳ね返る。
- サージは34%を消費し0.56秒持続する。自然回復、救助、充電門、ニアミスで補給する。
- 漂流者へ通常時は近接、サージ中は広い範囲で接触すると救助。連続救助は得点倍率になる。
- 流木はサージで破砕可能。コンクリートとバージは回避専用。船体3点を失うと失敗。
- 約94秒で4局面を通り、船体と救助数に応じた結果を表示する。

## M1の90秒構成

0〜25秒は広い外港で単独救助と流木破砕を交互に教える。25〜50秒は浸水街路で狭窄とコンクリートを加える。50〜75秒は横流の視覚表現と左右競合を重ねる。75〜94秒は水平線を塞ぐ防潮バージと左右門を抜け、小さな決着を作る。

## 本編への発展

M2では代表区間の完成船体アニメーション、入力設定、音量、保存、初回導線を確立する。M3では護送対象、分岐水路、潜水と浮上、潮位切替を単独導入してから組み合わせる。最終ボスは通常障害の高耐久化ではなく、アンカー切断で走路を生成し、船腹を壁走行し、内部排水路へ進入する三構造を持つ。

## M3外港

0〜180秒は単独救助・流木破砕・充電門から始め、4組の人数優先救助と3組の破砕／迂回へ段階発展する。同時SOSは高人数側と低人数側の一方だけを救助できる。分岐水路はサージを消費して瓦礫を破砕すると高得点、安全門を抜けると次の判断へ充電を残せる。外港だけで基本入力、救助優先、資源を伴う経路判断を一巡させる。

## M3浸水商業区

180〜360秒は直線狭窄を廃止し、水路中心、幅、交差流が連続変化する店舗峡谷を進む。入口のMARKET/ARCADE救助は得点だけでなく次の60秒を分岐させ、MARKETは狭い多屈曲のサービス水路とコンクリート、ARCADEは広い大旋回と強い交差流・流木になる。中盤のCLINIC/STATION救助が次の50秒の曲率、流れ、条件付き障害を再び変え、最後に合流する。全回収ではなく、選んだ救助先が次の操舵課題を決める二段階の連鎖分岐である。

## M3地下放水路

360〜540秒は空を閉じた低天井の地下施設へ入り、左右操舵に上下矢印の潜水・浮上を加える。低天井は深度0.58以上、吸入口は深度0.38以下で安全に抜けられる。導入で深層・表層救助を往復した後、深層でDRAIN/FLOOD、RELIEF/BYPASSの2基の排水弁を排他的に操作する。弁の選択は後続の水位、水路中心・幅・横流、出現する上下障害、救助可能層を変え、先の設備操作を後の立体攻略へ連鎖させる。外港の全回収と商業区の平面分岐から、同じ前進中に上下層を往復し、水路そのものを先に構成する判断へ変える。

## M3倒壊コンテナ港

540〜720秒は上下入力で港全体の潮位を変え、救助フェリーと11回のコンテナ崩落を越える。低潮は吊り荷の下、高潮は沈没荷の上を通す。途中2回の救助桟橋で積載人数を選び、積載が増えるほどフェリーの追従と許容隊形が厳しくなる一方、Spaceサージは短時間フェリーを呼び寄せる。SERVICE/LOCK、CANAL/DOCKの二段階航路は要求潮位、後続水路形状、出現障害を変える。個人救助から、救える人数と同行船の隊形・航路を同時に管理する護送へ目的と失敗対象を変える。

## M3高潮防壁

720〜900秒は上昇する高潮を背に鋼製防壁へ進入する。予告された左右の壁端へ操舵し、Spaceサージで1.35秒の壁走行へ移り、その間に上または下キーで門レバーを操作する。12門の途中でPUMPS/BEACONS、RELIEF/LOCKSの壁面設備を排他的に選び、その選択が後続水路の中心・幅・横流と出現門を変える。倒壊港から引き継いだ救助フェリーはSpaceで隊形回復し、全門と2設備を通過してSAFE BASINへ収容する。潮位を選ぶ護送から、位置・瞬間入力・設備選択・隊形管理を連続させる大山場へ変える。

## M3最終ボス — LEVIATHAN BREAKER

900〜1020秒は通常障害の高耐久化ではなく三つの構造へ転換する。最初の36秒は左右アンカーへ接近中にSpaceで鎖を切り、巨大船の下へ進入する走路を生成する。次の42秒は狭い左右船腹レーンへ寄せてSpaceで壁走行し、3箇所の装甲を剥がす。最後の42秒は閉鎖された船内排水路へ入り、下層ドレンは潜水、上層ベントは浮上で開放してから、露出した中央コアをSpaceで破砕する。外の護送対象を守る目的から巨大構造そのものへ侵入して停止させる目的へ変え、既習のサージ、壁走行、潜水・浮上を別順序で再構成する。
