# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の縦切り、M2の代表区間表現と製品基盤、M3本編を完了した。外港、浸水商業区、地下放水路、倒壊コンテナ港、高潮防壁を各約3分へ拡張し、最終2分はアンカー切断、巨大船の船腹壁走行、内部排水路、コア破砕へ構造転換する。5区間とボスの空間・目的・操作・攻略は分離でき、状態注入なしの習熟方針通しは約17分。M4では救助48名の無傷方針、救助を減らす無傷直行、10回のWAKE SKIMで直行より高得点を取る危険方針を全編比較した。序盤90秒へ危険方向、段階操作提示、安全ゲートの1点修復を加え、コア破砕後には外殻破断、圧力解放、沈降、2艇脱出を7.46秒の動作として追加した。入力を遅らせた初見相当方針は約88秒から約192秒へ進んだが、外部人間の初見確認には代えない。全完走方針が固定17分で時間短縮にならず、区間音、外部プレイヤー実測、公開は未完成である。
