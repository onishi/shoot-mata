# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の縦切り、M2の代表区間表現と製品基盤、M3本編を完了した。外港、浸水商業区、地下放水路、倒壊コンテナ港、高潮防壁を各約3分へ拡張し、最終2分はアンカー切断、巨大船の船腹壁走行、内部排水路、コア破砕へ構造転換する。5区間とボスの空間・目的・操作・攻略は分離でき、状態注入なしの習熟方針通しは約17分。M4の複数方針批評、手触り・表現拡張、初見外部プレイヤー実測、公開は未完成である。
