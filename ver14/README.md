# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約を完了し、M1の約94秒縦切りを実装した。港湾、浸水街路、横流、防潮バージ接近の4局面で、操舵、救助、サージ破砕、充電、被害、結果まで遊べる。これは中核仮説を評価するVertical Sliceであり、本編、完成素材、設定・保存、全ボス、公開は未完成である。
