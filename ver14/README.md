# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の約94秒縦切り、M2の代表区間表現と製品基盤を完了し、M3本編制作へ移る。港湾、浸水街路、横流、防潮バージ接近の4局面で、操舵、救助、サージ破砕、充電、被害、結果まで遊べる。救難艇の固有シルエット、港湾の三層景観、SOS旗を振る漂流者、接触で二分する流木、連続飛沫、救助引上げ、速度連動するエンジン・水音に加え、音量・動き軽減・キー変更、保存・破損復旧、フォーカス喪失時の安全停止を実装済みだが、後続区間の完成造形、16分以上の本編、全ボス、公開は未完成である。
