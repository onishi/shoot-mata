# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の約94秒縦切り、M2の代表区間表現と製品基盤を完了し、M3本編制作中。外港に続く浸水商業区を、中心が東西へ0.27移動する狭いS字水路、流向が反転する交差流、二組の左右救助選択、商店街の近景を持つ固有区間へ更新した。救難艇の固有シルエット、港湾の三層景観、SOS旗を振る漂流者、接触で二分する流木、連続飛沫、救助引上げ、速度連動するエンジン・水音に加え、音量・動き軽減・キー変更、保存・破損復旧、フォーカス喪失時の安全停止を実装済みだが、地下放水路以降の完成区間、16分以上の本編、全ボス、公開は未完成である。
