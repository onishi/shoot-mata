# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の縦切り、M2の代表区間表現と製品基盤を完了し、M3本編制作中。外港、S字と交差流を読む浸水商業区、上下層を往復する地下放水路、潮位を切り替えて救助フェリーを護送する倒壊コンテナ港に続き、上昇する高潮を背に左右の防壁をサージ走行して門レバーを操作する高潮防壁を実装した。5区間の空間・目的・操作・攻略は分離できたが、現状の通しは約121秒の縦切りであり、16分以上の本編、各区間の製品尺、全ボス、公開は未完成である。
