# TIDEBREAK 95 v14.0

洪水都市を突っ切る救難ハイドロフォイルを操り、慣性のある操舵と一瞬のサージで漂流者を救い、瓦礫を砕き、崩壊する防潮線へ駆けつける前進型レスキューレーサー。

## 起動

```sh
cd ver14/game
npm run serve
```

PC版Chromeで `http://127.0.0.1:4314` を開く。Enterで開始、左右矢印で操舵、Spaceでサージ、Pでポーズ、Rで再挑戦する。

## 現在地

M0の白紙3案比較と製品規模契約、M1の縦切り、M2の代表区間表現と製品基盤を完了し、M3本編制作中。外港、浸水商業区、地下放水路、倒壊コンテナ港、高潮防壁を各約3分へ拡張した。高潮防壁では12門の壁走行、2回の設備選択、救助フェリーの隊形回復と安全区画収容を組み合わせる。5区間の空間・目的・操作・攻略は分離でき、状態注入なしの習熟方針通しは約900秒。製品規模契約の下限16分と、走路生成・船腹壁走行・内部排水路からなる全ボス、公開は未完成である。
