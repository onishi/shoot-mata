# Game design

## 中核ループ

前方のSOS・充電門・障害を読む → 慣性操舵で進路を作る → Spaceのサージを救助または破砕へ使う → 救助連鎖とニアミスで充電する。サージ中は救助範囲が広がり軽瓦礫を砕くが、コンクリートと大型船は避ける必要がある。

## M1ルール

- 左右矢印は横加速度を与え、離しても短く滑る。水路端では跳ね返る。
- サージは34%を消費し0.56秒持続する。自然回復、救助、充電門、ニアミスで補給する。
- 漂流者へ通常時は近接、サージ中は広い範囲で接触すると救助。連続救助は得点倍率になる。
- 流木はサージで破砕可能。コンクリートとバージは回避専用。船体3点を失うと失敗。
- 約94秒で4局面を通り、船体と救助数に応じた結果を表示する。

## M1の90秒構成

0〜25秒は広い外港で単独救助と流木破砕を交互に教える。25〜50秒は浸水街路で狭窄とコンクリートを加える。50〜75秒は横流の視覚表現と左右競合を重ねる。75〜94秒は水平線を塞ぐ防潮バージと左右門を抜け、小さな決着を作る。

## 本編への発展

M2では代表区間の完成船体アニメーション、入力設定、音量、保存、初回導線を確立する。M3では護送対象、分岐水路、潜水と浮上、潮位切替を単独導入してから組み合わせる。最終ボスは通常障害の高耐久化ではなく、アンカー切断で走路を生成し、船腹を壁走行し、内部排水路へ進入する三構造を持つ。

## M3外港

0〜180秒は単独救助・流木破砕・充電門から始め、4組の人数優先救助と3組の破砕／迂回へ段階発展する。同時SOSは高人数側と低人数側の一方だけを救助できる。分岐水路はサージを消費して瓦礫を破砕すると高得点、安全門を抜けると次の判断へ充電を残せる。外港だけで基本入力、救助優先、資源を伴う経路判断を一巡させる。

## M3浸水商業区

180〜205秒は直線狭窄を廃止し、水路中心が東0.27から西0.27へ振れるS字と、最大0.34で二度反転する交差流を操舵へ加える。半幅は外港0.72から最狭0.435へ縮む。MARKET/ARCADE、CLINIC/STATIONの二組は同時にSOSを出し、片方を救助すると他方が閉じるため、全回収ではなく流れ、充電、進入角を見た救助ルート選択になる。

## M3地下放水路

205〜230秒は空を閉じた低天井の地下施設へ入り、左右操舵に上下矢印の潜水・浮上を加える。低天井は深度0.58以上、吸入口は深度0.38以下で安全に抜けられる。DIVE TEAMとVALVE CREWは深層、AIR POCKETは表層でのみ救助でき、終端ではUPPER/LOWER CREWの一方を層と横位置の両方から選ぶ。外港の全回収と商業区の平面分岐から、同じ前進中に上下層を往復する立体判断へ変える。

## M3倒壊コンテナ港

230〜249秒は上下入力で港全体の潮位を変え、救助フェリーと5回のコンテナ崩落を越える。低潮は吊り荷の下、高潮は沈没荷の上を通し、艇とフェリーの横隊形も維持する。個人救助から同行船の護送へ目的と失敗対象を変える。

## M3高潮防壁

249〜276秒は上昇する高潮を背に鋼製防壁へ進入する。予告された左右の壁端へ操舵し、Spaceサージで1.35秒の壁走行へ移り、その間に上または下キーで門レバーを操作する。5門は左右とレバー方向を交互に変え、成功すると高潮圧を押し戻し、失敗すると船体と高潮圧を失う。水位を選ぶ倒壊港から、位置・瞬間入力・設備操作を連続させる区間へ変える。
