# Technical design

- PC版Chrome、Canvas 2D、Web Audio、ES modules。外部実行依存なし。
- `model.js`は描画・音から独立した決定的状態更新を持つ。固定入力と時間刻みで高速検証できる。
- 経路イベントは時刻、種別、横位置のデータとして定義する。M2以降は区間データへ分割する。
- 描画は遠近座標 `z` を画面Yと横幅へ変換する。実ゲーム判定は正規化座標で行う。
- `window.__TIDEBREAK__`は目視監査時の版assertと状態読取に使う。完成配布前に攻略用の直接状態変更は公開面から除く。
- 目標は60fps、1280×720と960×540相当を標準、640×360を最小監査対象とする。
