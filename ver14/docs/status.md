# v14.0 Status

## 現在状態

- 現在版: v14.0 (`ver14/`)
- 段階: M0完了、M1 Vertical Slice完了、M2代表区間制作中

## M0達成

- 白紙からTIDEBREAK 95、IRON CHORUS、VOLT SHEPHERDの3案を、10秒、90秒、幻想、三転換、ボス、再挑戦、代表画面、動きと音で比較した。
- 上位2案を5場面へ落とし、主要入力が説明前から気持ちよく、目的と主役を一画面へ出せるTIDEBREAK 95を採用した。
- 初見20〜30分、習熟16〜22分、5固有区間、4発展段階、4山場、構造攻略ボスの製品規模契約とM1撤退条件を固定した。

## M1達成

- 新規Canvas/Web Audio実装へ、慣性操舵、サージ、救助、流木破砕、破壊不能障害、充電、被害、連鎖得点、ポーズ、再挑戦、結果を接続した。
- 約94秒で外港、浸水街路、横流、防潮バージ接近へ変わる30イベントの縦切りを実装した。
- `npm run verify`は5/5 testsと全4ソース構文に合格した。
- 一意ポート4314、版タイトルassert、状態注入なしのChrome実キー監査は94.01秒、30/30イベント、4/4局面、船体3、救助10、68,500点、RANK Aで完走した。
- タイトル、サージ、救助、3転換、結果を1280×720で、プレイと結果を640×360で比較し、切れ、意図しない重なり、判別不能はなかった。
- M1撤退条件には該当しない。主役・都市・人物の造形、連続水しぶき、救助者の引上げ動作はM2品質へ未達である。

## M2進行

- 救難艇を赤白船体、キャビン、翼、支柱を持つ固有シルエットへ更新し、横速度に追従するロールとサージ時の浮上を加えた。
- 航跡を速度・横移動・サージで開き方が変わる左右非対称の連続飛沫へ更新した。
- 救助者がロープ軌道で艇へ収束する0.9秒の引上げを追加し、処理済み対象が艇の下へ残る描画欠陥も除去した。
- Web Audioへ速度・サージ・区間に追従するエンジンと水音の連続層を追加した。通常85.32Hz / gain 0.02232・0.0165から、サージ123.8Hz / gain 0.0348・0.0295へ上がり、結果画面では両gainが0になる。
- Chromeの背景抑制で監査が途中終了する非決定性を発見し、監査上限を延長したうえで未完走を明示的に失敗させた。
