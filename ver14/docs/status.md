# v14.0 Status

## 現在状態

- 現在版: v14.0 (`ver14/`)

## M1達成

- 新規Canvas/Web Audio実装へ、慣性操舵、サージ、救助、流木破砕、破壊不能障害、充電、被害、連鎖得点、ポーズ、再挑戦、結果を接続した。
- 約94秒で外港、浸水街路、横流、防潮バージ接近へ変わる30イベントの縦切りを実装した。

## M2達成

- 救難艇を赤白船体、キャビン、翼、支柱を持つ固有シルエットへ更新し、横速度に追従するロールとサージ時の浮上を加えた。
- 航跡を速度・横移動・サージで開き方が変わる左右非対称の連続飛沫へ更新した。
- 救助者がロープ軌道で艇へ収束する0.9秒の引上げを追加し、処理済み対象が艇の下へ残る描画欠陥も除去した。
- Web Audioへ速度・サージ・区間に追従するエンジンと水音の連続層を追加した。通常85.32Hz / gain 0.02232・0.0165から、サージ123.8Hz / gain 0.0348・0.0295へ上がり、結果画面では両gainが0になる。
- Chromeの背景抑制で監査が途中終了する非決定性を発見し、監査上限を延長したうえで未完走を明示的に失敗させた。
- 外港を遠景の非対称クレーン・作業船、中景の水路、手前の岸壁・救難標識からなる三層景観へ更新した。走路境界とSOSの機能色は維持している。
- 漂流者を救命浮輪、左右非対称に振る腕、赤いSOS旗を持つ造形へ更新し、流木は木目と枝を持つ輪郭、サージ接触時は二つの回転する半身と11片の破片へ変形するようにした。
- Chrome監査へ漂流者接近と流木破砕の自動捕捉を追加し、方針も「充電済みなら破砕、未充電なら回避」へ修正した。最終通しは94.013秒、30/30イベント、4局面、船体3、救助10、70,950点、両捕捉trueで完走した。
- タイトルの`S`から開く設定画面へ、10%刻みのマスター音量、動き軽減、操舵左右・サージのキー再割当を実装した。動き軽減は画面揺れを止め飛沫粒子を7個から3個へ抑え、音量は短音と連続音の両方へ反映する。
- `tidebreak95.settings.v1`へ設定を保存し、JSON破損、不正範囲、未許可キー、重複割当を安全な既定値へ復旧する。8/8 testsと隔離Chromeで破損復旧、70%・動き軽減・A/D/Wの再読込保持、A入力到達、AudioContext 0.7を確認した。
- プレイ中の`blur`またはタブ非表示で`RESCUE HOLD`へ入り、操舵入力を解放して作者時間と連続音を停止する。復帰は明示的なP入力とし、古い操舵を再利用しない。
- 隔離Chromeの製品監査で、停止中の作者時間差0秒、左右入力false、連続音停止、P復帰後の入力falseを確認した。復帰後60.735秒・3,645 framesは平均16.663ms、最大20.7ms、20ms超1 frameで、18ms平均・80ms最大のM2予算に合格した。
- 1280×720の停止画面を目視し、主役と走路を残した暗転上に停止理由と復帰操作が重なりなく読めることを確認した。これによりM2代表表現と製品基盤を完了とする。

## M3地下放水路達成

- 50〜75秒の横流区間を、閉じた地下施設と上下層攻略へ置き換えた。下入力で潜り、上入力で浮上する決定的`depth`/`depthV`を追加した。
- 低天井は深度0.58以上、回転吸入口は0.38以下を安全層とし、DIVE TEAM・VALVE CREWは深層、AIR POCKETは表層だけで救助できる。終端はUPPER/LOWER CREWの上下排他選択になる。
- 斜材、警告灯、パイプ、水膜、気泡、深度計、必要入力標識を追加し、潜水時はエンジン周波数を最大24%下げ水音を増幅する。
- 初回Chrome通しは最大深度1へ到達したが、再浮上フラグが一フレームの閾値跨ぎを要求してfalseになった。履歴最大深度と現在深度で判定するよう修正し回帰テストを追加した。
- 次の通しでは75秒後に地下の低天井が到達して船体1を失うイベント時刻の食み出しを発見した。境界を越える障害を除去し、最終通しは94.013秒、36/36イベント、船体3、救助13、109,550点で完走した。
- 最終通しは深層2名・表層2名、最大深度1、潜水後の再浮上trueを記録し、両層の代表画面で主役、障害、深度HUD、必要入力に切れ・重なりがないことを確認した。
- 製品監査で左操舵と潜水を同時保持してフォーカスを失わせ、両入力の解放、作者時間差0.0166秒、連続音停止、明示復帰を確認した。復帰後60.768秒・3,645 framesは平均16.672ms、最大33.3msで予算内だった。

## M3倒壊コンテナ港達成

- 75〜94秒を倒壊コンテナ港へ置き換え、上下キーで目標潮位を切り替える潮位制御、艇の横位置を遅れて追う救助フェリー、低潮・高潮を要求する5回のコンテナ崩落を実装した。
- 崩落は必要潮位に達し、艇とフェリーの横差が0.38以内なら通過する。失敗時はフェリー耐久が減り、3回失敗すると専用ゲームオーバーになる。
- ガントリー、積層コンテナ、崩落岸壁、潮位線、低潮・高潮予告、フェリー造形と耐久HUDを追加し、区間目的を個人救助から護送へ転換した。
- 初回目視でフェリーが艇の真後ろへ重なり、高潮の証拠が次の低潮予告を捕捉する問題を発見した。フェリーを遠近方向へ離し、潮位と予告が一致する連続フレームだけを捕捉するよう修正した。
- `npm run verify`は15/15 testsと全ソース・監査スクリプト構文に合格。最終の状態注入なしChrome通しは94.013秒、36/36イベント、船体3・フェリー3、救助13、113,550点、5/5崩落通過、潮位切替5回で完走した。1280×720の低潮・高潮と640×360の結果・再挑戦に切れや意図しない重なりはない。

## M3外港製品尺達成

- 外港を25秒から180秒へ拡張し、単独救助・流木破砕・充電門を教える導入から、4組の人数優先救助と3組のサージ破砕／安全迂回へ段階発展させた。
- 優先救助は同時SOSの一方だけを救え、3/2/4/3人の高人数側と1/1/1/2人の近道側を比較する。破砕ルートはSpaceと充電を要求し高得点、安全迂回は充電を補給するため、救助数・速度・次判断の資源が競合する。
- `harborPriorities`と`harborRoutes`を決定的履歴へ追加し、人数加算、代替信号の閉鎖、破砕／迂回の排他、充電差を単体テストで固定した。タイトルとHUDは外港進行を示す表示へ更新した。
- `npm run verify`は19/19 testsと全ソース・監査スクリプト構文に合格。状態注入なしChrome通しは276.006秒、71/71イベント、船体3、救助29、優先救助4/4、破砕ルート3/3、後続の上下層・崩落5/5・防壁門5/5を保って完走した。
- 1280×720の人数優先と破砕／迂回、640×360の結果・再挑戦を目視し、艇、SOS、人数、ルート標識、HUDに切れや意図しない重なりはない。
