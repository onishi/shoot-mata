# 体験品質

- 爪を閉じる一拍と重量による歩速低下で、暴走機を工具で固定した手応えを作る。
- 扉の向こうまで通す横投げの速度と接触時の強い停止で、暴走機を群れへ返す気持ちよさを作る。
- 予告と着地を見て、掴む、位置を変える、即座に投げるを選び直せるようにする。
- 搬送橋の横移動、縦坑の視線の縦移動、注湯炉の左右を守る判断を、文字や色を隠した場面でも区別できるようにする。
- 床に置く奥行きのマーカー、輪郭、誇張したモーションを時代の文法として採用。フォーカス停止とキーボード導線で現代化する。コイン投入とコンティニューカウントダウンは企画から外す。

## M1 監督機の再照準

固定60 Hzのキー再生で最初の命中前後を比較した。64.83秒では投擲物が監督機に届く直前。65.15秒では機体と影が離れ、「投擲無効」の表示と床の矢印が出ている。65.45秒では表示が消え、予定地点に火花が出る。画面では持ち直した投擲物の射線が着地点より上に残り、次は奥行きを合わせ直す必要が見える。初見でその判断に至るか、着地音が合図として伝わるかは未確認。[3フレームの比較](evidence/foreman-landing.png)

### 練習モードでの実時間比較

ローカル配信の v15.0 を新規 Chrome プロファイルで起動し、監督機戦の練習を2回、実時間の自動キー入力で試した。どちらも開始約0.2秒で初弾を放ち、約0.7秒で「投擲無効」と床の着地マーカーを記録した。練習開始からの経過時間で比較する。

- 元の射線を維持した回は、約0.8秒に持ち直して続投した。投擲物が元の射線を通過し、着地後も監督機の耐久表示は2、得点は500だった。
- 着地先に合わせた回は、移動中に下へ約0.5秒動いた。着地後の約1.3秒で床の照準が監督機に重なり、続投後は耐久表示が1、得点は1000になった。
- 両方とも最終結果は「停止」。再挑戦後も練習設定が保持され、結果画面で設定を解除すると通常の搬入口から開始した。

比較画像の上段は元の射線、下段は着地先に合わせた射線。各段の左が続投前、右が続投後。入力は時刻を指定しており、表示を見た初見の操作判断と着地音の聞き取りは未確認。商業参照2作に対する選択と応答、失敗と上達、展開と再挑戦の3軸は未確認のまま。[続投前後の比較](evidence/foreman-practice.png)

### 表示を見て続投するための合図

監督機が移動している間は画面下に「着地を待つ」と出る。着地直後の記録では、監督機の火花より上を照準線が通り、画面下は「監督機に射線を合わせる」に切り替わった。奥行きを変えて足元の輪が強調されると「Zで投げる」に変わった。Chromeの実時間テストではこの表示に応じてキーを操作し、500点から1000点になった。初見操作と着地音の試聴は未確認。[移動中](evidence/foreman-cue-wait.png) · [着地後](evidence/foreman-cue-aim.png) · [射線一致](evidence/foreman-cue-throw.png)

### 最初に当たる機体の予測

新規Chromeで監督機の練習を2回起動し、実時間の自動キー入力で、掴んですぐに投げた場合と掴んで待った場合を比べた。開始直後は輪が監督機に付き、「Zで投げる」の状態で投げると500点になった。待った回は残り25秒の時点で接近した敵機に輪が移り、「手前に敵機 · 位置を変える」に切り替わった。そこで投げると200点で、監督機の耐久は3のままだった。プレイヤーと敵機が重なった場面でも、輪は両機の手前に見えた。照準は各フレームの位置をもとに計算するため、投擲後に移動する機体で結果は変わり得る。[射線が通る場面](evidence/foreman-contact-clear.png) · [敵機が入り込んだ場面](evidence/foreman-contact-blocked.png)

## 圧延機の突進レーン

圧延機は予告の開始位置からプレイヤーがいた左右方向に突進する。床の赤い帯から奥行き方向に抜けると、機体の横へ回って掴める。回帰テストでは同じ開始位置から、帯に残ったときは耐久が5から4になり、下へ12フレーム歩いたときは耐久5のまま突進後に掴めた。

固定60 HzのChromeキー再生で、最初の圧延機の奥行きが y=260.7 に保たれ、横位置が x=638.2 → 620.0 → 575.8 と進む様子を採取した。3場面とも耐久5。通しでは67.88秒に鎮圧成功（1700点、耐久4）し、Enterで再挑戦した。帯を見て初見で避けられるかは未確認。[予告](evidence/roller-warning.png) · [突進中](evidence/roller-charge.png) · [突進後](evidence/roller-recovery.png)

商業2作の比較に使える公式ブラウザ版のページを確認した。どちらも家庭用移植版として掲載されている。M1のプレイ比較では実際に使用した版を記録する。[ファイナルファイト](https://captown.capcom.com/en/classic_games/17) · [キャプテンコマンドー](https://captown.capcom.com/en/classic_games/37)

## 所持中の被弾と回避

Chromeの固定60 Hzキー再生で、開幕の小型機を抱えたまま待つと、次の小型機が詰めた6.57秒に耐久が5から4に減り、照準が消えて「落とした」が出た。近接状態から奥行き方向へXで回避した回帰テストでは、耐久5のまま所持を継続した。落とした機体は反動が終わると掴み直せる。初見で危険に気づいて投げるか回避できるかと、商業参照との3軸比較は未確認。

### 圧延機と小型機の輪郭

### 搬入口の掴みから初弾まで

新規Chromeの固定60 Hzキー再生で、再挑戦直後に敵機の輪と「輪の付いた敵機を Z でつかむ」を確認した。左を向いて掴むと射線に敵機がいないため「敵機に射線を合わせる」が出た。通常通しでは最初の小型機を保持し、約1秒で次の敵機が射線に入り「Zで投げる」が出た。投げた結果は1.28秒に200点。案内の切り替えを確認した段階であり、初見で自発的に照準を変えられるかは未確認。

### 再挑戦で掴みと投擲を外す

Chromeの固定60 Hzキー再生で、通常通しの初弾は1.28秒で200点。再挑戦直後に左を向いて掴み、敵のいない左へ投げると床の端で「命中なし」が表示され、得点は0のままだった。その後、上へ離れてZを押すと自機の上に「つかめない」が表示され、所持なしのままだった。投擲先と自機で表示位置を分け、各メッセージは0.65秒表示する。初見でこの違いを読み取って位置や投げる時機を変えられるかは未確認。

### 危険帯からの退避

新規プロファイルのChromeで、現行モジュールを埋め込んだ一時HTMLに固定60 Hzのキー入力を再生した。状態注入なしで監督機区画の同じ突進を比較した。66.57秒に圧延機の危険帯へ入ると、監督機戦の案内に優先して「突進に注意 · ↑↓で帯から出る」が表示された。

- 奥行き308.9に留まる入力では、67.17秒に耐久が4から3へ減り、68.62秒に1700点で鎮圧した。
- 案内の次フレームから↑とXで退避すると、5フレーム後に奥行き273.1で案内が消え、耐久4のまま1700点で鎮圧した。両回とも再挑戦で耐久5・0点に戻った。

表示と入力に伴う結果差を確認した。初見の人が表示を読んで退避できるか、走行音・着地音・制動音の試聴、商業参照との実操作比較は未確認。

## 圧延機の停止から再始動まで

新規 Chrome で現行コードを埋め込んだ一時 HTML を起動し、状態注入なしで固定 60 Hz のキー入力を再生した。[停止直後・停止中盤・再始動の連続フレーム](evidence/roller-stop-meter.png)は上から 25.60 秒、25.77 秒、26.10 秒。圧延機は最初の二枚で同じ位置に留まり、ゲージは 89% から 52% に減った。三枚目では表示が消え、圧延機が接近を再開した。範囲外では「停止中」、掴み対象に入れば「Zでつかむ」と表示する。ゲージは再始動までの時間を指し、再始動後も掴み判定は通常のルールに従う。

回帰では危険帯に残ると耐久4、奥行きへ避けると耐久5で停止直後に掴めた。ブラウザの自動入力では 68.62 秒で鎮圧成功（1700点、耐久3）、再挑戦で耐久5・0点に戻った。商業参照との比較、初見相当の判断、試聴は未確認。

## 圧延機を奪った後の投擲

小型機を運ぶ速度は105、圧延機は78。圧延機を投げると通常の敵に対する命中半径が33から49に広がり、床の橙色の射線と発射音の低さで違いを伝える。回帰では奥行き差40の同じ配置で、小型機の照準は反応せず0点、圧延機の照準は敵を捉えて200点となった。危険帯を避けて圧延機を確保すれば、運ぶ間は追われやすくなる代わりに、奥行きを詰めずに投げられる。

Capcom Townの公式ページは確認できたが、ローカル環境では配信ホストの名前解決に失敗した。商業参照2作との3軸比較、初見での使い分け、投擲音の聞こえ方は未確認。

### 運搬中に接近する小型機

新規Chromeで、搬入口の最初の小型機をつかんで待つ入力を固定60 Hzで再生した。次の小型機が接近すると5.97秒に機体灯と足元の橙色の輪が現れた。その場に残ると6.57秒に被弾し、耐久が5から4に下がって「落とした」と表示された。輪が出た次のフレームで下＋Xを入力した回は、6.10秒に輪が消え、下入力を維持した7.20秒時点でも耐久5・所持を保った。回避の試験には描画を検出する自動入力を使った。初見での発見と回避判断は未確認。
