# 体験品質

- 爪を閉じる一拍と重量による歩速低下で、暴走機を工具で固定した手応えを作る。
- 扉の向こうまで通す横投げの速度と接触時の強い停止で、暴走機を群れへ返す気持ちよさを作る。
- 予告と着地を見て、掴む、位置を変える、即座に投げるを選び直せるようにする。
- 搬送橋の横移動、縦坑の視線の縦移動、注湯炉の左右を守る判断を、文字や色を隠した場面でも区別できるようにする。
- 床に置く奥行きのマーカー、輪郭、誇張したモーションを時代の文法として採用。フォーカス停止とキーボード導線で現代化する。コイン投入とコンティニューカウントダウンは企画から外す。

## M1 監督機の再照準

固定60 Hzのキー再生で最初の命中前後を比較した。64.83秒では投擲物が監督機に届く直前。65.15秒では機体と影が離れ、「投擲無効」の表示と床の矢印が出ている。65.45秒では表示が消え、予定地点に火花が出る。画面では持ち直した投擲物の射線が着地点より上に残り、次は奥行きを合わせ直す必要が見える。初見でその判断に至るか、着地音が合図として伝わるかは未確認。[3フレームの比較](evidence/foreman-landing.png)

### 練習モードでの実時間比較

ローカル配信の v15.0 を新規 Chrome プロファイルで起動し、監督機戦の練習を2回、実時間の自動キー入力で試した。どちらも開始約0.2秒で初弾を放ち、約0.7秒で「投擲無効」と床の着地マーカーを記録した。練習開始からの経過時間で比較する。

- 元の射線を維持した回は、約0.8秒に持ち直して続投した。投擲物が元の射線を通過し、着地後も監督機の耐久表示は2、得点は500だった。
- 着地先に合わせた回は、移動中に下へ約0.5秒動いた。着地後の約1.3秒で床の照準が監督機に重なり、続投後は耐久表示が1、得点は1000になった。
- 両方とも最終結果は「停止」。再挑戦後も練習設定が保持され、結果画面で設定を解除すると通常の搬入口から開始した。

比較画像の上段は元の射線、下段は着地先に合わせた射線。各段の左が続投前、右が続投後。入力は時刻を指定しており、表示を見た初見の操作判断と着地音の聞き取りは未確認。商業参照2作に対する選択と応答、失敗と上達、展開と再挑戦の3軸は未確認のまま。[続投前後の比較](evidence/foreman-practice.png)

### 表示を見て続投するための合図

監督機が移動している間は画面下に「着地を待つ」と出る。着地直後の記録では、監督機の火花より上を照準線が通り、画面下は「監督機に射線を合わせる」に切り替わった。奥行きを変えて足元の輪が強調されると「Zで投げる」に変わった。Chromeの実時間テストではこの表示に応じてキーを操作し、500点から1000点になった。初見操作と着地音の試聴は未確認。[移動中](evidence/foreman-cue-wait.png) · [着地後](evidence/foreman-cue-aim.png) · [射線一致](evidence/foreman-cue-throw.png)
